# 1. 이터러블(Iterable)

### 1) 이터러블

> **반복 가능한 객체**

`__iter__(..)`가 정의되어 있다면 반복할 수 있다.

이터러블은 반복을 위해 이터레이터를 생성할 수 있는 객체이다.

대표적으로 리스트와 같은 객체가 있다.

```python
nums = [10, 20, 30]

nums.__iter__
```

`for`문을 이용해서도 요소를 하나씩 꺼낼 수 있다.

```python
for num in nums:
    print(num)
```

결과:

```text
10
20
30
```

---

# 2. 이터레이터(Iterator)

### 1) 이터레이터

> **반복을 하면서 순서대로 요소를 하나씩 조회할 수 있는 객체**

이터레이터를 만들기 위해 `iter(...)`를 사용한다.

```text
이터러블
   ↓
iter(...)
   ↓
이터레이터 객체 생성
```

이터레이터에서는 `next(...)`를 사용하여 다음 요소를 하나씩 조회한다.

```text
next(...)
   ↓
다음 요소 조회
```

---

### 2) `iter()`와 `next()`

```python
fruits = ['Apple', 'Orange', 'Melon', 'Banana',]

it = iter(fruits)
```

`iter(fruits)`는 이터레이터 객체를 생성한다.

이후 `next()`를 호출하면 요소를 하나씩 가져온다.

```python
next(it)
```

첫 번째 요소:

```text
Apple
```

다시 `next()`를 호출하면 다음 요소를 가져온다.

```python
next(it)
```

다음 요소:

```text
Orange
```

즉,

```text
iter(...)
→ 이터레이터 생성

next(...)
→ 다음 요소 하나 조회
```

---

# 3. 제너레이터(Generator)

### 1) 제너레이터

> **함수의 실행을 정지하고 원할 때 다시 재개하는 형태**

제너레이터에서는 `yield`를 사용한다.

```python
def generate_nums():

    print("1번째")
    yield 10

    print("2번째")
    yield 20

    print("3번째")
    yield 30
```

이 함수를 호출하면 일반 함수처럼 모든 코드가 즉시 실행되는 것이 아니라 제너레이터 객체가 생성된다.

```python
gen = generate_nums()

gen
```

이후 `next()`를 호출할 때마다 함수가 실행되다가 `yield`에서 정지한다.

```python
next(gen)
```

실행 흐름:

```text
generate_nums()
      ↓
"1번째" 출력
      ↓
yield 10
      ↓
10 반환 후 실행 정지
```

다시 `next(gen)`을 호출하면 정지했던 지점부터 실행이 재개된다.

```text
next(gen)
      ↓
"2번째" 출력
      ↓
yield 20
      ↓
20 반환 후 다시 정지
```

다시 호출하면:

```text
next(gen)
      ↓
"3번째" 출력
      ↓
yield 30
      ↓
30 반환
```

즉,

> **제너레이터는 필요한 시점에 하나씩 값을 생성한다.**

---

### 2) 제너레이터와 메모리

제너레이터는 값을 한꺼번에 모두 메모리에 만들어 두는 방식이 아니다.

```python
gen = generate_nums()
```

이후

```python
next(gen)
```

을 호출할 때 필요한 값을 하나씩 꺼내온다.

원본에서는 `next(gen)`을 통해 꺼내오는 값이 힙 영역에 할당되는 과정을 설명하고 있다.

반면 일반 리스트는 생성할 때부터 요소들이 메모리에 저장된다.

```python
nums = [10, 20, 30]
```

즉,

```text
리스트
→ 10, 20, 30을 처음부터 메모리에 적재

제너레이터
→ 필요할 때 값을 하나씩 생성
```

---

# 4. 제너레이터 표현식

### 1) 제너레이터 표현식

리스트 컴프리헨션과 비슷한 형태로 제너레이터를 만들 수 있다.

원본에서는 다음과 같이 설명한다.

- 리스트 컴프리헨션 → 생성 결과가 처음부터 메모리에 적재
- 리스트 대신 제너레이터 표현식을 사용하면 메모리 소비가 적다.
- 대용량 데이터 처리에 활용할 수 있다.

예시:

```python
gen = (i for i in range(1, 101) if i % 2 == 0)
```

이 표현식은 `1`부터 `100`까지의 숫자 중 짝수만 생성하는 제너레이터를 만든다.

---

### 2) `next()`로 하나씩 조회

```python
next(gen)
```

첫 번째 짝수인

```text
2
```

를 가져온다.

다시 `next(gen)`을 호출하면 다음 값이 나온다.

```python
next(gen)
```

다음 짝수:

```text
4
```

이처럼 필요한 값만 하나씩 가져올 수 있다.

---

### 3) `for`문으로 조회

제너레이터는 `for`문을 이용해서도 순서대로 값을 가져올 수 있다.

```python
for num in gen:
    print(num)
```

제너레이터에 남아 있는 값들을 하나씩 꺼내면서 반복한다.

---

# 5. 이터러블 → 이터레이터 → 제너레이터 연결

전체 개념을 연결하면 다음과 같다.

```text
이터러블(Iterable)
→ 반복 가능한 객체
        ↓
iter(...)
        ↓
이터레이터(Iterator)
→ next()를 통해 요소를 하나씩 조회
        ↓
제너레이터(Generator)
→ 실행을 중단하고 필요할 때 다시 재개
→ 값을 하나씩 생성
```

# 핵심 개념 정리

| 개념 | 핵심 |
|---|---|
| 이터러블 | 반복 가능한 객체 |
| `__iter__()` | 이터레이터를 얻을 수 있도록 하는 기능 |
| 이터레이터 | 요소를 순서대로 하나씩 조회 |
| `iter()` | 이터레이터 생성 |
| `next()` | 다음 요소 조회 |
| 제너레이터 | 실행을 중단하고 필요할 때 다시 재개 |
| `yield` | 값을 반환하면서 함수 실행을 일시 정지 |
| 제너레이터 표현식 | 값을 필요할 때 하나씩 생성 |
| 리스트 | 생성 결과가 처음부터 메모리에 적재 |
| 제너레이터 | 필요한 시점에 값을 생성하여 메모리 소비가 적음 |

---

# 오늘의 핵심 비교

### 리스트

```python
nums = [10, 20, 30]
```

```text
생성 시점
   ↓
10, 20, 30
모두 메모리에 적재
```

### 제너레이터

```python
gen = (i for i in range(1, 101) if i % 2 == 0)
```

```text
필요한 시점

```

따라서

> **대용량 데이터를 처리할 때 제너레이터를 사용하면 메모리를 효율적으로 사용할 수 있다.**

# 오늘의 한 줄 정리

> **이터러블은 반복 가능한 객체이고, 이터레이터는 `next()`를 통해 요소를 하나씩 조회하며, 제너레이터는 `yield`를 이용해 실행을 중단했다가 필요할 때 다시 재개하면서 값을 하나씩 생성한다.**
