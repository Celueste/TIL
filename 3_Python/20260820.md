## 1. 데이터 가공 및 필터링 함수

### map()

`map()`은 반복 가능한 데이터의 모든 요소에 동일한 함수를 적용하여 새로운 형태로 변환할 때 사용한다. 데이터를 하나씩 꺼내어 지정한 규칙으로 일괄 변환하는 역할을 한다.

~~~python
original_prices = [1000, 2000, 3000]

discounted = list(map(lambda x: x * 0.9, original_prices))

print(discounted)
~~~

- `original_prices`에 원래 가격 리스트를 정의한다.
- `lambda x: x * 0.9`를 통해 각 요소에 10% 할인을 적용하는 익명 함수를 선언한다.
- `map()` 결과를 `list()`로 감싸 최종 리스트 형태로 변환한다.

출력 결과:
~~~text
[900.0, 1800.0, 2700.0]
~~~

### filter()

`filter()`는 조건식이 `True`인 데이터만 추출할 때 사용한다.

~~~python
scores = [45, 80, 55, 90, 30]

passing_scores = list(filter(lambda x: x >= 60, scores))

print(passing_scores)
~~~

- `lambda x: x >= 60`을 통해 60점 이상인지 판별하는 조건을 지정한다.
- 조건에 부합하는 데이터만 남겨 리스트 형태로 반환한다.

출력 결과:
~~~text
[80, 90]
~~~

## 2. 반복문과 데이터 결합 함수

### enumerate()

`enumerate()`는 반복문 실행 시 데이터와 함께 해당 요소의 인덱스를 튜플 형태로 전달한다.

~~~python
student_list = ["김철수", "이영희", "박민수"]

for idx, name in enumerate(student_list, start=1):
    print(f"{idx}번 대기자: {name}")
~~~

- 기본적으로 인덱스는 0부터 시작한다.
- `start=1` 옵션을 지정하여 시작 번호를 1로 변경한다.

출력 결과:
~~~text
1번 대기자: 김철수
2번 대기자: 이영희
3번 대기자: 박민수
~~~

### zip()

`zip()`은 여러 개의 반복 가능한 객체를 동일한 인덱스끼리 묶어준다.

~~~python
names = ["김철수", "이영희"]
emails = ["cheolsoo@univ.ac.kr", "younghee@gmail.com"]

for name, email in zip(names, emails):
    print(f"이름: {name} | 이메일: {email}")
~~~

- 리스트들의 길이가 다를 경우 가장 짧은 데이터의 길이에 맞춰 묶이고 남는 요소는 생략된다.

출력 결과:
~~~text
이름: 김철수 | 이메일: cheolsoo@univ.ac.kr
이름: 이영희 | 이메일: younghee@gmail.com
~~~

## 3. 정렬 및 최솟값·최댓값 함수

### sorted()

`sorted()`는 전달받은 데이터를 정렬하여 새로운 리스트를 반환하는 내장 함수이다. 원본 리스트를 직접 변경하지 않는다.

~~~python
scores = [85, 95, 90, 78]

print(sorted(scores))
print(sorted(scores, reverse=True))
~~~

- `sorted(scores)`는 기본값인 오름차순으로 정렬한다.
- `reverse=True` 옵션을 추가하면 내림차순으로 정렬한다.

출력 결과:
~~~text
[78, 85, 90, 95]
[95, 90, 85, 78]
~~~

### min()과 max()

`min()`은 데이터 집합에서 가장 작은 값을, `max()`는 가장 큰 값을 반환한다.

~~~python
scores = [85, 95, 90, 78]

print(min(scores))
print(max(scores))
~~~

출력 결과:
~~~text
78
95
~~~

## 5. 날짜와 시간 처리

### datetime

날짜와 시간을 다룰 때 사용하는 모듈이다.

~~~python
import datetime

now = datetime.datetime.now()
print(now)

today = datetime.date.today()
print(today)
~~~

- `datetime.datetime.now()`는 현재 날짜와 시각 정보를 동시에 가져온다.
- `datetime.date.today()`는 현재 날짜 정보만 가져온다.

### strftime()

날짜 및 시간 객체를 지정한 문자열 서식으로 변환한다.

~~~python
now = datetime.datetime.now()

print(now.strftime("%Y년 %m월 %d일 %H시 %M분 %S초"))
~~~

| 포맷 코드 | 설명 |
|---|---|
| `%Y` | 4자리 연도 |
| `%m` | 2자리 월 |
| `%d` | 2자리 일 |
| `%H` | 24시간 표기 시 |
| `%M` | 분 |
| `%S` | 초 |
| `%A` | 요일 이름 |

### time

코드 실행을 일시 지연시키거나 성능을 측정할 때 사용한다.

~~~python
import time

print("시작")
time.sleep(2)
print("2초 후 실행")
~~~

- `time.sleep(초)`는 전달한 초 단위만큼 프로그램 동작을 멈춘다.

~~~python
import time

start_time = time.perf_counter()

time.sleep(0.5)

end_time = time.perf_counter()
elapsed = end_time - start_time

print(f"소요 시간: {elapsed:.2f}초")
~~~

- `time.perf_counter()`는 고해상도 타이머를 제공하여 경과 시간을 계산할 때 사용한다.

## 6. 수학 연산과 JSON

### math

기본 연산자 이상의 수학 연산 기능을 제공한다.

~~~python
import math

value = 3.141592

print(math.ceil(value))
print(math.floor(value))
print(math.trunc(value))
print(math.fabs(-5.5))
print(math.sqrt(16))
print(math.pi)
~~~

| 함수 및 상수 | 설명 |
|---|---|
| `math.ceil()` | 올림 |
| `math.floor()` | 내림 |
| `math.trunc()` | 소수점 버림 |
| `math.fabs()` | 절댓값(부동소수점) |
| `math.sqrt()` | 제곱근 계산 |
| `math.pi` | 원주율 상수 |

### json

서로 다른 시스템 간에 데이터를 교환할 때 사용하는 표준 데이터 포맷이다.

- **직렬화(Serialization)**: Python 객체를 JSON 포맷 문자열로 변환한다.
- **역직렬화(Deserialization)**: JSON 포맷 문자열을 다시 Python 객체로 복원한다.

~~~python
import json

student_dict = {
    "이름": "홍길동",
    "나이": 21,
    "전공": "컴퓨터공학과"
}

json_text = json.dumps(student_dict, ensure_ascii=False, indent=4)

print(json_text)
print(type(json_text))
~~~

- `json.dumps()`는 Python 객체를 JSON 문자열로 변환한다.
- `ensure_ascii=False`는 한글이 유니코드로 깨지는 현상을 방지한다.
- `indent=4`는 들여쓰기를 적용하여 가독성을 높인다.
- 결과값은 문자열(`str`) 타입이 된다.

~~~python
restored_dict = json.loads(json_text)

print(restored_dict)
print(type(restored_dict))
~~~

- `json.loads()`는 JSON 형태의 문자열을 Python 딕셔너리 객체로 복원한다.

| 함수 | 입력 대상 | 변환 결과 |
|---|---|---|
| `json.dumps()` | Python 객체 | JSON 문자열 |
| `json.loads()` | JSON 문자열 | Python 객체 |
| `json.dump()` | Python 객체 + 파일 포인터 | JSON 파일 저장 |
| `json.load()` | JSON 파일 포인터 | Python 객체 |

## 7. 난수와 시스템 정보

### random

무작위 값을 생성하거나 리스트의 순서를 섞을 때 사용한다.

~~~python
import random

print(random.randint(1, 45))
print(random.random())

fruits = ["사과", "바나나", "오렌지", "포도"]
print(random.choice(fruits))
~~~

| 함수 | 역할 |
|---|---|
| `random.randint(a, b)` | a부터 b까지의 정수 중 하나를 무작위 선택 |
| `random.random()` | 0.0 이상 1.0 미만의 무작위 실수 생성 |
| `random.choice()` | 시퀀스 데이터에서 무작위로 하나의 요소 선택 |
| `random.shuffle()` | 리스트의 요소를 무작위로 섞음(원본 변경) |
| `random.sample()` | 중복 없이 지정한 개수만큼 무작위 추출 |

### os

운영체제 기능과 파일 경로 조작을 수행한다.

~~~python
import os

print(os.getcwd())
print(os.listdir("."))
print(os.path.exists("test.txt"))
~~~

- `os.getcwd()`는 현재 작업 경로를 반환한다.
- `os.listdir()`은 전달한 경로에 존재하는 파일과 폴더 목록을 리스트로 반환한다.
- `os.path.exists()`는 해당 경로 또는 파일의 존재 여부를 불리언 값으로 확인한다.

### sys

파이썬 인터프리터의 동작 환경을 제어하거나 정보를 조회한다.

~~~python
import sys

print(sys.version)
print(sys.argv)
sys.exit()
~~~

- `sys.version`은 설치된 파이썬 버전 정보를 출력한다.
- `sys.argv`는 명령줄(터미널)에서 실행 시 전달된 인수 목록을 담고 있다.
- `sys.exit()`은 실행 중인 프로세스를 즉시 종료한다.

## 8. 오류와 해결

### 1) 문자열 리스트에 sum() 사용 시 TypeError 발생

#### 오류 내용
문자열 요소로 이루어진 리스트에 `sum()`을 호출할 경우 예외가 발생한다.

~~~text
TypeError: unsupported operand type(s) for +: 'int' and 'str'
~~~

#### 오류 원인
`sum()`은 숫자 데이터의 합계를 구하기 위해 설계된 함수이며 기본 시작값이 숫자 0으로 설정되어 있어 문자열과 산술 덧셈을 수행할 수 없다.

#### 수정 코드
~~~python
words = ["Python", "공부", "중"]

# sum(words) 대신 join() 사용
print(" ".join(words))
~~~

#### 해결 방법 및 기억할 점
문자열 요소를 병합할 때는 문자열 메서드인 `join()`을 사용한다. `sum()`은 숫자 연산 전용으로만 사용해야 한다.

### 2) map()과 filter()의 결과 객체 출력 문제

#### 오류 내용
`map()` 또는 `filter()`의 결과를 바로 출력하면 데이터 내용 대신 이터레이터 객체 정보가 표시된다.

~~~text
<map object at 0x...>
<filter object at 0x...>
~~~

#### 오류 원인
해당 함수들은 메모리 효율을 위해 결과를 즉시 연산하지 않고 이터레이터 객체 형태로 지연 평가를 수행한다.

#### 해결 방법 및 기억할 점
반복문에서 직접 순회하거나, 눈으로 확인하려면 `list()` 함수로 명시적 형변환을 수행해야 한다.

~~~python
numbers = [1, 2, 3, 4]

result_map = list(map(lambda x: x * 2, numbers))
result_filter = list(filter(lambda x: x > 2, numbers))

print(result_map)
print(result_filter)
~~~

### 3) all()과 any()의 빈 리스트 판별 혼선

#### 원인 및 동작 원리
`all()`과 `any()`에 빈 이터러블을 전달할 경우 논리적 기본값에 따라 결과가 다르게 반환된다.

~~~python
print(all([]))
print(any([]))
~~~

출력 결과:
~~~text
True
False
~~~

- `all([])`은 집합 내에 `False`인 요소가 하나도 없기 때문에 `True`를 반환한다(공허 참).
- `any([])`는 집합 내에 `True`인 요소가 하나도 존재하지 않기 때문에 `False`를 반환한다.

| `datetime` | 날짜/시각 표현 | 연, 월, 일, 시, 분, 초 단위 계산 |
| `time` | 실행 제어 | 대기 시간 지정 및 수행 시간 측정 |
| `math` | 수치 계산 | 올림, 내림, 제곱근 등 수학 공식 지원 |
| `json` | 데이터 변환 | 파이썬 객체와 JSON 포맷 간 상호 교환 |
| `random` | 무작위 처리 | 난수 생성 및 무작위 추출/섞기 |
| `os` | 환경/경로 | 디렉토리 및 파일 존재 여부 확인 |
| `sys` | 시스템 환경 | 인터프리터 제어 및 인자 전달 |

### map() vs filter()

~~~python
numbers = [1, 2, 3, 4, 5]

result_map = list(map(lambda x: x * 2, numbers))
result_filter = list(filter(lambda x: x > 3, numbers))
~~~

- `map()`은 전체 데이터의 개수를 유지한 채 값을 변환한다.
- `filter()`는 조건에 맞는 데이터만 남겨 전체 개수를 축소한다.

### dumps() vs loads()

- `json.dumps()`: Python 객체를 **JSON 문자열**로 변환한다.
- `json.loads()`: **JSON 문자열**을 Python 객체로 복원한다.
- 함수명 뒤의 `s`는 문자열(String)을 의미한다고 연계하여 기억한다.

## 10. 전체 흐름 정리

~~~text
데이터 처리 작업
       │
       ├─ 전체 값의 변환이 필요한 경우 ───────> map()
       │
       ├─ 조건에 따른 선별이 필요한 경우 ─────> filter()
       │
       ├─ 반복 순서 번호가 필요한 경우 ───────> enumerate()
       │
       ├─ 여러 데이터를 묶어야 하는 경우 ────> zip()
       │
       └─ 순서 정렬 또는 극값 확인 ───────────> sorted() / min() / max()
~~~

## 11. 핵심 정리

### 핵심 코드

~~~python
# 데이터 가공 및 필터링
doubled = list(map(lambda x: x * 2, [1, 2, 3]))
evens = list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4]))

# JSON 직렬화 및 역직렬화
json_data = json.dumps(data_dict, ensure_ascii=False)
python_obj = json.loads(json_data)
~~~

### 핵심 개념

- 내장 함수인 `map()`과 `filter()`는 이터레이터를 반환하므로 즉시 확인하려면 `list()` 변환이 필요하다.
- `sorted()`는 원본을 변경하지 않고 새롭게 정렬된 리스트를 생성한다.
- 문자열 리스트의 결합은 `sum()`이 아닌 `join()` 메서드를 사용해야 한다.
- 표준 라이브러리는 별도 설치 없이 `import` 문으로 즉시 사용 가능하다.

## 12. 느낀 점

이번 학습을 통해 Python에는 데이터를 가공하고 다루기 위한 유용한 내장 함수와 표준 라이브러리가 체계적으로 마련되어 있다는 점을 정리했다. 특히 `map()`과 `filter()`를 활용하면 복잡한 반복문 없이도 간결한 코드로 데이터를 변환하고 추출할 수 있다는 점이 인상적이었다. 또한 외부 시스템과의 데이터 연동에 필수적인 `json`, 시스템을 제어하는 `os`와 `sys`, 시간 처리를 담당하는 `datetime` 모듈의 기본 역할을 명확히 구분할 수 있게 되었다. 단순 암기에 그치지 않고 처리할 데이터의 특성과 목적에 맞춰 적절한 도구를 선택하는 연습을 꾸준히 이어가야겠다고 생각했다.
