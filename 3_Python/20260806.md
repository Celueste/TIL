# Python 개발 환경 및 기본 문법
### 1) 가상환경의 필요성
1. 시스템 전역 설치의 문제
    - 전역설치: 내 컴퓨터 전체(시스템 전역)에 환경을 구축하는 방식
    - 프로젝트마다 필요한 라이브러리 버전이 달라 의존성 충돌이 발생할 수 있음
    - Python 버전이 달라야 하는 프로젝트를 동시에 관리하기 어려움
    - 한 프로젝트의 패키지 변경이 다른 프로젝트에 영향을 줄 수 있음

2. 가상환경을 사용하는 이유
   - 프로젝트마다 필요한 Python 버전을 다르게 설정할 수 있음
   - 프로젝트별 라이브러리 버전을 독립적으로 관리할 수 있음
   - 라이브러리 간 의존성 충돌을 방지할 수 있음
<br>
<br>

### 2) 가상환경 구축 방식
1.  venv
    ```
    python -m venv .venv
    ```
    - Python에 기본으로 포함된 가상환경 도구
    - 별도의 설치가 필요하지 않음
    - 간단한 프로젝트에서 사용하기 좋음

2. Anaconda
    - Python과 다양한 라이브러리를 함께 관리할 수 있음
    - 가상환경 및 패키지 관리 기능 제공
    - 데이터 분석 및 머신러닝 환경에서 많이 사용

3. uv
    - Rust 기반으로 만들어져 빠른 패키지 및 프로젝트 관리가 가능
    - 프로젝트 단위로 환경을 관리
    - 의존성 관리가 편리함
    - Python 버전과 패키지 버전을 함께 관리할 수 있음
<br>
<br>

### 3) 버전 표기법
1. 일반적으로 `Major.Minor.Patch` 형태로 버전을 표시함.  
    예:
        ```
        0.12.2
        ```
2. Major 버전

        ```
        0.12.2
        ↑
        Major
        ```  
    - 큰 변경이 발생하는 버전
    - 이전 버전과 호환되지 않을 수 있음

3. Minor 버전

        ```
        0.12.2
          ↑
        Minor
        ```
    - 새로운 기능 추가
    - 기존 기능을 유지하면서 작은 변경이 이루어짐
    - 일반적으로 하위 버전과의 호환성을 유지

4. Patch 버전

        ```
        0.12.2
             ↑
           Patch
        ```
    - 버그 수정
    - 오류 및 코드 개선
    - 기존 기능을 유지하면서 문제를 해결

※ Python이나 일부 라이브러리는 버전에 따라 호환성 문제가 발생할 수 있으므로 버전 관리가 중요함.
<br>
<br>

### 4) pyproject.toml
- uv init 명령어로 프로젝트를 초기화하면 생성되는 가장 표준적이고 직관적인 명세서 구조
- 프로젝트의 Python 버전과 의존성 등의 정보를 관리하는 파일
- 프로젝트 환경 정보를 공유할 때 활용
- 다른 환경에서도 동일한 프로젝트 환경을 구성하는 데 사용
<br>
<br>


# Python 기본 문법
### 1) 변수
1. 변수란? 값을 가진 공간의 주소를 가진 이름표  
예:
   ```python
   name = "Alice"
   age = 20
   ```
    - `name` → `"Alice"`라는 값을 가리키는 이름
    - `age` → `20`이라는 값을 가리키는 이름
<br>
<br>

2. 변수명 작성 규칙
    - 변수명에는 다음을 사용할 수 있음.
        - 영문 대문자
        - 영문 소문자
        - 숫자
        - `_`

    - 다음을 사용할 수 없음
        - 숫자로 시작할 수 없음
        - 공백을 사용할 수 없음
        - 예약어를 사용할 수 없음
        ```
        1name = "Alice"
        user name = "Alice"
        if = 10
        for = 20
        True = 30
        ```
<br>
<br>

3. 변수명 작성 권장 사항
    - 의미 있는 이름 사용
        ```
        age = 20
        user_name = "Kim"
        total_price = 10000
        ```
    - 의미를 알기 어려운 이름은 지양:
        ```
        a = 20
        b = "Kim"
        c = 10000
        ```

    - 여러 단어는 `_`로 구분

        ```
        user_name = "Kim"
        total_price = 10000
        student_number = 10
        ```
<br>
<br>

### 2) 동적 타이핑
1. 정의:  
    변수의 자료형을 미리 선언하지 않고, 실행 시 변수에 할당된 값에 따라 자료형이 결정되는 방식

2. 특징
    - Python은 동적 타이핑 언어
    - 자료형을 직접 선언하지 않아도 됨
    - 하나의 변수에 다른 자료형의 값을 할당할 수 있음

3. 예시
    ```
    value = 10
    print(type(value))  # int

    value = "Hello"
    print(type(value))  # str

    value = 3.14
    print(type(value))  # float
    ```

4. 사용하는 이유
    - 자료형을 직접 선언하지 않아 코드를 간결하게 작성할 수 있음
    - 상황에 따라 다양한 자료형의 값을 유연하게 사용할 수 있음
