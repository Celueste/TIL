# 1. 함수의 기본 정의와 작동 방식

### 1) 함수

> 특정 작업을 하나의 코드 블록으로 묶어 필요할 때마다 재사용할 수 있도록 만든 것이다.

함수를 사용하는 가장 큰 목적은

> **코드의 재활용**

이다.

같은 작업을 여러 번 해야 한다면 코드를 매번 반복해서 작성하는 대신 함수를 만들어두고 호출하면 된다.

---

### 2) 함수 정의

기본적인 함수의 형태는 다음과 같다.

```python
def 함수이름(매개변수, ...):
    # 처리 부분

    return 반환값
```

예시:

```python
def calc(x):
    y = x * 2 + 1

    return y
```

위 함수는 전달받은 `x`에 `2`를 곱하고 `1`을 더한 값을 반환한다.

---

### 3) 함수 호출

함수를 정의했다고 바로 실행되는 것은 아니다.

함수를 실행하려면 함수 이름 뒤에 `()`를 붙여 호출해야 한다.

```python
calc(10)
```

함수를 호출하면

```text
10 → 함수에 전달
   ↓
x * 2 + 1
   ↓
21 반환
```

이 된다.

반환된 값을 변수에 저장할 수도 있다.

```python
result = calc(10)

print(result)
```

결과:

```text
21
```

---

# 2. `return`의 역할

`return`은 크게 두 가지 역할을 한다.

### ① 반환값을 전달

```python
def calc(x):
    y = x * 2 + 1

    return y
```

`return y`를 통해 계산된 `y`를 함수 밖으로 전달한다.

---

### ② 함수의 종료

`return`이 실행되면 해당 함수는 즉시 종료된다.

예를 들어,

```python
def add(num):
    if num == 999:
        print("종료")
        return

    result = num ** 2

    return result
```

`999`가 입력되면

```text
종료
```

를 출력하고 `return`을 만나 함수가 종료된다.

따라서 아래 코드는 실행되지 않는다.

```python
result = num ** 2
```

즉,

> **return = 값을 돌려주거나, 함수 실행을 끝낸다.**

# 3. 함수 이름을 다른 변수에 저장하기

파이썬에서는 함수를 변수에 저장할 수도 있다.

```python
def calc(x):
    y = x * 2 + 1

    return y
```

이 함수를 다른 변수에 저장할 수 있다.

```python
calc2 = calc
```

이제 `calc2`를 통해서도 같은 함수를 호출할 수 있다.

```python
calc2(20)
```

결과:

```text
41
```

즉,

```python
calc2 = calc
```

는 새로운 함수를 만드는 것이 아니라

> `calc2`가 `calc` 함수를 가리키도록 하는 것이다.

# 4. 매개변수(Parameter)와 인수(Argument)

함수에 값을 전달할 때 자주 등장하는 개념이다.

### 매개변수(Parameter)

> 함수 정의 부분에서 입력값을 받아주는 변수

```python
def add(num1, num2):
    return num1 + num2
```

여기서

```text
num1
num2
```

가 매개변수(Parameter)이다.

---

### 인수(Argument)

> 함수를 호출할 때 실제로 전달하는 값

```python
add(10, 20)
```

여기서

```text
10
20
```

이 인수(Argument)이다.

---

### 쉽게 구분하기

```python
def add(num1, num2):
    return num1 + num2
```

→ `num1`, `num2` = **매개변수**

```python
add(10, 20)
```

→ `10`, `20` = **인수**

기억법:

> **정의할 때 = 매개변수**  
> **호출할 때 = 인수**

---

# 5. 위치 인수와 키워드 인수

함수에 값을 전달하는 방법에는 대표적으로

- 위치 인수(Positional Arguments)
- 키워드 인수(Keyword Arguments)

가 있다.

---

### 1) 위치 인수

> 매개변수의 순서에 맞춰 값을 전달하는 방법

```python
def add(num1, num2):
    return num1 + num2
```

호출:

```python
add(10, 20)
```

순서대로

```text
num1 = 10
num2 = 20
```

이 된다.

따라서 위치 인수에서는 **순서가 중요하다.**

---

### 2) 키워드 인수

> 매개변수 이름을 직접 지정하여 값을 전달하는 방법

```python
add(num1=10, num2=20)
```

이렇게 매개변수 이름을 직접 지정할 수 있다.

키워드 인수는 이름을 기준으로 연결되기 때문에 순서는 중요하지 않다.

```python
add(num2=20, num1=10)
```

도 동일하게 동작한다.

---

### 3) 위치 인수와 키워드 인수를 함께 사용

두 가지를 함께 사용할 수도 있다.

```python
def add(num1, num2, name, mobile):
    return f"{num1+num2}, {name=}, {mobile=}"
```

예:

```python
add(10, 20, mobile="010-0000-0000", name="김영희")
```

결과:

```text
30, name='김영희', mobile='010-0000-0000'
```

---

### 4) 주의할 점

**키워드 인수 뒤에 위치 인수를 사용할 수 없다.**

잘못된 예:

```python
add(mobile="010-0000-0000", 10, 20, name="김영희")
```

오류:

```text
SyntaxError:
positional argument follows keyword argument
```

즉,

> **위치 인수 → 키워드 인수**

순서는 가능하지만,

> **키워드 인수 → 위치 인수**

순서는 불가능하다.

---

# 6. 기본값 매개변수(Default Parameter)

> 함수 호출 시 값을 전달하지 않아도 기본적으로 사용할 값을 미리 설정하는 방법

예를 들어,

```python
def add(num1, num2, name, mobile="010"):
    return f"{num1+num2}, {name=}, {mobile=}"
```

`mobile`에 값을 전달하지 않으면 자동으로 `"010"`이 사용된다.

```python
add(10, 20, "김영희")
```

결과:

```text
30, name='김영희', mobile='010'
```

반대로 값을 전달하면 전달한 값이 사용된다.

```python
add(10, 20, "김영희", "010-0000-0000")
```

---

### 기본값 매개변수의 중요한 규칙

**기본값이 있는 매개변수는 오른쪽 끝부터 순서대로 정의해야 한다.**

예를 들어 다음과 같은 형태는 문제가 된다.

```python
def add(num1, num2, name=None, mobile):
    ...
```

기본값이 있는 `name` 뒤에 기본값이 없는 `mobile`이 있기 때문이다.

따라서 다음처럼 작성해야 한다.

```python
def add(num1, num2, mobile, name=None):
    return f"{num1+num2}, {name=}, {mobile=}"
```

# 7. 가변 인수 `*args`

> 함수에 전달되는 위치 인수의 개수를 정하지 않고 여러 개 받을 수 있도록 하는 방법

일반적인 함수는 매개변수 개수가 정해져 있다.

```python
def add(num1, num2, num3):
    return num1 + num2 + num3
```

따라서 다음과 같이 정해진 개수만큼 전달해야 한다.

```python
add(10, 20, 30)
```

하지만 `*args`를 사용하면 개수에 제한 없이 위치 인수를 받을 수 있다.

```python
def add(*nums):
    total = 0

    for num in nums:
        total += num

    return total
```

이제 다음과 같이 사용할 수 있다.

```python
add(10, 20)
```

```python
add(10, 20, 30)
```

```python
add(10, 20, 30, 40)
```

각각 전달된 모든 숫자를 더한다.

---

### `*args`의 특징

```python
def add(*nums):
    ...
```

`nums`에는 여러 개의 위치 인수가 들어간다.

즉,

```text
add(10, 20)
→ nums = (10, 20)

add(10, 20, 30)
→ nums = (10, 20, 30)

add(10, 20, 30, 40)
→ nums = (10, 20, 30, 40)
```

그리고 `*args`는

> **위치 인수용 가변 인수**

이다.

---

# 8. 키워드 가변 인수 `**kwargs`

> 개수가 정해지지 않은 키워드 인수를 여러 개 받을 때 사용한다.

예:

```python
def print_user_info(**info):
    print(info)
```

호출:

```python
print_user_info(name="김철수", age=20)
```

결과:

```python
{'name': '김철수', 'age': 20}
```

즉,

```text
name="김철수"
age=20
```

과 같이 키워드 형태로 전달된 값들이 `info`에 저장된다.

---

### `**kwargs`를 일반 매개변수와 함께 사용

```python
def print_user_info(name, age, **info):
    print("name:", name)
    print("age:", age)
    print(info)
```

호출:

```python
print_user_info(
    "김",
    0,
    mobile="010-0000-0000"
)
```

결과:

```text
name: 김
age: 0
{'mobile': '010-0000-0000'}
```

---

# 9. `*args`와 `**kwargs` 함께 사용

두 가지를 함께 사용할 수도 있다.

```python
def print_user_info(name, age, *args, **kwargs):
    print("name:", name)
    print("age:", age)
    print(args)
    print(kwargs)
```

호출:

```python
print_user_info(
    "김",
    0,
    "a",
    20,
    mobile="010-0000-0000"
)
```

결과:

```text
name: 김
age: 0
('a', 20)
{'mobile': '010-0000-0000'}
```

정리하면,

```text
일반 매개변수
    ↓
name, age

*args
    ↓
추가 위치 인수

**kwargs
    ↓
추가 키워드 인수
```

# 10. `return`으로 여러 데이터 반환하기

함수에서 여러 개의 값을 반환할 수도 있다.

```python
def calc(num1, num2):
    return (
        num1 + num2,
        num1 * num2,
        num1 - num2,
        num1 / num2
    )
```

호출:

```python
a, b, c, d = calc(10, 2)
```

각각 다음과 같이 저장된다.

```text
a = 12
b = 20
c = 8
d = 5.0
```

출력:

```python
print(a, b, c, d)
```

결과:

```text
12 20 8 5.0
```

즉,

> `return`에서 여러 값을 반환하면 여러 변수에 나누어 받을 수 있다.

# 11. 함수의 메모리 생애주기

### [심화] Heap vs Call Stack

함수가 실행될 때는 함수 실행과 관련된 정보가 메모리에 관리된다.

원본에서는 `sys._getframe()`을 이용해 현재 실행 중인 함수의 프레임과 부모 함수의 프레임을 확인했다.

예시 구조:

```python
import sys

def outer_func():
    x = 10

    def inner_func():
        y = 20

        frame = sys._getframe()

        print(f"현재 실행 함수: {frame.f_code.co_name}")
        print(f"현재 지역 변수: {frame.f_locals}")

        parent_frame = frame.f_back

        print(f"부모 함수 이름: {parent_frame.f_code.co_name}")
        print(f"부모 함수의 지역 변수: {parent_frame.f_locals}")

    inner_func()

outer_func()
```

실행 흐름은 다음과 같다.

```text
outer_func()
    ↓
inner_func()
    ↓
현재 실행 중인 inner_func의 frame 확인
    ↓
frame.f_back
    ↓
부모 함수인 outer_func의 frame 확인
```

---

### 주요 개념

#### `frame`

현재 실행 중인 함수의 실행 프레임을 나타낸다.

#### `f_locals`

현재 프레임의 지역 변수를 확인할 수 있다.

```python
frame.f_locals
```

#### `f_globals`

현재 프레임의 전역 스코프를 확인할 수 있다.

#### `f_back`

현재 프레임을 호출한 부모 프레임으로 이동할 수 있다.

즉,

```text
inner_func frame
       ↓
   f_back
       ↓
outer_func frame
```

# 12. 함수 핵심 정리

### 함수 기본

```text
def
→ 함수 정의

함수이름()
→ 함수 호출

return
→ 값을 반환하거나 함수 종료
```

---

### 매개변수와 인수

```text
매개변수(Parameter)
→ 함수 정의에서 값을 받는 변수

인수(Argument)
→ 함수 호출 시 전달하는 실제 값
```

---

### 인수 전달 방식

```text
위치 인수
→ 순서가 중요

키워드 인수
→ 매개변수 이름을 지정
→ 순서는 중요하지 않음

주의
→ 위치 인수 뒤에 키워드 인수 사용
→ 키워드 인수 뒤에 위치 인수 사용 불가
```

---

### 기본값

```python
def add(num1, num2, name=None):
    ...
```

→ 값을 전달하지 않으면 `None`을 기본값으로 사용한다.

중요:

> **기본값이 있는 매개변수는 오른쪽에 배치한다.**

---

### 가변 인수

```text
*args
→ 여러 개의 위치 인수

**kwargs
→ 여러 개의 키워드 인수
```

기억법:

```text
*args
→ 값이 여러 개

**kwargs
→ 이름=값 형태가 여러 개
```

---

### 복수 반환

```python
return a, b, c
```

→ 여러 값을 반환할 수 있다.

```python
x, y, z = 함수()
```

→ 반환된 값을 각각의 변수에 나누어 받을 수 있다.

---

# 오늘의 한 줄 정리

> **함수는 반복해서 사용할 코드를 하나의 기능으로 묶어 재사용하는 것이며, 매개변수로 입력을 받고 `return`으로 결과를 반환한다. `*args`와 `**kwargs`를 이용하면 다양한 개수의 인수를 유연하게 받을 수 있다.**
