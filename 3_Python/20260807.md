# 1. 기본 자료형
### 1) 정수와 실수
- 정수형(int): 소수점이 없는 숫자를 표현하는 자료형
- 실수형(float): 소수점이 있는 숫자를 표현하는 자료형
    ```
    num1 = 10
    num2 = 3.14

    print(type(num1))  # <class 'int'>
    print(type(num2))  # <class 'float'>
    ```
<br>
<br>

### 2) 문자열 자료형

- 문자열(str): 문자나 문자열을 표현하는 자료형
- 작은따옴표(') 또는 큰따옴표(")를 사용하여 표현
    ```
    name = "Python"
    message = "Hello"

    print(name)
    print(message)
    ```
<br>
<br>

### 3) 논리형 자료형
- 논리형(bool): 참과 거짓을 표현하는 자료형
- True와 False 두 가지 값을 가짐
    ```
    is_student = True
    is_adult = False

    print(type(is_student))  # <class 'bool'>
    ```
<br>
<br>

### 4) 명시적 형변환
- 개발자가 직접 자료형을 변환하는 것
- int(), float(), str(), bool() 등의 함수를 사용
    ```
    num = "10"

    result = int(num)

    print(result)        # 10
    print(type(result))  # <class 'int'>
    ```
<br>
<br>

# 2. 형변환
### 1) 명시적 형변환
- 개발자가 직접 자료형을 변환하는 방식
- 변환 함수를 사용하여 원하는 자료형으로 변환
    ```
    num = "100"
    num = int(num)
    print(num + 10)  # 110
    ```
<br>
<br>

### 2) 묵시적 형변환
- Python이 연산 과정에서 자동으로 자료형을 변환하는 방식
- 주로 서로 다른 숫자형을 연산할 때 발생
    ```
    num1 = 10       # int
    num2 = 3.14     # float

    result = num1 + num2

    print(result)        # 13.14
    print(type(result))  # <class 'float'>
    ```
- int와 float를 연산하면 float로 변환됨
<br>
<br>

# 3. 연산자
### 1) 산술 연산자
- 숫자를 계산할 때 사용하는 연산자

    | 연산자 | 의미 | 예시 |
    |---|---|---|
    | + | 덧셈 | 10 + 3 |
    | - | 뺄셈 | 10 - 3 |
    | * | 곱셈 | 10 * 3 |
    | / | 나눗셈 | 10 / 3 |
    | // | 몫 | 10 // 3 |
    | % | 나머지 | 10 % 3 |
    | ** | 거듭제곱 | 10 ** 3 |
<br>
<br>

### 2) 복합 대입 연산자

- 변수의 값을 연산한 후 결과를 다시 변수에 대입하는 연산자
- 기존 변수의 값을 기준으로 연산하고 결과를 저장함
    ```
    num = 10

    num += 5
    print(num)  # 15

    num -= 3
    print(num)  # 12

    num *= 2
    print(num)  # 24

    num /= 4
    print(num)  # 6.0
    ```
<br>
<br>

### 3) 비교 연산자

- 두 값을 비교하여 True 또는 False를 반환

    | 연산자 | 의미 |
    |---|---|
    | == | 같다 |
    | != | 같지 않다 |
    | > | 크다 |
    | < | 작다 |
    | >= | 크거나 같다 |
    | <= | 작거나 같다 |
<br>
<br>

### 4) 논리 연산자

- 여러 조건을 조합하거나 조건의 참과 거짓을 판단할 때 사용

    | 연산자 | 의미 |
    |---|---|
    | and | 모든 조건이 참이면 True |
    | or | 하나라도 참이면 True |
    | not | 논리값을 반대로 변경 |
    ```
    age = 20
    is_student = True

    print(age >= 20 and is_student)  # True
    print(age < 20 or is_student)    # True
    print(not is_student)            # False
    ```
<br>
<br>

### 5) 연산자 우선순위
- 여러 연산자가 함께 사용될 경우 정해진 순서에 따라 연산됨
- 괄호를 사용하면 원하는 연산을 먼저 수행할 수 있음
- 곱셈이 덧셈보다 먼저 계산됨.
- 괄호를 사용하면 덧셈이 먼저 계산됨.
<br>
<br>

# 4. 문자열 형식화
문자열 안에 변수나 값을 넣어 원하는 형태로 출력하는 방법
### 1) % 연산자 방식

- % 연산자를 사용하여 문자열에 값을 삽입하는 방식
- 오래된 문자열 형식화 방법
    ```
    name = "Python"
    age = 10

    print("이름: %s, 나이: %d" % (name, age))
    ```
- %s → 문자열,
- %d → 정수

### 2) str.format() 메서드 방식
- format() 메서드를 사용하여 문자열에 값을 삽입하는 방식
    ```
    name = "Python"
    age = 10

    print("이름: {}, 나이: {}".format(name, age))
    ```
    변수명을 직접 지정할 수도 있음.

    ```
    name = "Python"
    age = 10

    print("이름: {name}, 나이: {age}".format(name=name, age=age))
    ```

### 3) f-string 방식
- 문자열 앞에 f를 붙이고 {} 안에 변수나 표현식을 작성
- Python에서 간결하고 직관적인 문자열 형식화 방법
    ```
    name = "Python"
    age = 10

    print(f"이름: {name}, 나이: {age}")
    ```

    표현식도 사용할 수 있음.

    ```
    num1 = 10
    num2 = 20

    print(f"{num1} + {num2} = {num1 + num2}")
    ```
