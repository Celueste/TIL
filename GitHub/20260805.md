        - Main/master  <-완성본
                git branch -d 브랜치명
                git branch -D 브랜치명  <-강제
                git branch -m 브랜치명
                git branch -M 브랜치명  <-강제

    # 병합: git merge 병합할 브랜치
            ① Fast forword
                main O O
                order    O △ △
                =>   O O △ △

            ② 3-way
                Main O O ㅁ
                Order   O △ △
                =>
                Main O O ㅁ ◆(new)
                Order   O △ △

            ③ Rebase: git rebase main
                Main O O ㅁ ㅁ
                Order   O △ △
                =>
                Main O O ㅁ △ △

        * 병합시 브랜치에 충돌이 발생한다면,
            1) 충돌 해결 후:  git add .   리베이스 진행 rebase 
                            --continue
            2) 만약 해결 x : --skip (현재 해결 건너뛰기)
                            --abort (rebase 취소)
