# 1. 핵심 개념

## MLP(Multi Layer Perceptron)

MLP는 **Multi Layer Perceptron(다층 퍼셉트론)**의 줄임말이다.

쉽게 말하면 여러 개의 층으로 이루어진 기본적인 인공신경망 구조이다.

```text
입력층
  ↓
은닉층
  ↓
출력층
```

Fashion MNIST 모델에서는 다음과 같은 구조를 사용했다.

```text
28 × 28 이미지
      ↓
Flatten
      ↓
784개 숫자
      ↓
Linear(784 → 128)
      ↓
ReLU
      ↓
Dropout
      ↓
Linear(128 → 10)
      ↓
의류 10개 카테고리
```

---

## 가중치(Weight)

가중치는 입력 데이터가 결과에 얼마나 영향을 주는지를 결정하는 값이다.

처음에는 보통 무작위 값으로 시작한다.

```text
무작위 가중치
      ↓
예측
      ↓
Loss 계산
      ↓
Gradient 계산
      ↓
Optimizer
      ↓
가중치 수정
```

학습을 반복하면서 가중치가 점점 더 좋은 값으로 변경된다.

---

## Loss(손실)

Loss는 모델의 예측과 실제 정답이 얼마나 다른지를 나타내는 값이다.

```text
예측과 정답이 비슷함
→ Loss 작음

예측과 정답이 많이 다름
→ Loss 큼
```

모델 학습의 목표는 **Loss를 줄이는 것**이다.

---

## Gradient(기울기)

Gradient는 Loss를 줄이기 위해 가중치를 어느 방향으로 수정해야 하는지 알려주는 값이다.

쉽게 말하면:

> **"가중치를 이쪽 방향으로 수정하면 Loss가 줄어들 것 같아!"라고 알려주는 힌트**

라고 생각하면 된다.

---

## Optimizer(옵티마이저)

Optimizer는 Gradient를 이용해서 실제로 가중치를 수정한다.

```text
Gradient
   ↓
Optimizer
   ↓
가중치 업데이트
```

대표적인 Optimizer에는 다음과 같은 것들이 있다.

* SGD
* Adam

Gradient가 **어느 방향으로 수정할지 알려주는 값**이라면,

Optimizer는 **그 Gradient를 이용해 실제 가중치를 수정하는 방법**이다.

---

## 역전파(Backpropagation)

역전파는 Loss를 기준으로 각 가중치가 얼마나 수정되어야 하는지 계산하는 과정이다.

```python
loss.backward()
# Loss를 기준으로 각 가중치의 Gradient를 계산
```

→ `loss.backward()`는 **역전파를 수행해서 각 파라미터의 Gradient를 계산한다.**

전체 학습 과정은 다음과 같다.

```text
입력 데이터
    ↓
순전파
    ↓
예측
    ↓
Loss 계산
    ↓
역전파
    ↓
Gradient 계산
    ↓
Optimizer
    ↓
가중치 수정
```

## Flatten

```python

```

→ 2차원 이미지를 1차원으로 펼치는 Layer를 만든다.

Fashion MNIST 이미지는:

```text

```

```text

```



→ 784개의 입력값을 받아서 128개의 값으로 변환하는 **Linear Layer**를 만든다.

```text
      ↓
Linear
      ↓
128개 출력값
```

---

## ReLU

```python

```

→ ReLU 활성화 함수를 사용한다.

ReLU는:

```text
음수 → 0
양수 → 그대로
```

변환한다.

예:

```text
[-3, -1, 2, 5]

↓ ReLU

[0, 0, 2, 5]
```

ReLU는 신경망에 **비선형성**을 추가해 복잡한 패턴을 학습할 수 있도록 도와준다.

---

## Dropout

```python
self.dropout = nn.Dropout(p=0.2)
```

→ 학습할 때 일부 뉴런을 랜덤하게 끄는 Dropout Layer를 만든다.

```python
p=0.2
```

→ 학습할 때 약 20%의 뉴런을 랜덤하게 사용하지 않는다.

목적:

```text
특정 뉴런에만 지나치게 의존
        ↓
과대적합 가능성 증가

Dropout
        ↓
일부 뉴런을 랜덤하게 끔
        ↓
특정 뉴런에만 의존하는 것을 줄임
```

---

# 9. 전체 MLP 모델 코드

```python
import torch.nn as nn


class AdvancedFashionClassifier(nn.Module):

    def __init__(self):

        super().__init__()
        # nn.Module의 기본 기능 초기화


        self.flatten = nn.Flatten()
        # 28 × 28 이미지를
        # 784개의 숫자로 펼침


        self.hidden_layer = nn.Linear(784, 128)
        # 784개의 입력값
        # ↓
        # 128개의 뉴런


        self.relu = nn.ReLU()
        # 음수는 0으로 변경


        self.dropout = nn.Dropout(p=0.2)
        # 학습 중 일부 뉴런을 랜덤하게 끔
        # 과대적합 방지에 도움


        self.output_layer = nn.Linear(128, 10)
        # 128개의 값
        # ↓
        # 10개 클래스 점수


    def forward(self, x):

        out = self.flatten(x)
        # 28 × 28
        # ↓
        # 784


        out = self.hidden_layer(out)
        # 784
        # ↓
        # 128


        out = self.relu(out)
        # 음수 제거
        # 비선형성 추가


        out = self.dropout(out)
        # 일부 뉴런을 랜덤하게 끔


        out = self.output_layer(out)
        # 128
        # ↓
        # 10개 클래스 점수


        return out
        # 최종 결과 반환
```

전체 흐름:

```text
이미지
 ↓
Flatten
 ↓
784
 ↓
Linear
 ↓
128
 ↓
ReLU
 ↓
Dropout
 ↓
Linear
 ↓
10개 클래스
```

# 21. RNN과 시계열 데이터

시계열 데이터는 **시간이나 순서가 중요한 데이터**이다.

예:

```text
월요일 → 화요일 → 수요일
```

문장도 순서가 중요하다.

```text
나는 → 밥을 → 먹었다
```

RNN은 이런 순서가 있는 데이터를 처리하는 신경망이다.

---

## Time Step

```text
나는 밥을 먹었다
```

RNN은 데이터를 하나씩 읽는다.

```text
Time Step 1 → 나는

Time Step 2 → 밥을

Time Step 3 → 먹었다
```

→ **Time Step은 데이터를 순서대로 하나씩 처리하는 시점**이다.

---

## Hidden State

Hidden State는 이전까지 읽은 정보를 가지고 있는 값이다.

```text
나는
 ↓
Hidden State

밥을 + 이전 Hidden State
 ↓
새로운 Hidden State

먹었다 + 이전 Hidden State
 ↓
새로운 Hidden State
```

쉽게 말하면:

> **지금까지 읽은 내용을 기억하고 있는 메모장**

이라고 생각할 수 있다.

# 27. 단어에 번호 붙이기

```python
vocab = {

    for i, (word, _) in enumerate(
        counts.most_common(vocab_size - 2)
    )
}
```

→ 가장 많이 등장한 단어부터 `vocab_size - 2`개를 선택한다.


→ `<UNK>`에 1번을 부여한다.

`<UNK>`는 Vocabulary에 없는 모르는 단어를 의미한다.

따라서:

```text

2부터 → 실제 단어
```

# 28. One-Hot Encoding과 Embedding

One-Hot Encoding은 하나의 위치만 1이고 나머지는 0으로 표현하는 방법이다.

```text
사과

↓

[1, 0, 0, 0]
```

하지만 단어가 20,000개라면:

```text
사과
 ↓
20,000개의 숫자
```

가 필요하다.

대부분의 값이 0이기 때문에 비효율적이다.

그래서 Embedding을 사용한다.

```text
단어 번호
   ↓
Embedding
   ↓
[0.2, -0.3, 0.8, ...]
```

→ **Embedding은 단어 번호를 여러 개의 숫자로 이루어진 벡터로 변환하는 과정**이다.

# 34. Padding

모든 문장의 길이는 서로 다르다.

```text
나는 영화를 봤다
→ 3개 단어

오늘 친구와 재미있는 영화를 봤다
→ 5개 단어
```

Batch로 묶어서 계산하려면 문장의 길이를 맞춰야 한다.

```python
if len(ids) < self.max_len:
```

→ 현재 문장의 길이가 최대 길이보다 짧은지 확인한다.

```python
ids += [0] * (
    self.max_len - len(ids)
)
```

→ 부족한 부분을 0으로 채운다.

예:

```text
[15, 48, 90]

↓

32개까지 부족한 공간을 0으로 채움

↓

[15, 48, 90, 0, 0, 0, ...]
```

0은:

```text
0 → <PAD>
```

이다.

# 42. LSTM 전체 모델

```python
class SentimentLSTM(nn.Module):

    def __init__(
        self,
        vocab_size,
        embedding_dim,
        hidden_dim
    ):

        super().__init__()

        self.embedding = nn.Embedding(
            vocab_size,
            embedding_dim,
            padding_idx=0
        )

        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim,
            batch_first=True
        )

        self.fc = nn.Linear(
            hidden_dim,
            1
        )


    def forward(self, x):

        embedded = self.embedding(x)

        # 단어 번호
        # ↓
        # 단어 벡터


        lstm_out, (hidden, cell) = self.lstm(embedded)

        # 문장을 순서대로 읽으면서
        # Hidden State와 Cell State를 계산


        out = self.fc(hidden[-1])

        # 마지막 Hidden State
        # ↓
        # Linear
        # ↓
        # 긍정/부정 점수


        return out
```

각 단계의 흐름:

```text
단어 번호
   ↓
Embedding
   ↓
단어 벡터
   ↓
LSTM
   ↓
Hidden State
   ↓
Linear
   ↓
긍정/부정 점수
```


```text

```

→ 부정일 가능성이 높다고 볼 수 있다.

```text
학습
→ BCEWithLogitsLoss 사용
→ 별도 Sigmoid 필요 없음

테스트
→ torch.sigmoid() 사용
→ 확률 형태로 변환
```

→ 역전파를 수행해서 Gradient를 계산한다.

```python
optimizer.step()
```

→ Gradient를 이용해서 가중치를 업데이트한다.

# 느낀 점

오늘은 이미지 데이터와 텍스트 데이터가 서로 다른 방식으로 모델에 입력된다는 것을 배웠다.

Fashion MNIST는 이미지를 Tensor로 변환한 후 Flatten을 사용해서 1차원으로 만들고, Linear Layer를 통해 분류했다.

반면 영화 리뷰 데이터는 단어의 순서가 중요하기 때문에 단어를 번호로 변환하고 Embedding을 거친 후 LSTM을 사용했다.

특히 이번 학습을 통해 다음 개념을 이해할 수 있었다.

```text
MLP
→ 여러 개의 Layer로 구성된 기본적인 신경망

Flatten
→ 2차원 이미지를 1차원으로 펼치는 것

Time Step
→ 데이터를 순서대로 하나씩 처리하는 시점

Hidden State
→ 이전까지 처리한 정보를 기억하는 값

Embedding
→ 단어 번호를 여러 개의 숫자로 이루어진 벡터로 변환하는 것

Padding
→ 문장의 길이를 맞추기 위해 빈 공간을 채우는 것

Gradient
→ Loss를 줄이기 위해 가중치를 어느 방향으로 수정할지 알려주는 값

Optimizer
→ Gradient를 이용해서 실제 가중치를 수정하는 방법

Backpropagation
→ Loss를 기준으로 Gradient를 계산하는 과정

Early Stopping
→ Validation Loss가 개선되지 않으면 학습을 미리 종료하는 방법

model.train()
→ 모델을 학습 모드로 변경

model.eval()
→ 모델을 평가 모드로 변경

torch.no_grad()
→ Gradient를 계산하지 않고 예측

.to(device)
→ 모델이나 데이터를 CPU/GPU로 이동
```

이번에는 단순히 모델을 실행하는 것보다 **코드의 각 부분이 어떤 역할을 하는지 하나씩 이해하는 것이 중요하다고 느꼈다.**

앞으로도 새로운 코드를 배울 때 단순히 복사해서 실행하는 것이 아니라,

```text
이 코드는 무엇을 하는가?
        ↓
왜 필요한가?
        ↓
데이터가 어떻게 변하는가?
        ↓
다음 코드와 어떻게 연결되는가?
```

순서로 공부해보려고 한다.
