# [TIL] 파이토치(PyTorch) 기반 패션 이미지 분류(MLP) & 영화 리뷰 감정 분석(LSTM) 완전 정복

## 1. 오늘 배운 딥러닝 핵심 개념 및 용어 정리

### 1) 이미지 분류와 다층 퍼셉트론(MLP) 핵심 원리
* **가중치(Weight, 중요도 다이얼)**: 로봇 머릿속의 볼륨 다이얼이다. 처음엔 무작위 숫자로 시작하지만, 학습을 거치며 정답을 맞히기 딱 좋은 각도로 돌아간다.
* **손실(Loss, 오답 점수)**: 모델의 예측값과 실제 정답 간의 오차다. 100점을 맞으면 0점이고 다 틀리면 커진다. 이 점수를 0점으로 깎아내는 것이 학습 목표다.
* **그래디언트(Gradient, 고칠 방향 쪽지)**: 오답 점수를 줄이기 위해 각 가중치 다이얼을 어느 방향으로 얼만큼 돌릴지 계산한 힌트 쪽지다.
* **옵티마이저(Optimizer, 과외 선생님)**: 쪽지(그래디언트)를 보고 지정된 보폭(학습률)으로 가중치 다이얼을 찰칵 돌려주는 일꾼이다 (`Adam` 활용).
* **역전파(Backpropagation, 거꾸로 원인 찾기)**: 출력층의 오차를 바탕으로 입력층 방향으로 거슬러 올라가며 각 층의 그래디언트를 계산하는 과정이다 (`loss.backward()`).
* **은닉층(Hidden Layer, 깊은 생각 층)**: 사진을 보고 바로 정답을 찍는 게 아니라, 보이지 않는 중간에서 128개의 뇌세포가 모여 "이게 티셔츠인가 바지인가?" 깊게 고민하는 층이다.
* **활성화 함수(ReLU, 생각에 굴곡 주기)**: 더하기 곱하기 계산만 하면 반듯한 직선 막대기만 만들어 복잡한 옷 곡선을 못 배운다. 0 미만(음수)은 0으로 싹둑 버리고 양수만 살려 생각에 굴곡을 준다.
* **드롭아웃(Dropout, 게으름 방지)**: 훈련할 때 뇌세포 20%를 번갈아 자게 만들어, 특정 뉴런만 답을 외우는 꼼수(과대적합)를 막고 골고루 실력을 키운다.

### 2) 자연어 처리와 순환 신경망(RNN / LSTM) 핵심 원리
* **타임스텝(Time Step, $t$, 시간 번호표)**: 문장에서 단어를 몇 번째 순서로 읽고 있는지 알려주는 시계 바늘이다. "영화가(1) -> 너무(2) -> 꿀잼(3)"처럼 글자를 하나씩 짚는 순간을 뜻한다.
* **은닉 상태(Hidden State, $h_t$, 단기 기억 메모지)**: 바로 직전 단어까지 읽었던 내용과 이번 단어를 합쳐서 만든 '현재 시점의 기억 요약본'이다.
* **토큰화(Tokenization, 글자 쪼개기)**: 문장을 단어 단위(띄어쓰기 기준)로 잘게 쪼개는 작업이다.
* **단어 사전(Vocabulary, 단어 번호표 모음집)**: 자주 나오는 단어 20,000개를 골라 0번부터 번호를 붙여둔 사전이다.
  * `<PAD>` (0번): 문장 길이를 맞추기 위해 빈 곳에 채워 넣는 빈칸 번호다.
  * `<UNK>` (1번): 사전에 없는 생소한 단어를 뜻하는 물음표 번호다.
* **패딩(Padding, 길이 맞추기)**: 문장 길이가 제각각이면 컴퓨터가 묶음 계산을 못 하므로, 모든 문장을 32칸으로 통일하고 모자란 칸은 0으로 채워주는 작업이다.
* **임베딩(Embedding, 의미 압축기)**: 단순한 단어 번호(정수)를 128개의 숫자로 이루어진 '의미가 담긴 밀집 좌표'로 바꿔주는 층이다. 비슷한 단어끼리는 좌표가 가까워진다.
* **LSTM (장단기 메모리 뇌세포)**: 이전 RNN이 문장이 길어지면 앞 단어를 까먹는 치매 현상(기울기 소실)을 고치기 위해, '망각 게이트' 등을 달아 중요한 기억만 쏙쏙 오래 기억하도록 만든 순환 뇌세포다.

## 2. [실습 1] 패션 이미지 다층 퍼셉트론(MLP) 분류 코드 분석

### 1단계: 도구 챙기고 GPU 작업실 배정하기

```python
import torch
from torchvision import datasets
from torchvision.transforms import ToTensor
from torch.utils.data import DataLoader, random_split

device = torch.device(
    "cuda"
    if torch.cuda.is_available()
    else "mps"
    if torch.backends.mps.is_available()
    else "cpu"
)
```

* `device = torch.device(...)`: 엔비디아 GPU(`cuda`), 맥북 GPU(`mps`), 기본 CPU(`cpu`) 중 가장 빠른 작업실로 로봇 방을 배정한다.
* **GPU 사용 이유**: CPU는 똑똑한 교수님 1명이라 한 번에 1문제만 풀지만, GPU는 초등학생 5,000명이 모여 단순 더하기 계산 수만 개를 1초 만에 동시에 풀어내어 100배 빠르다.

---

### 2단계: 패션 데이터셋 다운로드 및 0~1 정규화

```python
raw_train_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=ToTensor()
)

test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=ToTensor()
)
```

* `datasets.FashionMNIST`: 연구자들이 옷 사진 7만 장을 미리 묶어둔 데이터 상자다. `train=True`는 공부용 6만 장, `train=False`는 시험용 1만 장이다.
* `transform=ToTensor()`: 0~255 사이의 픽셀 밝기 숫자를 255로 나눠 $0.0 \sim 1.0$ 사이의 소수점 텐서로 압축(정규화)하여 연산 폭발을 막는다.

### 3단계: 모의고사 세트 분리 및 DataLoader 배달부 생성

```python
train_size = 50000
val_size = 10000

train_data, val_data = random_split(
    raw_train_data,
    [train_size, val_size],
    generator=torch.Generator().manual_seed(42)
)

train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
val_loader = DataLoader(val_data, batch_size=32, shuffle=False)
test_loader = DataLoader(test_data, batch_size=32, shuffle=False)
```

* `random_split`: 6만 장을 5만 장(공부용)과 1만 장(모의고사용)으로 쪼갠다. 대괄호 `[ ]`는 파이썬 리스트 문법이다.
* `manual_seed(42)`: 누가 실행해도 똑같은 순서로 공정하게 섞이도록 랜덤 자물쇠를 거는 코드다.
* `DataLoader(..., batch_size=32)`: 32장씩 묶음 도시락으로 배달해 주는 일꾼이다.
* `shuffle=True`: 문제집 답 순서를 외우는 꼼수를 막기 위해 카드를 섞는다. 검증/테스트는 채점만 하므로 `shuffle=False`로 둔다.

### 4단계: 다층 퍼셉트론(MLP) 뇌 설계도 조립

```python
import torch.nn as nn

class AdvancedFashionClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.hidden_layer = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(p=0.2)
        self.output_layer = nn.Linear(128, 10)

    def forward(self, x):
        out = self.flatten(x)
        out = self.hidden_layer(out)
        out = self.relu(out)
        out = self.dropout(out)
        out = self.output_layer(out)
        return out
```

* `self.flatten = nn.Flatten()`: 가로 28칸 x 세로 28칸($28 \times 28 = 784$개 점)짜리 네모 사진을 784개의 긴 1줄 국수로 펴준다.
* `self.hidden_layer = nn.Linear(784, 128)`: 784개 신호를 받아 128개 뇌세포가 모여 생각하는 은닉층이다.
* `self.relu = nn.ReLU()`: 계산 결과가 0 미만이면 버리고 0 이상만 살려 생각에 곡선을 주는 필터다.
* `self.dropout = nn.Dropout(p=0.2)`: 공부할 때 뇌세포 20%를 쉬게 하는 도구다.
* `self.output_layer = nn.Linear(128, 10)`: 정답 옷 번호가 0번(티셔츠)부터 9번(부츠)까지 10개라서 최종 10개 점수를 내보낸다.
* `forward`: 사진 `x`가 들어오면 1줄 펴기 -> 128개 생각 -> 굴곡 주기 -> 20% 쉬기 -> 10개 점수 출력 순서로 생각하는 길이다.

---

### 5단계: 손실 함수, 옵티마이저, 조기 종료 루프 및 최종 평가

```python
import torch.optim as optim

model = AdvancedFashionClassifier().to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.005)

epochs = 20
patience = 3
patience_count = 0
best_val_loss = float('inf')

train_losses, val_losses = [], []

for epoch in range(epochs):
    # [1. 훈련 단계]
    model.train()
    running_loss = 0.0
    for images, labels in train_loader:
        images, labels = images.to(device), labels.to(device)

        optimizer.zero_grad()               # 칠판 낙서 지우기
        outputs = model(images)             # 문제 풀기 (순전파)
        loss = criterion(outputs, labels)   # 채점관 오답 점수 받기
        loss.backward()                     # 역전파 방향 쪽지 쓰기
        optimizer.step()                    # 다이얼 찰칵 수정하기

        running_loss += loss.item()

    epoch_train_loss = running_loss / len(train_loader)
    train_losses.append(epoch_train_loss)

    # [2. 검증 단계]
    model.eval()
    val_loss = 0.0
    with torch.no_grad():
        for images, labels in val_loader:
            images, labels = images.to(device), labels.to(device)
            outputs = model(images)
            loss = criterion(outputs, labels)
            val_loss += loss.item()

    epoch_val_loss = val_loss / len(val_loader)
    val_losses.append(epoch_val_loss)

    # [3. 조기 종료 검증]
    if epoch_val_loss < best_val_loss:
        best_val_loss = epoch_val_loss
        patience_count = 0
        torch.save(model.state_dict(), "best_fashion_model.pth")
    else:
        patience_count += 1
        if patience_count >= patience:
            print(f"조기 종료: {epoch+1} 에포크에서 학습 중단")
            break

# [4. 최종 기말고사 평가]
model.load_state_dict(torch.load("best_fashion_model.pth"))
model.to(device)
model.eval()

correct, total = 0, 0
with torch.no_grad():
    for images, labels in test_loader:
        images, labels = images.to(device), labels.to(device)
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

test_accuracy = correct / total * 100
print(f"테스트 세트 정확도: {test_accuracy:.2f}%")
```

* `best_val_loss = float('inf')`: 첫 시험 점수가 무조건 1등으로 수첩에 적히게 하려고 세상에서 가장 큰 무한대 숫자로 초기화한다.
* `patience = 3`: 모의고사 점수가 3번 연속 안 좋아지면 과대적합으로 판단하고 스스로 공부를 멈춘다.
* 최종 시험 10,000장에서 **85.49%**의 높은 정확도로 옷을 맞혔다.

## 3. [실습 2] 네이버 영화 리뷰 감정 분석(LSTM) 코드 분석

### 1단계: 데이터 로드 및 3단계 쪼개기 (Train / Val / Test)

```python
import pandas as pd
from sklearn.model_selection import train_test_split

# 1. 네이버 영화 리뷰 데이터셋(NSMC) 로드 (긍정=1, 부정=0, 탭 구분자로 읽기)
df = pd.read_csv('ratings.txt', sep='\t')

# 2. 결측치(내용이 빈 리뷰) 행 제거
df = df.dropna()

# 3. 데이터 1차 분할: 훈련 임시(80%)와 최종 테스트(20%)로 분리
train_tmp_df, test_df = train_test_split(df, test_size=0.2, random_state=42)

# 4. 데이터 2차 분할: 훈련 임시(80%)를 다시 진짜 훈련(64%)과 모의고사 검증(16%)으로 분리
train_df, val_df = train_test_split(train_tmp_df, test_size=0.2, random_state=42)

print("훈련세트:", len(train_df))    # 127,994개
print("검증세트:", len(val_df))      # 31,999개
print("테스트세트:", len(test_df))    # 39,999개
```

* `sep='\t'`: 일반 쉼표 대신 탭(Tab) 키로 칸이 띄워져 있어서 탭으로 읽으라는 뜻이다.
* `df.dropna()`: 리뷰 글이 아예 안 적혀있는 엉터리 빈칸 행을 깨끗하게 지운다.
* **2번 쪼갠 이유**: 한 번에 3등분 하는 함수가 없어서, 전체에서 시험용 20%를 먼저 떼어내고 남은 80% 중에서 20%를 검증용으로 또 떼어내어 **64% : 16% : 20%**의 완벽한 3분할을 만든다.

---

### 2단계: 단어 사전(Vocabulary) 구축 및 커스텀 Dataset 생성

```python
from collections import Counter
import torch
from torch.utils.data import DataLoader, Dataset

# 1. 훈련 데이터의 모든 리뷰 글을 띄어쓰기로 잘라 하나의 큰 단어 리스트로 모으기
vocab_size = 20000
all_words = []
for text in train_df['document']:
    all_words.extend(text.split())

# 2. 자주 나오는 상위 19,998개 단어를 세어서 2번부터 번호 부여
counts = Counter(all_words)
vocab = {word: i+2 for i, (word, _) in enumerate(counts.most_common(vocab_size - 2))}
vocab['<PAD>'] = 0  # 길이 채우기용 빈칸 토큰 (0번)
vocab['<UNK>'] = 1  # 사전에 없는 모르는 단어 토큰 (1번)

# 3. 파이토치 전용 커스텀 Dataset 설계도 만들기
class NSMCDataset(Dataset):
    def __init__(self, df, vocab, max_len=32):
        self.labels = df['label'].values
        self.texts = df['document'].astype(str).values
        self.vocab = vocab
        self.max_len = max_len

    def __len__(self):
        return len(self.labels)

    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]

        # 띄어쓰기로 자르고 단어 번호로 변환 (모르는 단어는 1번 <UNK> 부여)
        tokens = text.split()
        ids = [self.vocab.get(token, 1) for token in tokens[:self.max_len]]

        # 32칸 길이에 모자라면 뒤에 0(<PAD>)을 채워 넣음 (패딩)
        if len(ids) < self.max_len:
            ids += [0] * (self.max_len - len(ids))

        return torch.tensor(ids, dtype=torch.long), torch.tensor(label, dtype=torch.long)

# 4. 데이터셋 생성 및 64개 묶음 DataLoader 배달부 만들기
train_dataset = NSMCDataset(train_df, vocab)
val_dataset = NSMCDataset(val_df, vocab)
test_dataset = NSMCDataset(test_df, vocab)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)
```

* `i + 2`: 0번은 `<PAD>`(빈칸), 1번은 `<UNK>`(모르는 단어)로 미리 찜해두었기 때문에 진짜 단어들은 2번부터 번호를 매긴다.
* `tokens[:self.max_len]`: 문장이 32단어보다 길면 32번째 단어까지만 남기고 뒤는 잘라버린다.
* `ids += [0] * (...)`: 문장이 5단어로 짧으면 남은 27칸을 전부 0번으로 채워 딱 32칸 규격으로 통일한다.

### 3단계: 임베딩 + LSTM 감정 분석 모델 구조

```python
import torch.nn as nn

class SentimentLSTM(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        # 1. 20,000개 단어 번호를 128차원 의미 숫자로 압축 변환하는 임베딩 층
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        
        # 2. 128차원 신호를 받아 타임스텝 1~32까지 문맥을 기억하는 LSTM 층 (기억 메모지: 256칸)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        
        # 3. 마지막 256칸 기억 메모지를 보고 긍정/부정 점수 1개를 내뱉는 출력층
        self.fc = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        # x: (배치 크기 64, 문장 길이 32)
        embedded = self.embedding(x)                     # -> (64, 32, 128)
        lstm_out, (hidden, cell) = self.lstm(embedded)   # -> hidden: (1, 64, 256)
        out = self.fc(hidden[-1])                        # 마지막 타임스텝 기억만 꺼내 점수 산출 -> (64, 1)
        return out
```

* `nn.Embedding(..., padding_idx=0)`: 0번 패딩은 의미 없는 빈칸이므로 계산하지 않고 0으로 무시하라는 옵션이다.
* `batch_first=True`: 데이터 모양을 `(배치 크기 64, 문장 길이 32, 차원 128)` 형태로 파이토치 표준에 맞춘다.
* `hidden[-1]`: 문장 32단어를 처음부터 끝까지 다 읽고 난 뒤, 머릿속에 최종적으로 남은 256칸짜리 핵심 요약 메모지만 쏙 꺼내어 감정 판정대로 보낸다.

### 4단계: 이진 분류 훈련 및 조기 종료 루프

```python
import torch.optim as optim
import matplotlib.pyplot as plt

vocab_size = 20000
embedding_dim = 128
hidden_dim = 256

model = SentimentLSTM(vocab_size, embedding_dim, hidden_dim).to(device)

# 1. 긍정(1)/부정(0)을 맞히는 이진 분류 전용 손실 함수 채택
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

epochs = 20
patience = 3
patience_counter = 0
best_val_loss = float('inf')

train_losses, val_losses = [], []

for epoch in range(epochs):
    # [훈련 단계]
    model.train()
    running_train_loss = 0.0
    for sequences, labels in train_loader:
        sequences, labels = sequences.to(device), labels.to(device)

        optimizer.zero_grad()
        outputs = model(sequences)
        
        # labels 모양을 (64)에서 (64, 1)의 소수점 텐서로 맞춰 손실 계산
        loss = criterion(outputs, labels.float().unsqueeze(1))
        loss.backward()
        optimizer.step()

        running_train_loss += loss.item()

    epoch_train_loss = running_train_loss / len(train_loader)
    train_losses.append(epoch_train_loss)

    # [검증 단계]
    model.eval()
    running_val_loss = 0.0
    with torch.no_grad():
        for sequences, labels in val_loader:
            sequences, labels = sequences.to(device), labels.to(device)
            outputs = model(sequences)
            loss = criterion(outputs, labels.float().unsqueeze(1))
            running_val_loss += loss.item()

    epoch_val_loss = running_val_loss / len(val_loader)
    val_losses.append(epoch_val_loss)

    print(f"Epoch [{epoch+1}/{epochs}] | Train Loss: {epoch_train_loss:.4f} | Val Loss: {epoch_val_loss:.4f}")

    # [조기 종료 체크]
    if epoch_val_loss < best_val_loss:
        best_val_loss = epoch_val_loss
        patience_counter = 0
        torch.save(model.state_dict(), "best_movie_model.pth")
        print(" => 최적 모델 가중치 저장 완료")
    else:
        patience_counter += 1
        print(f" => 검증 손실 미개선 (Counter: {patience_counter}/{patience})")
        if patience_counter >= patience:
            print(f"\n[Early Stopping] {epoch+1} Epoch에서 학습을 선제 종료합니다.")
            break
```

* `BCEWithLogitsLoss()`: 긍정/부정 둘 중 하나를 맞힐 때 쓰는 전용 손실 함수다. 내부적으로 시그모이드 확률 계산까지 한 번에 안전하게 해준다.
* `labels.float().unsqueeze(1)`: 모델 출력 점수는 `(64, 1)` 형태의 2차원 소수점인데, 정답 라벨은 `(64)` 형태의 1차원 정수라서 모양을 `(64, 1)`의 소수점으로 똑같이 변환해 준다.
* 5번째 에포크에서 검증 오차가 3번 연속 증가하자 조기 종료(`Early Stopping`)가 발동되어 최적 모델(`best_movie_model.pth`)을 지켜냈다.

### 5단계: 임계값(Threshold=0.6) 적용 및 최종 테스트 평가

```python
# 1. 검증 손실이 가장 낮았던 똑똑한 모델 복원
model.load_state_dict(torch.load("best_movie_model.pth"))
model.eval()

correct = 0
total = 0
threshold = 0.6  # 60% 이상 확신할 때만 긍정(1)으로 인정

with torch.no_grad():
    for sequences, labels in test_loader:
        sequences, labels = sequences.to(device), labels.to(device)
        outputs = model(sequences)

        # 1. 출력 점수를 0~1 사이의 진짜 긍정 확률(%)로 변환
        probabilities = torch.sigmoid(outputs)

        # 2. 0.6(60%) 이상일 때만 진짜 긍정(1), 아니면 부정(0)으로 판정
        predictions = (probabilities >= threshold).int()

        correct += (predictions == labels.unsqueeze(1)).sum().item()
        total += labels.size(0)

test_accuracy = (correct / total) * 100
print(f"최종 테스트 데이터셋 정확도(Test Accuracy): {test_accuracy:.2f}%\n")
```

* `torch.sigmoid(outputs)`: 모델이 낸 임의의 점수를 0% ~ 100% 사이의 부드러운 확률 소수점($0.0 \sim 1.0$)으로 바꾼다.
* `threshold = 0.6`: 애매하게 51% 나온 것은 긍정으로 치지 않고, **확률이 60% 이상으로 확실할 때만 긍정(1) 리뷰로 인정**하는 안전 기준선이다.
* 39,999개의 실전 테스트 리뷰에서 **76.12%**의 준수한 감정 분석 정확도를 기록했다.

## 5. 내가 꼭 기억해야 할 핵심 마법 공식

1. **파이토치 훈련 4단계**: `zero_grad()`(칠판 지우기) -> `model(x)`(풀기) -> `loss.backward()`(원인 찾기) -> `optimizer.step()`(다이얼 고치기)
2. **모드 스위치**: 공부할 땐 `train()`, 시험 볼 땐 `eval()` + `with torch.no_grad()`로 컴퓨터 메모리 아끼기!
3. **과대적합 방어 3총사**: 뉴런을 쉬게 하는 `Dropout`, 문맥 순서를 기억하는 `LSTM`, 가장 똑똑할 때 멈추는 `Early Stopping`!
