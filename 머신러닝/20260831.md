# 1. 핵심 개념

## MLP(Multi Layer Perceptron)

MLP는 **Multi Layer Perceptron(다층 퍼셉트론)**의 줄임말이다.

쉽게 말하면 여러 개의 층으로 이루어진 기본적인 인공신경망 구조이다.

```text
입력층
  ↓
은닉층
  ↓
출력층
```

Fashion MNIST 모델에서는 다음과 같은 구조를 사용했다.

```text
28 × 28 이미지
      ↓
Flatten
      ↓
784개 숫자
      ↓
Linear(784 → 128)
      ↓
ReLU
      ↓
Dropout
      ↓
Linear(128 → 10)
      ↓
의류 10개 카테고리
```

---

## 가중치(Weight)

가중치는 입력 데이터가 결과에 얼마나 영향을 주는지를 결정하는 값이다.

처음에는 보통 무작위 값으로 시작한다.

```text
처음
무작위 가중치
      ↓
예측
      ↓
Loss 계산
      ↓
Gradient 계산
      ↓
Optimizer
      ↓
가중치 수정
```

학습을 반복하면서 가중치가 점점 더 좋은 값으로 변경된다.

---

## Loss(손실)

Loss는 모델의 예측과 실제 정답이 얼마나 다른지를 나타내는 값이다.

```text
예측과 정답이 비슷함
→ Loss 작음

예측과 정답이 많이 다름
→ Loss 큼
```

모델 학습의 목표는 Loss를 줄이는 것이다.

---

## Gradient(기울기)

Gradient는 Loss를 줄이기 위해 가중치를 어느 방향으로 수정해야 하는지 알려주는 값이다.

쉽게 말하면:

> **"가중치를 이쪽 방향으로 수정하면 Loss가 줄어들 것 같아!"라고 알려주는 힌트**

라고 생각하면 된다.

---

## Optimizer(옵티마이저)

Optimizer는 Gradient를 이용해서 실제로 가중치를 수정한다.

```text
Gradient
   ↓
Optimizer
   ↓
가중치 업데이트
```

대표적인 Optimizer에는 다음과 같은 것들이 있다.

* SGD
* Adam

---

## 역전파(Backpropagation)

역전파는 Loss를 기준으로 각 가중치가 얼마나 수정되어야 하는지 계산하는 과정이다.

```python
loss.backward()  # Loss를 기준으로 각 가중치의 Gradient를 계산
```

전체 학습 과정은 다음과 같다.

```text
입력 데이터
    ↓
순전파
    ↓
예측
    ↓
Loss 계산
    ↓
역전파
    ↓
Gradient 계산
    ↓
Optimizer
    ↓
가중치 수정
```

# 9. 전체 모델 코드

```python
import torch.nn as nn


class AdvancedFashionClassifier(nn.Module):

    def __init__(self):

        super().__init__()
        # PyTorch 신경망의 기본 기능 초기화


        self.flatten = nn.Flatten()
        # 28 × 28 이미지를
        # 784개의 숫자로 펼침


        self.hidden_layer = nn.Linear(784, 128)
        # 784개의 입력값을 받아
        # 128개의 뉴런으로 전달


        self.relu = nn.ReLU()
        # 음수는 0으로 만들고
        # 양수는 그대로 사용


        self.dropout = nn.Dropout(p=0.2)
        # 학습 중 일부 뉴런을 랜덤하게 사용하지 않음
        # 과대적합 방지에 도움


        self.output_layer = nn.Linear(128, 10)
        # 128개의 값을 받아
        # Fashion MNIST의 10개 클래스 점수 출력


    def forward(self, x):

        out = self.flatten(x)
        # 28 × 28 이미지
        # ↓
        # 784개 숫자


        out = self.hidden_layer(out)
        # 784개
        # ↓
        # 128개


        out = self.relu(out)
        # 음수 제거
        # 비선형성 추가


        out = self.dropout(out)
        # 학습할 때만 일부 뉴런을 랜덤하게 끔


        out = self.output_layer(out)
        # 128개
        # ↓
        # 10개 클래스 점수


        return out
        # 최종 결과 반환
```

전체 흐름:

```text
이미지

↓

Flatten

↓

784

↓

Linear

↓

128

↓

ReLU

↓

Dropout

↓

Linear

↓

10개 클래스
```

# 15. Fashion MNIST 모델 학습

```python
for epoch in range(epochs):

    # epochs가 20이면
    # epoch는 0부터 19까지 반복


    model.train()
    # 모델을 학습 모드로 변경
    # Dropout 같은 학습용 기능이 활성화됨


    running_loss = 0.0
    # 현재 Epoch에서 발생한
    # 모든 Batch Loss를 저장


    for images, labels in train_loader:

        # train_loader에서
        # 이미지 32개와 정답 32개를 가져옴


        images = images.to(device)
        labels = labels.to(device)

        # 이미지와 정답을
        # 모델이 있는 GPU 또는 CPU로 이동


        optimizer.zero_grad()

        # 이전 Batch에서 계산된 Gradient 초기화
        # PyTorch는 Gradient를 계속 누적하기 때문에 필요


        outputs = model(images)

        # 순전파
        # 이미지 → 모델 → 예측값


        loss = criterion(outputs, labels)

        # 모델의 예측과 실제 정답을 비교
        # Loss 계산


        loss.backward()

        # 역전파
        # 각 가중치를 어떻게 수정해야 하는지
        # Gradient 계산


        optimizer.step()

        # 계산된 Gradient를 사용해서
        # 실제 가중치 업데이트


        running_loss += loss.item()

        # 현재 Batch의 Loss 값을 저장
```

# 21. RNN과 시계열 데이터

시계열 데이터는 **시간이나 순서가 중요한 데이터**이다.

예를 들어:

```text
월요일 → 화요일 → 수요일
```

문장도 순서가 중요하다.

```text
나는 → 밥을 → 먹었다
```

RNN은 이런 순서가 있는 데이터를 처리하는 신경망이다.

---

## Time Step

```text
나는 밥을 먹었다
```

RNN은 다음처럼 하나씩 읽는다.

```text
Time Step 1 → 나는

Time Step 2 → 밥을

Time Step 3 → 먹었다
```

즉:

> **Time Step = 데이터를 순서대로 하나씩 처리하는 시점**

이다.

---

## Hidden State

Hidden State는 이전까지 읽은 정보를 기억하는 값이다.

```text
나는
 ↓
Hidden State

밥을 + 이전 Hidden State
 ↓
새로운 Hidden State

먹었다 + 이전 Hidden State
 ↓
새로운 Hidden State
```

쉽게 말하면:

> **지금까지 읽은 내용을 기억하는 메모장**

이라고 생각할 수 있다.

# 37. LSTM 전체 모델

```python
class SentimentLSTM(nn.Module):

    def __init__(
        self,
        vocab_size,
        embedding_dim,
        hidden_dim
    ):

        super().__init__()


        self.embedding = nn.Embedding(

            vocab_size,
            # 전체 단어 개수

            embedding_dim,
            # 각 단어를 표현할 숫자 개수

            padding_idx=0
            # 0번은 Padding
        )


        self.lstm = nn.LSTM(

            embedding_dim,
            # Embedding 결과를 입력으로 사용

            hidden_dim,
            # Hidden State 크기

            batch_first=True
            # Batch가 첫 번째 차원
        )


        self.fc = nn.Linear(

            hidden_dim,
            # LSTM의 마지막 기억

            1
            # 긍정/부정 점수 하나 출력
        )


    def forward(self, x):

        embedded = self.embedding(x)

        # 단어 번호

        # ↓

        # 단어 벡터


        lstm_out, (hidden, cell) = self.lstm(embedded)

        # LSTM이 문장을 순서대로 읽음

        # hidden → 현재까지 기억한 정보

        # cell → LSTM의 장기 기억


        out = self.fc(hidden[-1])

        # 마지막 Hidden State를 가져옴

        # ↓

        # 긍정/부정 점수 계산


        return out
```

전체 흐름:

```text
영화 리뷰

↓

단어 분리

↓

단어 번호

↓

Embedding

↓

LSTM

↓

마지막 Hidden State

↓

Linear

↓

긍정 / 부정 점수
```

# 느낀 점

오늘은 이미지 데이터와 텍스트 데이터가 서로 다른 방식으로 모델에 입력된다는 것을 배웠다.

Fashion MNIST는 이미지를 숫자로 변환한 후 Flatten을 사용해서 1차원으로 만들고 Linear Layer를 통해 분류했다.

반면 영화 리뷰 데이터는 단어의 순서가 중요하기 때문에 단어를 번호로 변환하고 Embedding을 거친 후 LSTM을 사용했다.

특히 이번 학습을 통해 다음 개념을 이해할 수 있었다.

```text
MLP
→ 여러 개의 Layer로 구성된 기본적인 신경망

Flatten
→ 2차원 이미지를 1차원으로 펼치는 것

Time Step
→ 데이터를 순서대로 하나씩 처리하는 시점

Hidden State
→ 이전까지 처리한 정보를 기억하는 값

Embedding
→ 단어 번호를 여러 개의 숫자로 이루어진 벡터로 변환하는 것

Padding
→ 문장의 길이를 맞추기 위해 빈 공간을 채우는 것

Early Stopping
→ Validation Loss가 개선되지 않으면 학습을 미리 종료하는 방법
```

이번에는 단순히 모델을 실행하는 것보다 **코드의 각 부분이 어떤 역할을 하는지 하나씩 이해하는 것이 중요하다고 느꼈다.**

앞으로도 새로운 코드를 배울 때 단순히 복사해서 실행하는 것이 아니라,

```text
이 코드는 무엇을 하는가?

↓

왜 필요한가?

↓

데이터가 어떻게 변하는가?

↓

다음 코드와 어떻게 연결되는가?
```

순서로 공부해보려고 한다.
