# 1. 핵심 개념

## MLP(Multi Layer Perceptron)

MLP는 여러 개의 선형 레이어(Linear Layer)와 활성화 함수(Activation Function)가 쌓여 구성된 기본적인 인공신경망 구조이다.

입력 데이터를 받아 은닉층을 거쳐 출력층으로 전달하면서 복잡한 데이터 표현을 학습한다.

~~~text
입력층
  |
  v
은닉층
  |
  v
출력층
~~~

Fashion MNIST 모델의 레이어 흐름은 다음과 같다.

~~~text
28 x 28 이미지
  |
  v
Flatten
  |
  v
784개 1차원 값
  |
  v
Linear (784 -> 128)
  |
  v
ReLU
  |
  v
Dropout (p=0.2)
  |
  v
Linear (128 -> 10)
  |
  v
10개 클래스 점수
~~~

- `Flatten`: 28 x 28 형태의 2차원 이미지 데이터를 784개의 1차원 벡터로 평탄화한다.
- `Linear`: 선형 변환을 통해 입력 노드를 가중치와 결합하여 다음 레이어로 연결한다.
- `ReLU`: 음수 값을 0으로 변환하여 비선형성을 제공한다.
- `Dropout`: 학습 과정에서 노드의 일부를 무작위로 비활성화하여 과적합을 방지한다.

## 신경망 학습 핵심 요소

- **가중치(Weight)**: 입력 값이 결과에 미치는 영향력을 나타내며 초기 무작위 값에서 점차 최적의 값으로 갱신된다.
- **손실(Loss)**: 모델의 예측값과 실제 정답의 차이를 수치화한 값으로 모델 학습의 목표는 이 값을 최소화하는 것이다.
- **기울기(Gradient)**: 손실 값을 줄이기 위해 가중치를 어느 방향과 크기로 조정해야 하는지 나타내는 변화도이다.
- **옵티마이저(Optimizer)**: 계산된 Gradient를 기반으로 실제 가중치를 수정하는 알고리즘이다. (예: SGD, Adam)
- **역전파(Backpropagation)**: `loss.backward()` 호출을 통해 손실 값을 시작으로 각 가중치 노드까지 거슬러 올라가며 미분값(Gradient)을 계산하는 과정이다.

## 시계열 데이터와 RNN/LSTM

시계열 데이터는 순서와 문맥이 중요한 데이터이다. 자연어 문장 역시 단어가 나열되는 순서에 따라 의미가 달라지는 시계열 데이터에 해당한다.

- **Time Step**: 시계열 데이터를 순서대로 하나씩 처리하는 각 시점을 뜻한다.
- **Hidden State**: 이전 Time Step까지 처리된 입력 정보들을 누적해서 유지하는 메모리 상태이다.
- **LSTM(Long Short-Term Memory)**: RNN의 단점인 장기 의존성 한계를 보완하기 위해 셀 상태(Cell State)와 게이트 메커니즘을 추가한 순환 신경망 모델이다.

## 자연어 전처리 기초

- **Tokenization**: 텍스트를 공백 또는 형태소 단위의 작은 토큰 단위로 나누는 작업이다.
- **Vocabulary**: 자주 등장하는 토큰에 고유한 정수 번호(Index)를 매겨 관리하는 사전이다.
- **Padding(`<PAD>`)**: 서로 길이가 다른 문장들을 미니배치로 묶기 위해 동일한 최대 길이(`max_len`)로 맞추고 빈 공간을 특정 번호(예: 0)로 채우는 작업이다.
- **Unknown Token(`<UNK>`)**: 사전에 없는 단어가 들어왔을 때 대체하기 위한 특수 토큰이다.
- **Embedding**: 희소한 정수 번호(One-Hot Vector 형태)를 고정된 차원의 조밀한 실수 벡터(Dense Vector)로 압축 변환하는 기법이다.

# 2. 실습 및 코드

## Fashion MNIST 이미지 분류 (MLP)

### 환경 설정 및 데이터 준비

~~~python
import torch
from torchvision import datasets
from torchvision.transforms import ToTensor
from torch.utils.data import DataLoader, random_split

device = torch.device(
    "cuda"
    if torch.cuda.is_available()
    else "mps"
    if torch.backends.mps.is_available()
    else "cpu"
)

raw_train_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=ToTensor()
)

test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=ToTensor()
)

train_size = 50000
val_size = 10000
train_data, val_data = random_split(
    raw_train_data,
    [train_size, val_size],
    generator=torch.Generator().manual_seed(42)
)

train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
val_loader = DataLoader(val_data, batch_size=32, shuffle=False)
test_loader = DataLoader(test_data, batch_size=32, shuffle=False)
~~~

- `ToTensor()`를 통해 0~255 범위의 픽셀 데이터를 0~1 범위의 PyTorch FloatTensor로 변환한다.
- `random_split`으로 60,000장의 학습 데이터를 50,000장의 학습용과 10,000장의 검증용으로 분할한다.
- `train_loader`는 데이터 순서를 섞기 위해 `shuffle=True`를 적용하고 검증 및 테스트 로더는 `shuffle=False`를 유지한다.

### MLP 모델 클래스 정의

~~~python
import torch.nn as nn

class AdvancedFashionClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.hidden_layer = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(p=0.2)
        self.output_layer = nn.Linear(128, 10)

    def forward(self, x):
        out = self.flatten(x)
        out = self.hidden_layer(out)
        out = self.relu(out)
        out = self.dropout(out)
        out = self.output_layer(out)
        return out
~~~

- `nn.Module`을 상속받아 커스텀 모델 구조를 정의한다.
- 28 x 28 형태 입력을 784차원으로 펼친 후 128개의 은닉 노드를 거쳐 최종 10개 클래스 점수를 출력한다.

### 모델 초기화 및 학습 설정

~~~python
import torch.optim as optim

model = AdvancedFashionClassifier().to(device)

total_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
print(f"총 학습 가능한 모델 파라미터 개수: {total_params:,}개")

criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.005)

epochs = 20
patience = 3
patience_count = 0
best_val_loss = float("inf")
train_losses = []
val_losses = []
~~~

- 다중 분류를 위해 `nn.CrossEntropyLoss`를 손실 함수로 설정한다.
- 모델 파라미터 업데이트를 위한 최적화 알고리즘으로 `optim.Adam`을 생성한다.
- 검증 손실이 3회 연속 개선되지 않을 경우 학습을 조기 중단하기 위해 Early Stopping 설정을 구성한다.

### MLP 학습 및 검증 루프

~~~python
for epoch in range(epochs):
    model.train()
    running_loss = 0.0

    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

        running_loss += loss.item()

    epoch_train_loss = running_loss / len(train_loader)
    train_losses.append(epoch_train_loss)

    model.eval()
    val_loss = 0.0
    with torch.no_grad():
        for images, labels in val_loader:
            images = images.to(device)
            labels = labels.to(device)
            outputs = model(images)
            loss = criterion(outputs, labels)
            val_loss += loss.item()

    epoch_val_loss = val_loss / len(val_loader)
    val_losses.append(epoch_val_loss)

    if epoch_val_loss < best_val_loss:
        best_val_loss = epoch_val_loss
        patience_count = 0
        torch.save(model.state_dict(), "best_fashion_model.pth")
    else:
        patience_count += 1

    if patience_count >= patience:
        print(f"조기 종료: {epoch + 1} 에포크에서 학습 중단")
        break
~~~

- 배치가 시작될 때 `optimizer.zero_grad()`로 이전 배치의 그래디언트를 비운다.
- `loss.backward()`로 그래디언트를 구하고 `optimizer.step()`으로 가중치를 갱신한다.
- 검증 루프에서는 `model.eval()`과 `torch.no_grad()`를 선언해 역전파 연산을 차단하고 연산 속도 및 메모리를 절약한다.
- 검증 손실이 기존 최저치보다 낮아지면 `best_fashion_model.pth`로 가중치를 저장한다.

### 최적 가중치 로드 및 평가

~~~python
model.load_state_dict(torch.load("best_fashion_model.pth"))
model.to(device)
model.eval()

correct = 0
total = 0

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

test_accuracy = correct / total * 100
~~~

- 저장된 가중치를 `load_state_dict`로 복원한 후 테스트 데이터를 대상으로 성능을 검증한다.
- `torch.max(outputs.data, 1)`을 사용하여 10개의 출력값 중 가장 큰 인덱스를 예측 클래스로 선택한다.

## 영화 리뷰 감정 분석 (LSTM)

### 데이터 전처리 및 토큰 사전 구축

~~~python
import pandas as pd
from sklearn.model_selection import train_test_split
from collections import Counter

df = pd.read_csv("ratings.txt", sep="\t")
df = df.dropna()

train_tmp_df, test_df = train_test_split(df, test_size=0.2, random_state=42)
train_df, val_df = train_test_split(train_tmp_df, test_size=0.2, random_state=42)

vocab_size = 20000
all_words = []
for text in train_df["document"]:
    all_words.extend(text.split())

counts = Counter(all_words)
vocab = {
    word: i + 2
    for i, (word, _) in enumerate(counts.most_common(vocab_size - 2))
}
vocab["<PAD>"] = 0
vocab["<UNK>"] = 1
~~~

- `ratings.txt` 데이터를 불러와 결측치를 삭제하고 학습(64%), 검증(16%), 테스트(20%) 세트로 분할한다.
- 학습 세트의 단어 빈도를 집계하여 빈도순으로 상위 단어를 추출하고 정수 인덱스를 매긴다.
- 0번은 문장 길이 패딩을 위한 `<PAD>`, 1번은 미등록 단어를 위한 `<UNK>`로 지정한다.

### 커스텀 Dataset 및 DataLoader 생성

~~~python
from torch.utils.data import Dataset, DataLoader

class NSMCDataset(Dataset):
    def __init__(self, df, vocab, max_len=32):
        self.labels = df["label"].values
        self.texts = df["document"].astype(str).values
        self.vocab = vocab
        self.max_len = max_len

    def __len__(self):
        return len(self.labels)

    def __getitem__(self, idx):
        text = self.texts[idx]
        label = self.labels[idx]

        tokens = text.split()
        ids = [self.vocab.get(token, 1) for token in tokens[:self.max_len]]

        if len(ids) < self.max_len:
            ids += [0] * (self.max_len - len(ids))

        return (
            torch.tensor(ids, dtype=torch.long),
            torch.tensor(label, dtype=torch.long)
        )

train_dataset = NSMCDataset(train_df, vocab)
val_dataset = NSMCDataset(val_df, vocab)
test_dataset = NSMCDataset(test_df, vocab)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)
~~~

- `__getitem__` 함수 내에서 텍스트 분할, 토큰 인덱스 매핑, 패딩 처리를 순차적으로 수행한다.
- 길이가 부족한 문장은 끝부분에 `0`을 채워 모든 입력 텐서의 길이를 `max_len=32`로 맞춘다.

### SentimentLSTM 모델 정의

~~~python
import torch.nn as nn

class SentimentLSTM(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=0)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        embedded = self.embedding(x)
        lstm_out, (hidden, cell) = self.lstm(embedded)
        out = self.fc(hidden[-1])
        return out
~~~

- `nn.Embedding`: 단어 번호를 `embedding_dim` 크기의 임베딩 벡터로 변환하며 `padding_idx=0`으로 설정된 패딩 토큰은 학습 대상에서 제외한다.
- `nn.LSTM`: `batch_first=True` 설정을 통해 입력 형태를 `(batch_size, sequence_length, embedding_dim)`으로 받는다.
- 마지막 Time Step의 은닉 상태인 `hidden[-1]`을 추출하여 선형 레이어를 통과시킨 뒤 최종 1개의 점수를 출력한다.

### LSTM 모델 학습 및 평가

~~~python
vocab_size = 20000
embedding_dim = 128
hidden_dim = 256

model = SentimentLSTM(vocab_size, embedding_dim, hidden_dim).to(device)
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

epochs = 20
patience = 3
patience_counter = 0
best_val_loss = float("inf")

for epoch in range(epochs):
    model.train()
    running_train_loss = 0.0

    for sequences, labels in train_loader:
        sequences = sequences.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()
        outputs = model(sequences)
        loss = criterion(outputs, labels.float().unsqueeze(1))
        loss.backward()
        optimizer.step()

        running_train_loss += loss.item()

    model.eval()
    running_val_loss = 0.0
    with torch.no_grad():
        for sequences, labels in val_loader:
            sequences = sequences.to(device)
            labels = labels.to(device)
            outputs = model(sequences)
            loss = criterion(outputs, labels.float().unsqueeze(1))
            running_val_loss += loss.item()

    epoch_val_loss = running_val_loss / len(val_loader)

    if epoch_val_loss < best_val_loss:
        best_val_loss = epoch_val_loss
        patience_counter = 0
        torch.save(model.state_dict(), "best_movie_model.pth")
    else:
        patience_counter += 1

    if patience_counter >= patience:
        print("Early Stopping")
        break

model.load_state_dict(torch.load("best_movie_model.pth"))
model.eval()

correct = 0
total = 0
threshold = 0.6

with torch.no_grad():
    for sequences, labels in test_loader:
        sequences = sequences.to(device)
        labels = labels.to(device)
        outputs = model(sequences)
        probabilities = torch.sigmoid(outputs)
        predictions = (probabilities >= threshold).int()
        correct += (predictions == labels.unsqueeze(1)).sum().item()
        total += labels.size(0)

test_accuracy = (correct / total) * 100
~~~

- 이진 분류 작업을 수행하기 위해 손실 함수로 `BCEWithLogitsLoss`를 지정한다.
- 모델 출력 형태인 `(batch_size, 1)`과 일치시키기 위해 정답 텐서를 `labels.float().unsqueeze(1)` 형태로 가공하여 손실을 계산한다.
- 추론 시점에는 `torch.sigmoid(outputs)`를 적용해 확률값을 얻고 기준 임계값(`threshold = 0.6`) 이상인 경우를 긍정(1), 미만인 경우를 부정(0)으로 분류한다.

# 3. 비교 정리

| 구분 | Fashion MNIST (MLP) | 영화 리뷰 감정 분석 (LSTM) |
|---|---|---|
| 입력 데이터 | 2차원 이미지 데이터 (28 x 28) | 시퀀스 텍스트 데이터 (단어 나열) |
| 모델 구조 | MLP (다층 퍼셉트론) | LSTM (순환 신경망 계열) |
| 전처리 단계 | `ToTensor()` 텐서 변환, 정규화 | Tokenization, Vocab 매핑, Padding |
| 핵심 레이어 | `Flatten`, `Linear`, `ReLU`, `Dropout` | `Embedding`, `LSTM`, `Linear` |
| 출력 형태 | 10개 클래스별 로짓 점수 | 1차원 이진 분류 로짓 점수 |
| 문제 유형 | 다중 분류 (Multi-class Classification) | 이진 분류 (Binary Classification) |
| 손실 함수 | `nn.CrossEntropyLoss` | `nn.BCEWithLogitsLoss` |
| 최종 판단 방식 | `torch.max(outputs, 1)` 최댓값 인덱스 | `torch.sigmoid` 적용 후 Threshold 비교 |

# 4. 전체 흐름 정리

## Fashion MNIST 파이프라인

~~~text
의류 이미지 (28 x 28)
~~~

# 5. 핵심 정리

## 핵심 코드

~~~python
# 가중치 업데이트 기본 3단계
optimizer.zero_grad()
loss.backward()
optimizer.step()

# 평가 시 필수 구문
model.eval()
with torch.no_grad():
    outputs = model(inputs)

# 모델 저장 및 복원
torch.save(model.state_dict(), "model.pth")
model.load_state_dict(torch.load("model.pth"))
~~~

- `optimizer.zero_grad()`는 누적되는 이전 그래디언트를 비운다.
- `loss.backward()`는 역전파를 통해 파라미터별 변화도를 계산한다.
- `optimizer.step()`은 산출된 변화도를 바탕으로 가중치를 실제로 수정한다.
- `torch.no_grad()`는 가중치 갱신이 필요 없는 검증 및 테스트 단계에서 불필요한 연산 그래프 생성을 차단한다.

## 핵심 개념

- MLP는 정적 형태의 데이터를 다루는 데 적합하며 `Flatten`을 통해 평탄화 과정을 거친다.
- 시계열 및 텍스트 데이터는 순서 정보가 필수적이므로 `Embedding`과 `LSTM` 레이어를 활용해 가변적 문맥을 처리한다.
- `CrossEntropyLoss`는 내부적으로 Softmax 연산을 포함하고 다중 분류에 쓰인다.
- `BCEWithLogitsLoss`는 내부적으로 Sigmoid 연산을 포함하므로 모델 마지막에 수동으로 Sigmoid를 통과시키지 않는다.
- Early Stopping을 적용하면 검증 손실이 지속해서 개선되지 않을 때 학습을 멈춰 과적합을 차단할 수 있다.

# 6. 느낀 점

오늘은 이미지 데이터와 텍스트 데이터가 서로 다른 방식으로 전처리되고 모델에 전달되는 전체 파이프라인을 학습했다.

Fashion MNIST 실습에서는 2차원 이미지를 `Flatten`을 이용해 1차원으로 펼친 후 `Linear` 레이어를 연결하여 다중 분류를 수행했다.

반면 영화 리뷰 실습에서는 단어의 순서와 문맥을 보존하기 위해 Tokenization, Vocabulary 매핑, Padding을 차례로 적용하고 `Embedding`과 `LSTM`을 결합했다.

특히 순전파, 손실 계산, 역전파, 가중치 업데이트로 이어지는 학습 루프의 뼈대와 더불어 검증 단계에서 `model.eval()`과 `torch.no_grad()`를 선언해야 하는 이유를 정리할 수 있었다.

앞으로도 단순히 코드를 실행하는 것에 그치지 않고 데이터의 형태가 각 레이어를 통과하며 어떻게 변환되는지 점검하면서 학습할 계획이다.
