# 1. 핵심 개념

## 가중치(Weight)

신경망에서 가중치는 각 입력 데이터가 결과에 얼마나 영향을 주는지를 나타내는 값이다.

처음에는 가중치가 무작위 값으로 초기화된다.

```text
무작위 가중치
      ↓
예측
      ↓
Loss 계산
      ↓
Gradient 계산
      ↓
Optimizer
      ↓
가중치 수정
```

학습을 반복하면서 가중치는 점점 좋은 값으로 변경된다.

---

## 손실(Loss)

Loss는 모델의 예측과 실제 정답이 얼마나 다른지를 나타내는 값이다.

```text
예측값과 정답이 비슷함
→ Loss가 작음

예측값과 정답이 많이 다름
→ Loss가 큼
```

모델 학습의 목표는 Loss를 줄이는 것이다.

---

## Gradient

Gradient는 Loss를 줄이기 위해 가중치를 어느 방향으로 수정해야 하는지 알려주는 값이다.

```text
Loss
 ↓
Gradient 계산
 ↓
가중치를 어느 방향으로 수정할지 결정
```

---

## Optimizer

Optimizer는 Gradient를 이용해서 실제로 가중치를 수정한다.

예를 들어:

```python
optimizer.step()
```

을 실행하면 계산된 Gradient를 바탕으로 모델의 가중치가 업데이트된다.

대표적인 Optimizer로는 다음과 같은 것들이 있다.

* SGD
* Adam

---

## 역전파(Backpropagation)

역전파는 Loss를 기준으로 각 가중치가 얼마나 수정되어야 하는지 계산하는 과정이다.

PyTorch에서는 다음 코드로 실행한다.

```python
loss.backward()
```

전체 학습 과정은 다음과 같다.

```text
입력 데이터
    ↓
순전파
    ↓
예측값
    ↓
Loss 계산
    ↓
역전파
    ↓
Gradient 계산
    ↓
Optimizer
    ↓
가중치 업데이트
```

# 3. MLP 모델 만들기

이미지는 `28 × 28` 크기이다.

먼저 이미지를 1차원으로 변환해야 한다.

```text
28 × 28
   ↓
Flatten
   ↓
784
```

왜냐하면 다음과 같기 때문이다.

```text
28 × 28 = 784
```

---

## 3-1. 모델 구조

```python
import torch.nn as nn

class AdvancedFashionClassifier(nn.Module):

    def __init__(self):
        super().__init__()

        # 28 × 28 → 784
        self.flatten = nn.Flatten()

        # 은닉층
        self.hidden_layer = nn.Linear(784, 64)

        # 활성화 함수
        self.relu = nn.ReLU()

        # Dropout
        self.dropout = nn.Dropout(p=0.2)

        # 출력층
        self.output_layer = nn.Linear(64, 10)

    def forward(self, x):

        out = self.flatten(x)
        out = self.hidden_layer(out)
        out = self.relu(out)
        out = self.dropout(out)
        out = self.output_layer(out)

        return out
```

전체 구조는 다음과 같다.

```text
28 × 28 이미지
      ↓
Flatten
      ↓
784개 입력값
      ↓
Linear
784 → 64
      ↓
ReLU
      ↓
Dropout
      ↓
Linear
64 → 10
      ↓
10개 클래스 점수
```

---

# 3-2. Flatten

```python
self.flatten = nn.Flatten()
```

이미지의 형태를 변경한다.

```text
입력

28 × 28
   ↓

출력

784
```

이미지의 픽셀을 한 줄로 펼친다고 생각하면 된다.

---

# 3-3. Linear

```python
self.hidden_layer = nn.Linear(784, 64)
```

784개의 입력을 받아 64개의 뉴런으로 전달한다.

```text
784
 ↓
Linear
 ↓
64
```

64개의 뉴런이 중간에서 특징을 학습하기 때문에 이 층을 은닉층이라고 한다.

---

# 3-4. ReLU

```python
self.relu = nn.ReLU()
```

ReLU는 활성화 함수이다.

간단하게 보면 다음과 같다.

```text
음수 → 0
양수 → 그대로
```

예를 들어:

```text
-5 → 0
-1 → 0
 2 → 2
 8 → 8
```

ReLU를 사용하면 신경망이 더 복잡한 패턴을 학습할 수 있다.

---

# 3-5. Dropout

```python
self.dropout = nn.Dropout(p=0.2)
```

훈련할 때 일부 뉴런을 랜덤하게 사용하지 않는다.

`p=0.2`는 일부 뉴런을 Dropout한다는 의미이다.

Dropout은 특정 뉴런에 너무 의존하는 것을 줄여 과대적합을 방지하는 데 도움을 준다.

훈련할 때와 평가할 때 동작이 다르다.

```text
model.train()
→ Dropout 적용

model.eval()
→ Dropout 적용하지 않음
```


# 6. 모델 학습 과정

```python
for images, labels in train_loader:

    images = images.to(device)
    labels = labels.to(device)

    optimizer.zero_grad()

    outputs = model(images)

    loss = criterion(outputs, labels)

    loss.backward()

    optimizer.step()
```

학습 과정은 다음 순서로 진행된다.

---

## 6-1. Gradient 초기화

```python
optimizer.zero_grad()
```

PyTorch는 이전 Gradient를 계속 저장하기 때문에 새로운 Batch를 학습하기 전에 초기화해야 한다.

---

## 6-2. 순전파

```python
outputs = model(images)
```

입력 이미지를 모델에 전달하여 예측값을 만든다.

```text
이미지
 ↓
모델
 ↓
예측값
```

---

## 6-3. Loss 계산

```python
loss = criterion(outputs, labels)
```

모델의 예측과 실제 정답을 비교하여 Loss를 계산한다.

---

## 6-4. 역전파

```python
loss.backward()
```

Loss를 줄이기 위해 각 가중치의 Gradient를 계산한다.

---

## 6-5. 가중치 업데이트

```python
optimizer.step()
```

Optimizer가 Gradient를 이용하여 가중치를 수정한다.

---

# 7. Epoch Loss 계산

각 Batch의 Loss를 모두 더한 후 평균을 계산한다.

```python
running_loss += loss.item()

epoch_loss = running_loss / len(train_loader)
```

```text
Batch Loss
   ↓
모두 더함
   ↓
Batch 개수로 나눔
   ↓
한 Epoch의 평균 Loss
```

# 8. Validation

```python
with torch.no_grad():

    for images, labels in val_loader:
```

# 9. Early Stopping

학습을 너무 오래 하면 Training 데이터에는 잘 맞지만 새로운 데이터에서는 성능이 떨어질 수 있다.

이를 과대적합이라고 한다.

Early Stopping은 Validation Loss가 개선되지 않으면 학습을 중단하는 방법이다.

```python
epochs = 20
patience = 3

patience_count = 0

best_val_loss = float('inf')
```

`float('inf')`는 무한대를 의미한다.

처음에는 가장 좋은 Validation Loss가 없기 때문에 매우 큰 값으로 시작한다.

```python
if epoch_val_loss < best_val_loss:

    best_val_loss = epoch_val_loss

    patience_count = 0

    torch.save(
        model.state_dict(),
        "best_fashion_model.pth"
    )
```

Validation Loss가 개선되면:

```text
최고 Loss 업데이트
+
patience_count 초기화
+
모델 저장
```

개선되지 않으면:

```python
patience_count += 1
```

그리고 설정한 횟수만큼 개선되지 않으면 종료한다.

```python
if patience_count >= patience:

    print("조기 종료")

    break
```

# 11. Fashion MNIST 테스트

```python
correct = 0
total = 0

with torch.no_grad():

    for images, labels in test_loader:

        images = images.to(device)
        labels = labels.to(device)

        outputs = model(images)

        _, predicted = torch.max(outputs.data, 1)

        total += labels.size(0)

        correct += (
            predicted == labels
        ).sum().item()
```

`torch.max()`를 사용하여 10개의 출력 점수 중 가장 큰 값을 가진 클래스를 선택한다.

```text
출력

[0.2, 1.5, 0.1, 3.8, ...]

       ↓

가장 큰 값

3.8

       ↓

해당 클래스 선택
```

정확도는 다음과 같이 계산한다.

```python
test_accuracy = correct / total * 100
```

---

# 13. Time Step

RNN은 데이터를 한 번에 처리하지 않고 순서대로 하나씩 처리한다.

예를 들어:

```text
나는 밥을 먹었다
```

라면:

```text
Time Step 1 → 나는
Time Step 2 → 밥을
Time Step 3 → 먹었다
```

즉, 타임스텝은 데이터를 하나씩 처리하는 순서 또는 시점이다.

---

# 14. Hidden State

Hidden State는 이전까지 처리한 정보를 기억하는 값이다.

```text
나는
 ↓
h1

밥을 + h1
 ↓
h2

먹었다 + h2
 ↓
h3
```

RNN은 현재 입력값과 이전 Hidden State를 이용해서 새로운 Hidden State를 만든다.

쉽게 생각하면:

```text
Hidden State
=
현재까지 읽은 내용의 요약
```

이라고 이해할 수 있다.

# 15. One-Hot Encoding

컴퓨터는 단어를 그대로 계산할 수 없기 때문에 숫자로 변환해야 한다.

예를 들어:

```text
사과
바나나
딸기
포도
```

를 One-Hot Encoding 하면:

```text
사과   → [1, 0, 0, 0]

바나나 → [0, 1, 0, 0]

딸기   → [0, 0, 1, 0]

포도   → [0, 0, 0, 1]
```

하나의 위치만 1이고 나머지는 모두 0이다.

---

# 16. 차원의 저주

단어가 많아지면 One-Hot Vector의 크기도 커진다.

예를 들어 단어가 10,000개라면:

```text
사과

↓

[1, 0, 0, 0, 0, 0, ...]
```

10,000개의 숫자가 필요하다.

대부분의 값이 0이기 때문에 비효율적이다.

차원이 너무 커지면서 데이터가 희소해지고 계산이 어려워지는 문제를 차원의 저주라고 한다.

---

# 17. Embedding

Embedding은 단어를 작은 차원의 숫자 벡터로 변환하는 방법이다.

예를 들어:

```text
사과

↓

[0.2, -0.4, 0.7]
```

```text
바나나

↓

[0.3, -0.3, 0.6]
```

단어가 10,000개여도 각 단어를 128개의 숫자로 표현할 수 있다.

RNN에서는 일반적으로 다음과 같이 사용한다.

```text
문장
 ↓
단어 분리
 ↓
단어 번호
 ↓
Embedding
 ↓
숫자 벡터
 ↓
RNN / LSTM
```

# 18. 임베딩 가중치 행렬

임베딩은 모든 단어의 벡터를 하나의 행렬로 저장한다.

예를 들어:

```text
단어 0 → [0.2, 0.5, -0.1]

단어 1 → [0.3, 0.4, -0.2]

단어 2 → [-0.7, 0.1, 0.8]
```

이 벡터들을 모아놓은 것이 임베딩 가중치 행렬이다.

PyTorch에서:

```python
nn.Embedding(20000, 128)
```

의 의미는 다음과 같다.

```text
20,000개 단어

각 단어를

128개의 숫자로 표현
```

즉, 임베딩 가중치 행렬은:

```text
20,000 × 128
```

크기를 가진다.

---

# 19. 무작위 초기화

임베딩 벡터나 신경망의 가중치는 처음부터 좋은 값을 가지고 있지 않다.

처음에는 무작위 값으로 시작한다.

```text
처음

사과 → [0.12, -0.31, 0.08]

학습
 ↓

가중치 수정
 ↓

학습 후

사과 → 새로운 값
```

즉, 무작위 초기화는 학습 전에 가중치를 랜덤한 값으로 설정하는 것이다.

# 22. Vocabulary 만들기

텍스트 데이터를 모델에 입력하기 위해 단어에 번호를 부여한다.

```python
from collections import Counter

vocab_size = 20000

all_words = []

for text in train_df["document"]:

    all_words.extend(
        text.split()
    )
```

모든 리뷰를 단어 단위로 분리한다.

```python
counts = Counter(all_words)
```

단어가 등장한 횟수를 계산한다.

자주 등장하는 단어부터 Vocabulary에 저장한다.

```python
vocab = {
    word: i + 2
    for i, (word, _) in enumerate(
        counts.most_common(vocab_size - 2)
    )
}
```

---

# 23. PAD와 UNK

Vocabulary에는 특별한 토큰을 사용한다.

```python
vocab["<PAD>"] = 0

vocab["<UNK>"] = 1
```

의미는 다음과 같다.

```text
<PAD> = 0
→ 문장 길이를 맞추기 위한 빈칸

<UNK> = 1
→ Vocabulary에 없는 단어
```

실제 단어는 2번부터 번호를 사용한다.

---

# 24. Padding

문장은 길이가 모두 다르다.

예를 들어:

```text
나는 영화를 봤다
→ 3개 단어

오늘 친구와 재미있는 영화를 봤다
→ 5개 단어
```

Batch로 학습하기 위해 문장의 길이를 맞춰야 한다.

여기서는 최대 길이를 32로 설정한다.

```python
max_len = 32
```

문장이 짧으면:

```text
나는 영화를 봤다

↓

[단어, 단어, 단어, PAD, PAD, PAD ...]
```

남는 부분을 0으로 채운다.

```python
ids += [0] * (
    self.max_len - len(ids)
)
```

# 25. Custom Dataset

텍스트 데이터를 PyTorch에서 사용할 수 있도록 Dataset 클래스를 만든다.

```python
class NSMCDataset(Dataset):

    def __init__(
        self,
        df,
        vocab,
        max_len=32
    ):

        self.labels = df["label"].values

        self.texts = (
            df["document"]
            .astype(str)
            .values
        )

        self.vocab = vocab

        self.max_len = max_len
```

`__getitem__()`에서는 하나의 리뷰를 가져온다.

```python
text = self.texts[idx]

label = self.labels[idx]
```

문장을 단어로 나눈다.

```python
tokens = text.split()
```

단어를 번호로 변환한다.

```python
ids = [
    self.vocab.get(token, 1)
    for token in tokens[:self.max_len]
]
```

Vocabulary에 없는 단어는 `<UNK>`인 1번을 사용한다.

# 26. LSTM 모델

텍스트 감정 분석 모델은 다음 구조로 만들었다.

```text
단어 번호
 ↓
Embedding
 ↓
LSTM
 ↓
마지막 Hidden State
 ↓
Linear
 ↓
긍정 / 부정 점수
```

코드는 다음과 같다.

```python
class SentimentLSTM(nn.Module):

    def __init__(
        self,
        vocab_size,
        embedding_dim,
        hidden_dim
    ):

        super().__init__()

        self.embedding = nn.Embedding(
            vocab_size,
            embedding_dim,
            padding_idx=0
        )

        self.lstm = nn.LSTM(
            embedding_dim,
            hidden_dim,
            batch_first=True
        )

        self.fc = nn.Linear(
            hidden_dim,
            1
        )
```

---

# 27. Embedding Layer

```python
self.embedding = nn.Embedding(
    vocab_size,
    embedding_dim,
    padding_idx=0
)
```

단어 번호를 임베딩 벡터로 변환한다.

예를 들어:

```text
단어 번호

5
↓

Embedding

↓

[0.2, -0.5, 0.7, ...]
```

`padding_idx=0`은 0번인 `<PAD>`를 Padding 값으로 사용한다는 의미이다.

---

# 28. LSTM Layer

```python
self.lstm = nn.LSTM(
    embedding_dim,
    hidden_dim,
    batch_first=True
)
```

Embedding된 단어를 순서대로 처리한다.

```text
단어 1
 ↓
Hidden State

단어 2 + 이전 Hidden State
 ↓
새로운 Hidden State

단어 3 + 이전 Hidden State
 ↓
새로운 Hidden State
```

`batch_first=True`를 사용하면 데이터 형태를 다음과 같이 사용할 수 있다.

```text
(batch_size, sequence_length, embedding_dim)
```

예를 들어:

```text
(64, 32, 128)
```

의 의미는:

```text
64 → Batch 크기

32 → 문장 길이

128 → Embedding 차원
```

---

# 29. 마지막 Hidden State

LSTM은 문장을 순서대로 읽으면서 Hidden State를 업데이트한다.

```python
lstm_out, (hidden, cell) = self.lstm(
    embedded
)
```

최종 Hidden State를 가져온다.

```python
hidden[-1]
```

이는 문장을 모두 읽은 후의 최종 기억이라고 볼 수 있다.

이 값을 Linear Layer에 전달한다.

```python
out = self.fc(hidden[-1])
```

# 33. Sigmoid와 Threshold

모델의 출력값은 바로 확률이 아닐 수 있다.

그래서 Sigmoid를 사용한다.

```python
probabilities = torch.sigmoid(outputs)
```

Sigmoid를 사용하면 값이 다음 범위로 변환된다.

```text
0.0 ~ 1.0
```

예를 들어:

```text
0.8
```

은 긍정일 가능성이 높다는 의미로 사용할 수 있다.

Threshold를 0.6으로 설정했다.

```python
threshold = 0.6
```

```python
predictions = (
    probabilities >= threshold
).int()
```

즉:

```text
0.6 이상 → 긍정(1)

0.6 미만 → 부정(0)
```

# 느낀 점

오늘은 이미지 분류와 텍스트 감정 분석을 비교하면서 데이터의 종류에 따라 사용하는 모델 구조가 달라진다는 것을 배웠다.

이미지 분류에서는 이미지를 숫자로 변환하고 Flatten을 사용하여 1차원으로 만든 후 Linear Layer를 이용했다.

반면 텍스트 데이터는 단어의 순서가 중요하기 때문에 단어를 순서대로 처리하고 이전 정보를 기억할 수 있는 RNN과 LSTM을 사용한다.

특히 오늘 새롭게 이해한 내용은 다음과 같다.

```text
타임스텝
= 데이터를 순서대로 하나씩 처리하는 시점

Hidden State
= 이전까지 처리한 정보를 기억하는 값

Embedding
= 단어 번호를 의미를 가진 숫자 벡터로 변환하는 것

임베딩 가중치 행렬
= 모든 단어의 임베딩 벡터를 저장한 행렬

무작위 초기화
= 학습 전에 가중치를 랜덤한 값으로 시작하는 것
```

아직 LSTM 내부에서 Hidden State와 Cell State가 정확히 어떻게 계산되는지는 더 공부해야 하지만, 전체적인 데이터 흐름은 이전보다 이해할 수 있게 되었다.

다음에는 LSTM의 Cell State와 Gate 구조를 더 자세히 공부해보고 싶다.
