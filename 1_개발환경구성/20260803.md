# VS Code, Git 설치 및 GitHub 가입

## 1. 이번에 할 것

공부를 시작하면서 필요한 프로그램들을 설치하고 기본적인 환경을 준비한다.  
설치할 프로그램은 다음과 같다.
- VS Code
- Git
- GitHub 가입 
<br>
<br>

## 2. 설치하는 이유

### VS Code

Python 코드를 작성하기 위해 사용한다.

### Git

작성한 코드나 파일의 변경 내용을 기록하고 관리하기 위해 사용한다.

### GitHub

공부하면서 작성한 코드와 TIL을 저장하고 다른 곳에서도 확인할 수 있도록 사용한다.
<br>
<br>

## 3. 설치 방법

### 3-1. VS Code 설치

1. VS Code 공식 홈페이지에 접속한다.
2. 노트북에 맞는 (Windows or Mac) 설치 파일을 다운로드한다.
3. 다운로드한 설치 파일을 실행한다.
4. 설치 과정의 안내에 따라 설치한다.
5. 설치가 완료되면 VS Code를 실행한다.  

[VS Code 공식 홈페이지](https://code.visualstudio.com/)

설치가 완료되면 VS Code를 실행하여 정상적으로 작동하는지 확인한다.



### 3-2. Git 설치

1. Git 공식 홈페이지에 접속한다.
2. 노트북에 맞는 Git 설치 파일을 다운로드한다.
3. 설치 파일을 실행한다.
4. 설치 과정의 기본 설정을 확인하면서 설치한다.
5. 설치가 완료되면 터미널을 실행한다.

설치가 정상적으로 되었는지 다음 명령어로 확인한다.

`git --version`

Git의 버전이 출력되면 정상적으로 설치된 것이다.

[Git 공식 홈페이지](https://git-scm.com/)



### 3-3. GitHub 가입

Git으로 관리하는 파일을 온라인에 저장하고 관리하기 위해 GitHub 계정을 만든다.

1. GitHub 홈페이지에 접속한다.
2. `Sign up`을 선택한다.
3. 이메일 주소를 입력한다.
4. 비밀번호와 사용자 이름을 설정한다.
5. 이메일 인증을 진행한다.
6. 가입을 완료한다.

[GitHub 공식 홈페이지](https://github.com/)
<br>
<br>

## 4. 설치 확인

각 프로그램이 정상적으로 설치되었는지 확인한다.

### VS Code

VS Code를 실행하여 정상적으로 프로그램이 열리는지 확인한다.

### Git

`git --version`
<br>
<br>
## 5. 정리

이번에 코드를 작성하고 관리하기 위한 기본 프로그램을 설치했다.

| 프로그램 | 역할 |
|---|---|
| VS Code | 코드 작성 및 수정 |
| Git | 코드와 파일의 변경 내용 관리 |

앞으로 VS Code에서 Git을 이용하여 변경 사항을 기록한 뒤 GitHub에 TIL을 정리할 예정이다.
