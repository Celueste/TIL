# uv로 Python 가상환경 만들기

## 1. 이번에 할 것

uv를 이용하여 Python 프로젝트를 만들고 가상환경을 구성한다.
프로젝트에 `pandas` 의존성을 추가한다.
<br>
<br>

## 2. 가상환경을 사용하는 이유

- 프로젝트마다 필요한 Python 환경을 따로 관리하기 위해 사용한다.
- 프로젝트마다 필요한 패키지를 독립적으로 관리할 수 있다.
- 다른 프로젝트의 패키지와 충돌하는 것을 방지할 수 있다.
<br>
<br>

## 3. 가상환경 만드는 방법

### 3-1. Python 프로젝트 생성
1. 파이썬 프로젝트 전용 공간 생성 및 이동
    ```
    mkdir first-project
    cd first-project
    ```
2. 프로젝트 초기화 명령
    ```
    uv init
    ```
3.  uv init 시 자동으로 생성되는 파일 구조:
    - `pyproject.toml`: 프로젝트 이름, 버전, 라이브러리 의존성을 선언적으로 기록하는 모던 파이썬 표준 명세서
    - `.python-version`: 이 프로젝트에서 사용할 타깃 파이썬 버전을 명시해 두는 텍스트 파일
    - `main.py`: 기본 샘플 코드가 담겨 있는 첫 번째 파이썬 실행 파일
    
4. 특정 파이썬 버전 지정하기
    ```
    uv init ex_venv2 --python 3.14
    ```
    - `uv init` : 새로운 Python 프로젝트를 만든다.
    - `ex_venv2` : 프로젝트 이름이다.
    - `--python 3.14` : 사용할 Python 버전을 지정한다.  

    명령어를 실행하면 `ex_venv2` 폴더가 생성된다.

5. 이미 생성된 프로젝트의 버전 변경하는 방법
    ```
    uv python pin 3.12  # 현재 프로젝트의 파이썬 버전을 3.12로 변경
    ```


### 3-3. 가상환경 설정 및 활성화
1. 프로젝트 폴더로 이동
    ```
    cd ex_venv2
    ````
    생성된 프로젝트 폴더로 이동한다.

2. 가상환경 생성
    ```
    uv venv
    ```
    프로젝트 폴더 안에 `.venv` 가상환경이 생성된다.

3. 가상환경 활성화
    ```
    .venv\Scripts\activate
    ```
    가상환경이 활성화되면 터미널 앞에 `(.venv)`가 표시된다.

    ``` 
    (.venv) C:\...\ex_venv2>
    ```

### 3-4. 가상환경 동기화
1. 가상환경 생성 및 동기화
    ```
    uv sync
    ```
    - `pyproject.toml`에 정의된 의존성을 확인
    - 필요한 패키지를 설치
    - `.venv` 가상환경을 생성 및 동기화

2. 가상환경 활성화

    ```
    .venv\Scripts\activate
    ```
    활성화되면 터미널 앞에 다음과 같이 표시될 수 있음.

    ```
    (.venv)
    ```
3. 가상환경 비활성화
    ```powershell
    .venv\Scripts\deactivate.bat
    ```
    또는:
    ```
    deactivate
    ```
4. Python 버전 고정
    ```
    uv python pin 3.12
    ```
    - 프로젝트에서 사용할 Python 버전을 지정
    - 프로젝트별 Python 버전을 고정하여 환경 차이로 인한 문제를 줄일 수 있음

### 3-5. 파이썬 실행 및 종료
1. Python 코드 실행
    ```
    uv run main.py
    ```
    - 프로젝트의 가상환경을 기준으로 Python 파일을 실행

2. Python 실행
    ```
    python
    ```
3. Python 종료
    ```python
    exit()
    ```

## 4. pandas 패키지 설치

```
uv add pandas
```

- 프로젝트에 `pandas` 의존성을 추가
- 패키지를 추가할 때 `uv add` 사용

예:

```
uv add requests
uv add numpy
```

## 5. 정리

앞으로 Python 프로젝트를 시작할 때 uv를 이용해 가상환경을 만들고, 프로젝트별로 필요한 Python 환경과 패키지를 관리해야겠다.
