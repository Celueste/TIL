# JavaScript 개발 환경 구성

## 오늘 배운 내용 요약

JavaScript를 Jupyter Notebook에서 실행하기 위해 Node.js, NVM, Jupyter, ijavascript를 설치하고 개발 환경을 구성했다.

## 1. NVM 설치

여러 버전의 Node.js를 관리하기 위해 NVM(Node Version Manager)을 설치했다.

Windows에서는 NVM 설치 파일을 다운로드하여 설치하고, VS Code를 다시 실행한 후 Node.js 20 버전을 설치했다.

```bash
nvm install 20
nvm use 20
```

설치가 정상적으로 되었는지 버전을 확인했다.

```bash
node -v
npm -v
```

## 2. Jupyter 설치

Jupyter Notebook에서 JavaScript를 실행하기 위한 환경을 설치했다.

```bash
uv tool install --with jupyter jupyter-core
```

## 3. JavaScript 프로젝트 생성

실습용 프로젝트 폴더를 만들고 해당 폴더로 이동했다.

```bash
mkdir js-study
cd js-study
```

npm을 이용해 프로젝트를 초기화했다.

```bash
npm init -y
```

실행하면 프로젝트의 기본 설정을 관리하는 `package.json` 파일이 생성된다.

## 4. ijavascript 설치

Jupyter Notebook에서 JavaScript를 실행하기 위해 `ijavascript`를 프로젝트에 설치했다.

```bash
npm install --save-dev ijavascript
```

`--save-dev` 옵션을 사용하면 해당 패키지를 개발용 패키지로 설치할 수 있다.

## 5. JavaScript 커널 등록

설치한 ijavascript를 Jupyter Notebook에서 사용할 수 있도록 커널을 등록했다.

```bash
npx ijsinstall
```

커널 등록 후 Jupyter Notebook에서 `JavaScript (Node.js)` 커널을 선택하면 JavaScript 코드를 실행할 수 있다.

## 6. 이번 실습에서 사용한 주요 명령어

```bash
# Node.js 20 설치 및 사용
nvm install 20
nvm use 20

# 버전 확인
node -v
npm -v

# Jupyter 설치
uv tool install --with jupyter jupyter-core

# 프로젝트 생성
mkdir js-study
cd js-study

# npm 프로젝트 초기화
npm init -y

# ijavascript 설치
npm install --save-dev ijavascript

# Jupyter JavaScript 커널 등록
npx ijsinstall
```

## 느낀 점

이번 실습에서는 JavaScript를 실행하기 위한 개발 환경을 직접 설치하고 구성했다. NVM으로 Node.js 20을 설치하고, Jupyter와 ijavascript를 연결하면서 JavaScript를 Jupyter Notebook에서 실행할 수 있는 환경을 만들었다. 여러 명령어를 직접 입력하면서 각각의 설치 과정과 역할을 이해할 수 있었다.
