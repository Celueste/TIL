## 1. 정규 표현식 기본 개념

### 정규 표현식이란?

정규 표현식(Regular Expression)은 문자열에서 특정한 규칙이나 패턴을 가진 데이터를 추출, 검증, 치환할 때 사용하는 형식 언어이다. 복잡한 반복문이나 조건문 없이도 특정 형식을 가진 문자열을 간결한 코드로 처리할 수 있다.

### 기본 사용 예시

~~~python
import re

# 특정 식별 번호 패턴 치환 실습
data = """
park [RRN Omitted]
kim  [RRN Omitted]
"""

# 앞 6자리 숫자와 뒤 7자리 숫자를 탐지하는 패턴 객체 생성
pattern = re.compile(r"(\d{6})[-]\d{7}")

# 첫 번째 그룹(\g<1>)만 남기고 뒷자리를 마스킹 처리
result = pattern.sub(r"\g<1>-*******", data)
print(result)
~~~

- `re.compile()`을 사용하여 정규 표현식 패턴을 사전에 컴파일한다.
- `pattern.sub()`을 활용하여 패턴에 일치하는 대상 문자열을 마스킹 규칙으로 치환한다.

## 2. 정규 표현식 메타 문자 문법

메타 문자(Meta Characters)는 원래 문자가 가진 의미 대신 특정한 규칙을 표현하는 특수 기호이다.

### 문자 클래스 (`[]`)

대괄호 안에 포함된 문자 중 하나와 매치된다.

~~~text
[abc]  : 'a', 'b', 'c' 중 문자 1개와 일치
[a-z]  : 알파벳 소문자 범위 일치
[0-9]  : 숫자 범위 일치
~~~

- 자주 사용하는 단축 문자 클래스는 다음과 같다.
  - `\d`: 숫자와 일치 (`[0-9]`와 동일)
  - `\D`: 숫자가 아닌 문자와 일치 (`[^0-9]`와 동일)
  - `\w`: 영문자, 숫자, 밑줄(`_`)과 일치 (`[a-zA-Z0-9_]`와 동일)
  - `\W`: 영문자, 숫자, 밑줄이 아닌 문자와 일치
  - `\s`: 공백 문자(스페이스, 탭, 줄바꿈)와 일치
  - `\S`: 공백 문자가 아닌 문자와 일치

### 임의의 문자 (`.`)

- `.`은 줄바꿈(`\n`)을 제외한 모든 문자 1개와 매치된다.
- 문자 그대로의 점을 찾고 싶을 때는 백슬래시를 붙여 `\.` 형태로 이스케이프한다.

### 반복 수량자

패턴이 반복되는 횟수를 지정한다.

- `*`: 직전 패턴이 0회 이상 반복된다.
- `+`: 직전 패턴이 1회 이상 반복된다.
- `?`: 직전 패턴이 0회 또는 1회 존재한다.
- `{m, n}`: 직전 패턴이 최소 `m`회부터 최대 `n`회까지 반복된다.

### 위치 및 논리 조건

- `|`: 논리적 OR 조건으로, `A|B`는 A 또는 B와 일치한다.
- `^`: 문자열의 시작 위치를 의미한다.
- `$`: 문자열의 끝 위치를 의미한다.
- `\b`: 단어의 경계(Word Boundary)를 나타내며 독립된 단어를 식별할 때 사용한다.

## 3. re 모듈과 검색 메서드

파이썬에서는 기본 내장 라이브러리인 `re` 모듈을 사용한다.

### 검색 메서드 4종

~~~python
import re

p = re.compile(r"[a-z]+")

# match(): 문자열의 처음부터 일치하는지 검사
print(p.match("python"))     # Match 객체 반환
print(p.match("3 python"))   # None 반환

# search(): 문자열 전체를 탐색하여 처음 일치하는 위치를 찾음
print(p.search("3 python"))  # Match 객체 ('python') 반환

# findall(): 일치하는 모든 문자열을 리스트로 반환
result_list = p.findall("life is too short")
print(result_list)  # ['life', 'is', 'too', 'short']

# finditer(): 일치하는 모든 결과를 Match 객체의 반복자(Iterator)로 반환
for m in p.finditer("life is too short"):
    print(m.group())
~~~

### Match 객체의 주요 메서드

검색에 성공하여 생성된 Match 객체는 매치된 위치와 문자열 정보를 제공한다.

~~~python
m = p.search("3 python")

print(m.group())  # 매치된 실제 문자열 ('python')
print(m.start())  # 매치 시작 인덱스 (2)
print(m.end())    # 매치 종료 인덱스 (8)
print(m.span())   # 매치 시작과 종료 튜플 ((2, 8))
~~~

## 4. 컴파일 옵션과 Raw String

### 주요 컴파일 플래그

`re.compile()`의 두 번째 인자로 플래그를 전달하여 검색 방식을 제어한다.

- `re.DOTALL` (약칭 `re.S`): 줄바꿈 문자(`\n`)까지 포함하여 `.` 메타 문자를 매치한다.
- `re.IGNORECASE` (약칭 `re.I`): 영문 대소문자 구분 없이 매치한다.
- `re.MULTILINE` (약칭 `re.M`): 문자열 전체가 아닌 각 라인 단위로 `^`와 `$` 앵커를 적용한다.
- `re.VERBOSE` (약칭 `re.X`): 정규식 내부의 공백을 무시하고 주석을 작성할 수 있게 하여 가독성을 높인다.

### Raw String (`r"..."`)의 필요성

파이썬 문자열 자체의 이스케이프 규칙과 정규식의 백슬래시(`\`)가 충돌하는 것을 방지하기 위해 사용한다. 문자열 리터럴 앞에 `r`을 붙이면 백슬래시를 이스케이프 처리하지 않고 원형 그대로 정규식 파서에 전달한다.

~~~python
# 권장 작성 스타일
pattern = re.compile(r"\bclass\b")
~~~

## 5. 그룹화와 Lookaround

### 소괄호 그룹화 (`()`)

소괄호로 둘러싸인 패턴은 하나의 단위로 묶이며, 결과에서 개별 그룹별로 추출할 수 있다.

~~~python
import re

p = re.compile(r"(\w+)\s+(\d+[-]\d+[-]\d+)")
m = p.search("park 010-1234-1234")

print(m.group(1))  # 첫 번째 그룹: park
print(m.group(2))  # 두 번째 그룹: 010-1234-1234
~~~

- `(?P<이름>...)` 형식을 사용하면 그룹 번호 대신 명시적인 이름으로 데이터를 추출할 수 있다.

### 전방 탐색 (Lookaround)

조건에 해당하는 패턴이 앞뒤에 존재하는지만 확인하고, 매치 결과 문자열에는 해당 조건을 포함하지 않는다.

- **긍정형 전방 탐색 (`(?=...)`)**: 뒤에 특정 조건이 와야 매치된다.
  - `re.search(r".+(?=:)", "http://google.com").group()` 결과는 `http`이다.
- **부정형 전방 탐색 (`(?!...)`)**: 뒤에 특정 조건이 오지 않아야 매치된다.
  - `.*[.](?!bat$|exe$).*$`는 확장자가 `bat`나 `exe`가 아닌 파일명만 선별한다.

## 6. 문자열 치환과 탐욕적 매칭

### 문자열 치환 (`sub`, `subn`)

~~~python
import re

p = re.compile(r"blue|white|red")

# sub(): 치환된 문자열 반환
result_str = p.sub("colour", "blue socks and red shoes")
print(result_str)  # colour socks and colour shoes

# count 매개변수로 치환 횟수 제한
print(p.sub("colour", "blue socks and red shoes", count=1))

# subn(): (치환된 문자열, 총 치환 횟수) 튜플 반환
result_tuple = p.subn("colour", "blue socks and red shoes")
print(result_tuple)  # ('colour socks and colour shoes', 2)
~~~

### Greedy와 Non-greedy 매칭

- **Greedy (기본값)**: `*`, `+` 등은 조건을 만족하는 한 가장 긴(최대) 범위를 소비하여 매치한다.
- **Non-greedy (`?`)**: 반복 수량자 뒤에 `?`를 붙여 조건을 만족하는 가장 짧은(최소) 범위를 매치한다.

~~~python
import re

html_code = "<html><head><title>Title</title>"

# Greedy 방식: 전체 문자열을 끝까지 탐색
print(re.match(r"<.*>", html_code).group())
# 결과: <html><head><title>Title</title>

# Non-greedy 방식: 가장 가까운 닫는 태그에서 멈춤
print(re.match(r"<.*?>", html_code).group())
# 결과: <html>
~~~

## 7. 비교 정리

### 검색 메서드 특성 비교

| 메서드 | 검색 시작점 및 범위 | 매치 실패 시 반환값 | 주요 용도 |
|---|---|---|---|
| `match()` | 문자열의 첫 번째 인덱스부터 검사 | `None` | 시작 형식이 올바른지 엄격하게 검증할 때 |
| `search()` | 문자열 전체를 탐색 | `None` | 본문 중 특정 패턴이 한 번이라도 등장하는지 찾을 때 |
| `findall()` | 문자열 전체를 반복 탐색 | 빈 리스트 (`[]`) | 일치하는 모든 텍스트 값 자체를 리스트로 수집할 때 |
| `finditer()` | 문자열 전체를 반복 탐색 | 빈 이터레이터 | 매치된 모든 객체의 위치(`span`), 그룹 정보가 필요할 때 |

### 매칭 범위 성향 비교

| 구분 | 문법 표기 | 매칭 원리 | 예시 결과 (`<.*>` vs `<.*?>`) |
|---|---|---|---|
| Greedy | `*`, `+`, `{m,n}` | 가능한 한 최대 길이로 문자열을 탐색 | `<html>...<title>` 전체를 하나의 덩어리로 인식 |
| Non-greedy | `*?`, `+?`, `{m,n}?` | 조건을 만족하는 최소 길이에서 즉시 종료 | 첫 닫는 태그인 `<html>`만 정확하게 분리 |

## 8. 전체 흐름 정리

정규 표현식을 이용한 파이썬 데이터 처리 절차는 다음과 같다.

~~~text
처리 대상 원본 문자열 확인
    |
    v
필요한 규칙 분석 및 메타 문자를 활용한 패턴 작성
    |
    v
re.compile(r"패턴", 옵션)으로 컴파일 객체 생성
    |
    v
목적에 맞는 검색 메서드 호출 (match, search, findall, finditer)
    |
    v
Match 객체 메서드로 결과 확인 (group, span) 또는 sub()로 가공 치환
~~~

### 종합 활용 예시

~~~python
import re

text = "연락처는 010-1234-5678 및 02-987-6543 입니다."

# 전화번호 패턴 정의 (지역번호 2~3자리 - 국번 3~4자리 - 번호 4자리)
phone_pattern = re.compile(r"\b\d{2,3}-\d{3,4}-\d{4}\b")

# 일치하는 모든 연락처 수집
extracted_numbers = phone_pattern.findall(text)
print(extracted_numbers)
# 결과: ['010-1234-5678', '02-987-6543']
~~~

## 9. 핵심 정리

### 핵심 문법 요약

- **문자 클래스**: `\d`(숫자), `\w`(단어 문자), `\s`(공백 문자)
- **수량자**: `*`(0회 이상), `+`(1회 이상), `?`(0~1회), `{m,n}`(범위 반복)
- **위치 한정자**: `^`(시작), `$`(끝), `\b`(단어 경계)
- **그룹 및 확장**: `()`(그룹 지정 및 캡처), `(?=...)`(전방 탐색)
- **치환 및 제어**: `sub()`(문자열 치환), `r"..."`(Raw String 표기법)

## 10. 느낀 점

정규 표현식은 기호가 많아 초반 진입 장벽이 높지만, 각 메타 문자의 약속된 동작 방식을 분해해서 이해하면 문자열 파싱과 정제 작업에 매우 강력한 도구임을 확인했다.
특히 `match()`와 `search()`의 검색 범위 차이, 정규식 작성 시 의도치 않은 탐색 확장을 방지하는 Non-greedy 수량자의 역할, 그리고 `sub()`을 활용한 패턴 마스킹 기술을 명확히 정리할 수 있었다.
앞으로 이메일이나 전화번호와 같은 사용자 입력값 유효성 검증과 텍스트 데이터 전처리 과정에 적극적으로 정규 표현식을 적용해 보아야겠다.
