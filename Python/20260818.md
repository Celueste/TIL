# 1. 객체지향 기본개념
### 1) 객체지향
1. 배우는 이유: 데이터와 그 데이터를 활용하는 기능을 하나로 묶어 체계적으로 관리하고 재사용하기 위해 객체지향 개념을 배운다.
2. 객체지향: 프로그램을 객체(Object) 중심으로 구성하는 프로그래밍 방식

3. 객체의 요소
    - 속성(Attribute): 객체가 가지고 있는 데이터나 특징 → 변수
    - 행위(Method): 객체가 수행할 수 있는 동작이나 기능 → 함수
    >객체 = 속성(데이터) + 행위(기능)

4. 예를들어 '강아지'라는 객체가 있다면,
      - 속성: 이름, 나이, 색상
      - 행위: 짖기, 달리기, 먹기
      
      즉, 강아지와 관련된 데이터와 기능을 하나의 객체로 묶어서 관리할 수 있다.

5. 절차지향과 비교
    - 절차지향: 작업을 처리하는 순서와 과정을 중심으로 프로그램을 구성
    - 객체지향: 데이터와 기능을 가진 객체를 중심으로 프로그램을 구성

### 2) 클래스(Class)와 인스턴스(Instance)
\> 객체를 만들기 위한 설계도(클래스)와 실제로 만들어진 객체(인스턴스)의 관계(개념과 역할) 이해하기
1. 클래스  
    1. 정의: 객체를 만들기 위해 속성과 행동(메서드)을 미리 정의해 둔 설계도 또는 틀  
    2. 사용하는 이유: 같은 구조와 기능을 가진 객체를 쉽게 만들고 관리하기 위해 사용한다.
    4. 예시  
    ```
    # 빈 설계도 만들기
    class Bus:
        pass 
    ```
<br>

2. 인스턴스
    1. 정의: 클래스라는 설계도를 바탕으로 메모리에 실제로 생성된 구체적인 객체를 인스턴스라고 한다.
    2. 사용하는 이유: 클래스를 통해 실제로 사용할 객체를 만들기 위해 생성한다.
    3. 예시
    ```
    # 설계도를 바탕으로 실제 차량 객체들 생성
    bus1 = Bus()
    bus2 = Bus() 

    # bus1은 객체를 참조하는 변수이고, Bus()로 생성된 것이 인스턴스(객체)

    bus1 is bus2  # False(같은 클래스로부터 생성된 객체는 서로 다른 객체)

    ```
    ```
    # Bus라는 설계도로 버스 한 대를 만들고, 그 버스를 bus1이라는 이름으로 부른다.
    ```

### 3) \_\_init\_\_() 초기화 함수
\> 객체가 생성될 때 자동으로 호출되는 초기화 과정을 이해하기
1. 정의: 객체가 생성될 때 자동으로 호출되어 객체의 초기 상태를 설정하는 특수 메서드이다.
2. 사용하는 이유: 객체가 만들어질 때 필요한 초기값을 설정하기 위해 사용한다. 
3. 예시
    ```
    class Bus:
    def __init__(self):
        self.count = 0  # 객체가 생성되었을 때 승객 수를 0으로 초기화
    ```

### 4) self 키워드
\> 클래스 내부에서 현재 객체의 속성과 메서드에 접근하는 방법을 이해하기
1. 정의: 클래스에서 현재 객체(인스턴스) 자신을 가리키는 키워드
2. 사용하는 이유: 현재 객체 자신의 속성과 메서드에 접근하기 위해 사용한다
3. 예시
    ```
    class Bus:

    def __init__(self):
        self.count = 0  # self = 현재 객체, count = 현재 객체의 승객 수
        self.passengers = []  # self = 현재 객체, passengers = 현재 객체의 승객 목록

    def ride(self, passenger):
        self.count += 1  # 현재 객체(self)의 승객 수를 1 증가
        self.passengers.append(passenger)  # 현재 객체(self)의 승객 목록에 승객 추가  
    ```

### 5) 속성(Attribute)과 인스턴스 메서드(Method)
\> 객체가 가지고 있는 데이터(속성)와 기능(메서드)을 구분해서 이해하기
1. 속성
    1. 정의: 객체가 가지고 있는 데이터를 저장하는 변수
    2. 사용하는 이유: 객체마다 다른 상태나 정보를 저장하고 관리하기 위해 사용한다.
    3. 예시
        ```
        class Bus:
            def __init__(self):
                self.count = 0  # 속성: self.count → 승객 수
            self.passengers = []  # 속성: self.passengers → 승객 목록


        class Passenger:
            def __init__(self, name, age):
                self.name = name  # 속성: self.name → 승객 이름
                self.age = age  # 속성: self.age → 승객 나이
        ```
2. 인스턴스 메서드
    1. 정의: self를 매개변수로 받아 객체의 속성이나 데이터를 다루는 함수
    2. 사용하는 이유: 객체의 데이터를 조회하거나 변경하고, 객체의 기능을 수행하기 위해 사용한다.
    3. 예시
        ```
        def ride(self, passenger):
            self.count += 1
            self.passengers.append(passenger)
        
        # 이 전체가 ride라는 메서드, ride()는 메서드를 호출하는 표현       
        ```

### 6) \_\_str\_\_() / \_\_repr\_\_()
\> 객체를 출력할 때 객체의 정보를 문자열로 표현하는 방법 이해하기
1. \_\_str\_\_()
    1. 정의: 객체를 `print()`로 출력할 때 호출되는 메서드로, 객체를 사람이 이해하기 쉬운 문자열로 표현한다.
    2. 사용하는 이유: 객체의 상태나 정보를 보기 쉽게 출력하기 위해 사용한다.
    3. 예시
        ```
        passenger = Passenger("철수", 20)
        print(passenger)  # __str__() 호출

        # 이름: 철수, 나이: 20
        ```
2. \_\_repr\_\_()<br>
    1. 정의: 객체를 문자열로 표현하는 메서드로, 객체의 정보를 개발자가 확인하기 쉽도록 표현한다.
    2. 사용하는 이유: 객체의 상태를 기록하거나 디버깅할 때 유용하게 사용한다.
    3. 예시
        ```
        passenger = Passenger("철수", 20)
        print(repr(passenger))  # __repr__() 호출

        # Passenger(name='철수', age=20)
        ```

3. eval(문자열)
    1. 정의: 문자열을 파이썬 코드로 해석하여 실행하는 함수
    2. 사용하는 이유: 문자열 형태의 파이썬 표현식을 실제 값이나 객체로 변환할 때 사용할 수 있다.
    3. 주의사항: 외부에서 입력받은 문자열을 그대로 eval()에 사용하면 악성 코드가 실행될 수 있으므로 주의해야 한다.
    4. 예시
        ```
        passenger = Passenger("철수", 20)

        text = repr(passenger)
        print(text)
        # Passenger(name='철수', age=20)
        
        passenger2 = eval(text)
        print(passenger2)

        # 이름: 철수, 나이: 20
        ```

# 2. 상속과 MRO
### 1) 상속(Inheritance)
\> 기존 클래스의 정의와 기능을 새로운 클래스에서 이어받는 관계 이해하기
1. 정의: 이미 만들어진 클래스(부모 클래스)의 속성과 메서드를 그대로 물려받아 새로운 클래스(자식 클래스)를 정의하는 기술
2. 사용하는 이유: 기존 클래스의 기능을 활용하면서 필요한 부분만 추가하거나 변경하여 클래스를 효율적으로 구성하기 위해 사용
3. 예시
    ```
     class Animal:
        def breathe(self):
            print("숨을 쉽니다.")

    # Animal 클래스의 기능을 그대로 물려받습니다.
    class Dog(Animal):
        def bark(self):
            print("멍멍 짖습니다.")

    baduk = Dog()
    baduk.breathe()  # 부모에게 물려받은 기능을 그대로 사용합니다.
    baduk.bark()     # 자식 클래스만의 고유 기능도 함께 사용합니다.
    ```

### 2) super()
\> 상속 관계에서 부모 클래스의 객체와 기능에 접근하는 방법 이해하기
1. 정의: 자식 클래스 내부에서 부모 클래스의 메서드나 초기화 함수(__init__)를 호출할 때 사용
2. 사용하는 이유: 부모 클래스의 초기화나 기능을 그대로 사용하기 위해 사용한다.
3. 예시
    ```
    class Animal:
        def __init__(self, kind):
            self.kind = kind # 동물 종류

        def move(self):
            print("동물이 움직인다")

    class Dog(Animal):
        def __init__(self):
            super().__init__("강아지") # 부모 클래스의 __init__() 호출
           # self.kind = "강아지"
    ```

### 3) 메서드 오버라이딩(Overriding)
\> 자식 클래스가 부모 클래스의 메서드를 자신에게 맞게 재정의하는 방법 이해하기
1. 정의: 부모 클래스로부터 물려받은 메서드를 자식 클래스의 요구사항에 맞게 '새롭게 재정의'하는 것
2. 사용하는 이유: 부모 클래스의 기능을 그대로 사용하지 않고 자식 클래스의 특성에 맞게 기능을 변경하기 위해 사용한다.
3. 예시
    ```
    class Animal:
        def move(self):
            print("동물이 움직인다")

    class Dog(Animal):
        def move(self):  # 부모 클래스의 move()를 재정의
            print("강아지가 걷는다")

    dog = Dog()
    dog.move()
    # 강아지가 걷는다
    ```

### 4) isinstance()
\> 객체가 어떤 클래스에서 생성되었는지 확인하는 방법 이해하기

2. 사용하는 이유: 특정 객체가 특정 클래스 또는 자료형에 해당하는지 확인하기 위해 사용

### 5) 다중 상속
\> 하나의 클래스가 여러 부모 클래스를 상속할 수 있다는 개념과 그때 발생하는 메서드 호출 순서를 이해하기
1. 정의: 하나의 자식 클래스가 두 개 이상의 부모 클래스를 상속받는 것
2. 사용하는 이유: 여러 클래스의 기능을 하나의 클래스에서 함께 활용하기 위해 사용
3. 예시
    ```
    class ParentA:
        def a(self):
            print("ParentA = a()")
        def b(self):
            print("ParentA = b()")

    class ParentB:
        def a(self):
            print("ParentB = a()")
        def c(self):
            print("ParentB = c()")

    # class Child(ParentA,ParentB):
    #     pass

    class Child(ParentB, ParentA):
        pass
    ```

    ```
    c = Child()
    c.b()  # ParentA = b()
    c.c()  # ParentB = c()
    c.a()  # ParentB = a()
    ```

### 6) MRO(Method Resolution Order)
\> 다중 상속에서 같은 이름의 메서드가 있을 때 어떤 메서드가 먼저 선택되는지 이해하기
1. 정의: 클래스의 메서드나 속성을 찾을 때 적용되는 상속 탐색 순서
2. 사용하는 이유: 상속 관계에서 메서드를 어떤 순서로 탐색하고 호출하는지 확인하기 위해 사용
3. 예시
    ```
    class ParentA:
        def a(self):
            print("ParentA = a()")

    class ParentB:
        def a(self):
            print("ParentB = a()")

    class Child(ParentB, ParentA):
        pass

    print(Child.__mro__)
    # Child → ParentB → ParentA → object

    c = Child()
    c.a()
    # ParentB = a()
    ```
