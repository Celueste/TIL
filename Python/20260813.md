# 1. 변수 스코프와 LEGB

### 1) 변수 스코프

> 변수를 접근할 수 있는 범위

- 전역 변수(Global): 함수 외부에 정의된 변수, 코드 전역에서 접근 가능
- 지역 변수(Local): 함수 내부에 정의된 변수, 함수가 실행될 때 유효한 변수

```python
a = 10  # 전역 변수

def func():
    b = 20  # 지역 변수
    print(f"{a=},{b=}")

print(a)
func()
```

함수 내부에서는 전역 변수 `a`에 접근할 수 있지만, 함수 내부의 지역 변수 `b`는 함수 외부에서 직접 사용할 수 없다.

---

### 2) 중첩 함수와 변수 접근

```python
c = 30

def outer():
    a = 10

    print("c:", c)

    def inner():
        b = 20
        print(f"{a=},{b=},{c=}")

    inner()

outer()
```

여기서

- `c` → 전역 변수
- `a` → `outer()`의 지역 변수
- `b` → `inner()`의 지역 변수

`inner()`에서는 자신보다 바깥쪽에 있는 `a`와 전역 변수 `c`에 접근할 수 있다.

> 좁은 범위에서는 넓은 범위의 변수를 찾을 수 있지만, 넓은 범위에서는 좁은 범위의 변수를 직접 찾을 수 없다.

---

### 3) LEGB 스코프

파이썬의 변수 접근 우선순위:

```text
L → Local
E → Enclosing
G → Global
B → Builtin
```

> **좁은 범위가 우선순위가 높다.**

예시:

```python
a = "Global"

def outer():
    a = "Enclosing"
    print("outer:", a)

    def inner():
        a = "Local"
        print("inner:", a)

    inner()

outer()
```

결과:

```text
outer: Enclosing
inner: Local
```

변수를 찾을 때는

```text
Local
  ↓
Enclosing
  ↓
Global
  ↓
Builtin
```

순서로 찾는다.

---

### 4) `global` 키워드

함수 내부에서 전역 변수를 사용하겠다고 명시할 때 `global`을 사용한다.

```python
a = "Global"

def outer():
    a = "Enclosing"
    print("outer:", a)

    def inner():
        global a
        print("inner:", a)

    inner()

outer()
```

결과:

```text
outer: Enclosing
inner: Global
```

`global a`는

> `a`라는 변수는 전역 변수를 찾겠다는 의미

이다.

# 2. 일급 함수와 고차 함수

### 1) 일급 함수(First-class Function)

파이썬에서는 함수를 변수와 동일하게 취급할 수 있다.

- 함수를 변수에 저장할 수 있다.
- 함수의 매개변수로 함수를 사용할 수 있다.
- 함수의 반환값으로 함수를 사용할 수 있다.

즉,

> **함수도 하나의 값처럼 사용할 수 있다.**

---

### 2) 콜백 함수

> 다른 함수의 매개변수로 전달되어 호출되는 함수

```python
def callback2():
    print("callback()")

def func(callback):
    print("func()")
    callback()

func(callback2)
```

실행 순서:

```text
func(callback2)
      ↓
callback2 함수 전달
      ↓
func() 실행
      ↓
callback() 실행
      ↓
callback2() 실행
```

여기서 `callback2`가 콜백 함수이다.

---

### 3) 함수를 반환하는 함수

```python
def outer(num1):
    def inner(num2):
        return num1 + num2

    return inner
```

`outer()`는 `inner()` 함수를 반환한다.

```python
a = outer(10)

a(20)
```

결과:

```text
30
```

`a`는 `10`을 기억하고 있는 함수이다.

```python
a(30)
```

결과:

```text
40
```

다른 값으로도 새로운 함수를 만들 수 있다.

```python
b = outer(20)

b(20)
```

결과:

```text
40
```

---

### 4) 콜백 함수를 활용한 데이터 가공

```python
def change_numbers(*args, callback):
    numbers = list(args)

    for i in range(len(numbers)):
        numbers[i] = callback(numbers[i])

    return numbers
```

제곱 함수:

```python
def square(num):
    return num ** 2
```

```python
change_numbers(10, 20, 30, callback=square)
```

결과:

```text
[100, 400, 900]
```

10을 더하는 함수를 전달할 수도 있다.

```python
def plus(num):
    return num + 10

change_numbers(10, 20, 30, callback=plus)
```

결과:

```text
[20, 30, 40]
```

> 같은 함수라도 어떤 callback을 전달하느냐에 따라 데이터 처리 방식이 달라진다.

---

# 3. Lambda 함수

### 1) Lambda 함수

> 간단하게 일회용으로 사용하는 함수를 한 줄의 식으로 정의하는 방법

기본 형태:

```text
lambda 매개변수, 매개변수, ...: 처리부분
```

일회용으로 사용되므로 매개변수 이름도 최대한 간결하게 작성한다.

일반 함수:

```python
def square(num):
    return num ** 2
```

Lambda:

```python
square = lambda num: num ** 2

square(10)
```

결과:

```text
100
```

---

### 2) Lambda를 콜백 함수로 사용

```python
def change_numbers(callback, *args):
    numbers = list(args)

    for i in range(len(numbers)):
        numbers[i] = callback(numbers[i])

    return numbers
```

Lambda를 직접 전달할 수 있다.

```python
change_numbers(lambda x: x ** 2, 10, 20, 30)
```

결과:

```text
[100, 400, 900]
```

별도의 함수를 만들지 않고도 간단한 연산을 전달할 수 있다.

---

### 3) `map()`과 `filter()`

- `map()` → 변환 작업
- `filter()` → 특정 조건에서 데이터를 선별

`map()` 예시:

```python
fruits = ['사과', '오렌지', '망고']

list(map(lambda x: f"**{x}**", fruits))
```

결과:

```text
['**사과**', '**오렌지**', '**망고**']
```

`filter()` 예시:

```python
numbers = [*range(1, 11)]

list(filter(lambda x: x % 2 == 1, numbers))
```

결과:

```text
[1, 3, 5, 7, 9]
```

# 4. 클로저(Closure)

### 1) 클로저

> 내부 함수가 외부 함수의 변수를 기억하는 구조

```python
def outer():
    num1 = 10

    def inner():
        num2 = 20
        print(num1 + num2)

    return inner

inner = outer()
inner()
```

결과:

```text
30
```

`outer()`가 종료된 이후에도 `inner()`는 외부 변수 `num1`을 사용할 수 있다.

원본에서는 `num1`이 `inner`에 의해 사용되므로 힙 영역에 생성되어 있다고 설명하고 있다.

---

### 2) 여러 단계의 클로저

```python
def add(num1):
    def _add(num2):
        def __add(num3):
            return num1 + num2 + num3

        return __add

    return _add
```

세 단계로 값을 전달할 수 있다.

```python
result1 = add(10)(20)(30)

result1
```

결과:

```text
60
```

중간 결과를 변수에 저장할 수도 있다.

```python
add10 = add(10)

add10(30)(40)
```

결과:

```text
80
```

또는

```python
add10_20 = add(10)(20)

add10_20(30)
```

결과:

```text
60
```

# 5. 데코레이터(Decorator)

### 1) 데코레이터

> 기존 함수에 새로운 기능을 추가할 수 있도록 하는 디자인 패턴

데코레이터를 이해하기 위해 먼저 공통 기능과 핵심 기능을 분리한다.

---

### 2) 팩토리얼 함수

반복문을 이용한 팩토리얼:

```python
def factorial1(num):
    result = 1

    for i in range(1, num + 1):
        result *= i

    return result
```

재귀 함수:

```python
def factorial2(num):
    if num < 1:
        return 1

    return num * factorial2(num - 1)
```

두 함수 모두 `10!`을 계산할 수 있다.

---

### 3) 실행 시간 측정

```python
import time

start = time.time()

result = factorial1(10)
print(result)

end = time.time()

print("걸린시간:", end - start)
```

여기서

```text
start
→ 공통 기능

factorial1(10)
→ 핵심 기능

end
→ 공통 기능
```

이다.

---

### 4) 공통 기능과 핵심 기능 분리

시간 측정 기능을 별도의 함수로 분리한다.

```python
import time

def time_checker(callback, num):
    start = time.time()

    result = callback(num)

    end = time.time()

    print("걸린시간:", end - start)

    return result
```

사용:

```python
time_checker(factorial1, 10)
time_checker(factorial2, 10)
```

`factorial1`과 `factorial2`를 callback으로 전달하고, 시간 측정이라는 공통 기능은 `time_checker()`가 담당한다.

---

### 5) `wrapper()` 함수

데코레이터 형태로 만들면 다음과 같다.

```python
import time

def time_check2(callback):
    def wrapper(*args, **kwargs):
        start = time.time()

        result = callback(*args, **kwargs)

        end = time.time()
        print("걸린시간:", end - start)

        return result

    return wrapper
```

구조:

```text
time_check2()
      ↓
callback 전달
      ↓
wrapper() 생성
      ↓
실행 전 시간 측정
      ↓
callback 실행
      ↓
실행 후 시간 측정
      ↓
결과 반환
```

`*args`, `**kwargs`를 사용하기 때문에 다양한 형태의 인수를 받는 함수에도 적용할 수 있다.

---

### 6) `@` 데코레이터 문법

```python
@time_check2
def factorial2(num):
    if num < 1:
        return 1

    return num * factorial2(num - 1)
```

이후

```python
factorial2(10)
```

을 실행하면 `time_check2`의 시간 측정 기능이 함께 실행된다.

다른 함수에도 적용할 수 있다.

```python
@time_check2
def add(num1, num2):
    return num1 + num2

add(10, 20)
```

결과:

```text
30
```

---

# 6. `*`를 이용한 인수 전달

리스트의 값을 함수의 위치 인수로 전달할 수 있다.

```python
a = [10, 20]

def minus(num1, num2):
    return num1 - num2

minus(*a)
```

결과:

```text
-10
```

`minus(*a)`는 사실상

```python
minus(10, 20)
```

과 같다.

# 오늘의 핵심 정리

### 변수 스코프

```text
Global
→ 함수 외부에서 정의

Local
→ 함수 내부에서 정의
```

### LEGB

```text
L → Local
E → Enclosing
G → Global
B → Builtin
```

> 좁은 범위가 우선적으로 검색된다.

### 일급 함수

```text
함수를 변수에 저장
함수를 인수로 전달
함수를 반환
```

### 콜백 함수

```text
함수를 다른 함수의 인수로 전달
→ 전달받은 함수 실행
```

### Lambda

```text
lambda 매개변수: 처리부분
```

→ 간단한 일회용 함수를 한 줄로 표현

### `map()` / `filter()`

```text
map()
→ 변환

filter()
→ 조건에 맞는 데이터 선별
```

### 클로저

```text
외부 함수
   ↓
내부 함수 반환
   ↓
외부 함수 종료
   ↓
내부 함수가 외부 변수 기억
```

### 데코레이터

```text
기존 함수
   ↓
데코레이터
   ↓
추가 기능
   ↓
기존 함수 실행
```

> 기존 함수의 코드를 직접 수정하지 않고 공통 기능을 추가할 수 있다.

# 오늘의 한 줄 정리

> **파이썬에서는 함수도 하나의 값처럼 다룰 수 있기 때문에 함수를 다른 함수에 전달하거나 반환할 수 있고, 이를 바탕으로 콜백 함수·Lambda·클로저·데코레이터를 구현할 수 있다. 또한 LEGB 규칙을 통해 변수의 스코프와 접근 우선순위를 이해할 수 있다.**
