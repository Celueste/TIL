# 1. 클래스 변수와 인스턴스 변수
### 1) 클래스 변수
\> 여러 인스턴스가 공통으로 사용하는 데이터를 관리하는 방법 이해하기
1. 정의: 클래스에 직접 선언되어 클래스의 모든 인스턴스가 공유하는 변수

2. 사용하는 이유: 모든 인스턴스에서 동일하게 사용하는 값을 하나의 변수로 관리하기 위해 사용
3. 예시  
    ```
    class User:
        pass

    User.count = 100    # 클래스 변수, User에 직접 값을 넣음.
    
                                      User  ← 클래스
                                        ↓
                                      count = 100
    ```
<br>
<br>

### 2) 인스턴스 변수
\> 하나의 클래스로 만들어진 여러 객체가 서로 다른 데이터를 가질 수 있다는 것을 이해하기
1. 정의: 각 인스턴스마다 개별적으로 가지는 변수
2. 사용하는 이유: 각 인스턴스마다 다른 값을 저장하고 관리하기 위해 사용
3. 예시  
    ```
    class User:
        pass

    user = User()
    user.name = "김철수"   # 인스턴스 변수    
    ```
<br>
<br>

### 3) @classmethod
\> 인스턴스가 아닌 클래스 자체를 대상으로 동작하는 메서드를 만드는 방법을 이해하기
1. 정의: 클래스를 첫 번째 인자로 받는 메서드
2. 사용하는 이유: 클래스 변수에 접근하거나 클래스 자체를 이용하여 객체를 생성하는 등의 작업에 사용
3. 예시  
    ```
    class Calculator:
        count = 0

        # clz -> Calculator 클래스 객체 참조 변수
        # clz -> Calculator 클래스 객체를 가리키는 매개변수, 다른 클래스 메서드를 접근하기 위한 목적
        @classmethod
        def add(clz, num1, num2):
            clz.count += 1
            print("호출 횟수:", clz.count)
        
            return num1 + num2

    Calculator.add(10, 20)  # 호출 횟수: 1
    ```
<br>
<br>

### 4) @staticmethod
\> 클래스와 관련된 기능이지만 인스턴스나 클래스의 데이터를 사용하지 않는 메서드를 구분해서 작성하는 방법을 배우기 위해 배운다.
1. 정의: 클래스나 인스턴스의 상태에 직접 접근하지 않고 독립적으로 동작하는 메서드에 사용하는 데코레이터
2. 사용하는 이유: 클래스와 연관된 기능을 클래스 내부에 묶어 관리하면서 self나 cls가 필요 없는 메서드를 만들기 위해 사용
3. 예시  
    ```
    class Calculator:
       count = 0

        @staticmethod
        def minus(num1, num2):
            return num1 - num2

    Calculator.minus(10, 20)  # -10         
    ```

# 2. 예외 처리
### 1) 구문 오류(Syntax Error)와 런타임 예외(Exception)
1. 구문 오류
\> 파이썬 문법 오류와 프로그램 실행 중 발생하는 예외의 차이를 이해하기
    1. 정의: 파이썬 문법에 맞지 않는 코드를 작성했을 때 프로그램이 실행되기 전에 발생하는 오류
    2. 배우는 이유: 문법 오류를 확인하고 올바른 파이썬 문법으로 수정하기 위해
    3. 예시  
        ```
        if True
            print("Hello")  # :가 없기 때문에 SyntaxError가 발생한다.
        ```
<br>
<br>

2. 런타임 예외
    1. 정의: 문법적으로는 올바른 코드이지만 프로그램을 실행하는 도중 예상하지 못한 문제가 발생했을 때 발생하는 오류
    2. 배우는 이유: 프로그램이 갑자기 종료되는 것을 방지하고 예외 상황에 적절하게 대응하기 위해
    3. 예시  
        ```
        number = 10
        result = number / 0
        ```
<br>
<br>

### 2) 파이썬 대표 예외
1. 정의: 파이썬에서 자주 발생하는 오류 상황을 나타내는 예외 클래스
2. 배우는 이유: 오류의 종류를 파악하고 상황에 맞는 예외 처리를 하기 위해
3. 예시  
    - ValueError: 올바르지 않은 값  
    - TypeError: 잘못된 자료형  
    - IndexError: 존재하지 않는 인덱스  
    - KeyError: 존재하지 않는 딕셔너리 키  
    - ZeroDivisionError: 0으로 나누기  
    - FileNotFoundError: 파일을 찾을 수 없음  
<br>

### 3) try - except - else - finally
\> 예외가 발생하더라도 프로그램이 안정적으로 동작하도록 만드는 방법을 배우기
1. 정의: 예외가 발생할 수 있는 코드를 try에 작성하고, 예외가 발생했을 때 except, 예외가 발생하지 않았을 때 else, 예외 발생 여부와 관계없이 실행할 코드를 finally에 작성하는 예외 처리 구조
2. 사용하는 이유: 예외 상황에 대응하고 예외 발생 여부에 따라 서로 다른 코드를 실행하기 위해 사용
3. 예시  
    ```
    try:
        number = int(input("숫자를 입력하세요: "))  
        # 예외가 발생할 가능성이 있는 코드

    except:
        print("숫자만 입력해주세요.")
        # 예외가 발생하면 유입되는 구간, 예외에 대한 대안 처리
        # 대안 로직, 로깅 처리 
    
    else:
        print("입력한 숫자:", number)
        # 예외가 발생하지 않아야 유입되는 구간
    
    finally:
        print("프로그램 종료")
        # 예외가 발생하든 정상 처리되든 항상 유입되는 구간, 공통적인 처리 
        # 자원 정리(메모리 해제)
    ```

### 4) 다중 예외 처리
\> 프로그램에서 발생할 수 있는 여러 오류 상황을 구분하여 처리하는 방법을 배우기
1. 정의: 하나의 try에서 발생할 수 있는 여러 종류의 예외를 각각 처리하는 방법
2. 사용하는 이유: 예외 종류에 따라 사용자에게 다른 메시지를 제공하거나 서로 다른 처리를 하기 위해 사용
3. 예시  
    ```
    try:
        num = int(input())
        result = 10 / num

        print(result)
    
    except ZeroDivisionError:
        print("0이 아닌 정수를 입력하세요.")
    except ValueError:
        print("정수만 입력하세요")    
    ```

### 5) raise 키워드
\> 프로그램에서 잘못된 상황을 직접 판단하고 명확하게 오류를 발생시키는 방법을 배우기 위해 배운다.
1. 정의: 프로그래머가 직접 예외를 발생시키기 위해 사용하는 키워드
2. 사용하는 이유: 프로그램에서 정상적으로 처리할 수 없는 상황이나 잘못된 데이터를 발견했을 때 예외를 발생시켜 이후 코드의 실행을 막고, 해당 오류를 적절하게 처리하기 위해 사용
3. 예시  
    ```
    age = -1

    if age < 0:
        raise ValueError("나이는 0 이상이어야 합니다.")    
    ```
<br>

### 6) raise를 활용한 데이터 유효성 검증
\> 입력 데이터가 올바른지 검사하고 잘못된 경우 예외를 발생시키는 방법을 이해한다.
1. 정의: 입력받은 데이터가 조건에 맞는지 확인하고, 조건을 만족하지 않으면 raise를 사용하여 예외를 발생시키는 방법
2. 사용하는 이유: 입력값이 올바른 범위나 형식인지 검사하여 프로그램의 안정성을 높이기 위해 사용한다.
3. 예시  
    ```
    def set_age(age):
        if age < 0:
            raise ValueError("나이는 0 이상이어야 합니다.")
    
        return age

    print(set_age(20))  
    ```

### 7) 사용자 정의 예외
\> 기본 예외만으로 표현하기 어려운 프로그램의 특정 오류 상황을 직접 정의하는 방법을 배우기 위해 배운다.
1. 정의: 프로그래머가 프로그램의 특정 상황에 맞게 직접 만들어 사용하는 예외
2. 사용하는 이유: 프로그램의 비즈니스 규칙이나 특정 오류 상황을 명확하게 표현하고 처리하기 위해 사용

    ```
    class InsufficientBalanceError(Exception):
    ```

### 8) traceback
\> 오류가 어디에서 발생했는지 추적하고 원인을 파악하는 방법을 배우기 위해 배운다
1. 정의: 예외가 발생했을 때 오류가 발생한 위치와 호출된 함수의 흐름 등을 보여주는 정보
2. 사용하는 이유: 에러 발생 위치와 코드 실행 흐름을 확인하여 문제를 빠르게 찾기 위해 사용
3. 주요함수
    - `traceback.print_exc()` : 발생한 예외의 traceback을 콘솔에 출력
    - `traceback.format_exc()` : 발생한 예외의 traceback을 문자열로 반환
    - `traceback.print_stack()` : 예외 없이 현재 함수 호출 흐름을 콘솔에 출력
3. 예시  
    ```python
    import traceback

    try:
        result = 10 / 0
        print(result)
    except:
        print("에러 발생")
        message = traceback.format_exc()
        print("message", message)
    ```

    실행 결과
    ```text
    에러 발생
    message Traceback (most recent call last):
      ...
    ZeroDivisionError: division by zero
    ```

# 4. 유용한 내장 함수와 표준 라이브러리 함수
### 1) isinstance(): 자료형 검증
\> 데이터의 자료형을 확인하고 자료형에 따라 적절하게 처리하는 방법을 배우기 위해 배운다.
1. 정의: 객체가 특정 자료형인지 확인하는 함수
2. 사용하는 이유: 입력값이나 변수의 자료형을 검사하여 잘못된 데이터로 인한 오류를 예방하기 위해 사용

<br>


### 2) all()과 any()
\> 여러 조건의 참/거짓 여부를 간단하게 확인하는 방법을 배우기
1. 정의: all()은 모든 요소가 참인지 확인하고, any()는 하나라도 참인 요소가 있는지 확인하는 함수
2. 사용하는 이유: 여러 조건을 반복문 없이 한 번에 검사하기 위해 사용
3. 예시  
    ```
    all([True, 1," "])  # True

    any([False, 1, 0])  # True
    ```
<br>
<br>

### 3) len(), sum(), round()
\> 파이썬에서 자주 사용되는 기본적인 데이터 처리 방법을 익히기 위해 배운다.
1. 정의: len()은 요소의 개수를 구하고, sum()은 숫자의 합을 구하며, round()는 숫자를 반올림하는 함수
2. 사용하는 이유: 데이터의 개수, 합계, 반올림 등을 간단하게 계산하기 위해 사용한다.
3. 예시  
    ```
    num = 10.56
    print(round(num,1))  #10.6

    import math
    print(math.ceil(10.2))  #11

    print(math.floor(num))  #10
    ```
<br>
<br>

### 4) mean()과 median()
\> 데이터의 대표값을 계산하고 평균과 중앙값의 차이를 이해하기
1. 정의: mean()은 평균을 계산하고, median()은 중앙값을 계산하는 statistics 모듈의 함수
2. 사용하는 이유: 데이터의 평균과 중앙값을 간단하게 계산하기 위해 사용한다.
3. 예시
    ```
    import statistics
    nums = [10, 15, 20 ,8, 7, 100000]
    print("평균: ", statistics.mean(nums), "중앙값: ", statistics.median(nums))
    # 평균:  16676.666666666668 중앙값:  12.5
    ```
