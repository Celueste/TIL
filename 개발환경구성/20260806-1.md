# Python, uv, Jupyter 설치

## 1. 이번에 할 것

Python을 공부하고 실습하기 위해 필요한 프로그램을 설치한다.

- Python
- uv
- Jupyter Notebook
<br>
<br>

## 2. 설치하는 이유

### Python

Python 코드를 작성하고 실행하기 위해 설치한다.

### uv

Python 프로젝트를 만들고 가상환경과 패키지를 편하게 관리하기 위해 사용한다.

### Jupyter Notebook

Python 코드를 한 부분씩 실행하면서 결과를 바로 확인하고, 코드와 설명을 함께 정리하기 위해 사용한다.
<br>
<br>

## 3. 설치 방법

### 3-1. Python 설치

1. Python 공식 홈페이지에 접속한다.
2. Windows용 Python을 다운로드한다.
3. 설치 파일을 실행한다.
4. `Add Python to PATH` 옵션을 확인한다.
5. 설치를 진행한다.
6. 터미널에서 설치가 완료되었는지 확인한다.

`python --version`

Python 버전이 표시되면 정상적으로 설치된 것이다.

[Python 공식 홈페이지](https://www.python.org/)



### 3-2. uv 설치

1. 터미널을 실행한다.
2. uv를 설치한다.
3. 설치가 완료되었는지 확인한다.

`uv --version`

uv 버전이 표시되면 정상적으로 설치된 것이다.

uv를 이용하면 Python 프로젝트를 만들고 가상환경과 필요한 패키지를 관리할 수 있다.



### 3-3. Jupyter Notebook 설치

1. 터미널을 실행한다.
2. Jupyter Notebook을 설치한다.
3. 설치가 완료되었는지 확인한다.
4. Jupyter Notebook을 실행한다.

`jupyter --version`

Jupyter 버전이 표시되면 정상적으로 설치된 것이다.

Jupyter Notebook을 실행하면 브라우저에서 Python 코드를 작성하고 실행할 수 있다.
<br>
<br>

## 4. 정리

이번에 Python 공부와 실습에 필요한 환경을 구성했다.

| 프로그램 | 역할 |
|---|---|
| Python | Python 코드 작성 및 실행 |
| uv | Python 프로젝트와 가상환경 관리 |
| Jupyter Notebook | 코드를 실행하면서 결과 확인 및 정리 |
  

앞으로 Python과 Jupyter Notebook을 이용하여 Python을 공부하고 실습하며, uv를 이용해 프로젝트와 가상환경을 관리할 예정이다.
