# SourceTree 설치

## 1. 이번에 할 것
- SourceTree를 설치한다.
- GitHub 저장소와 연결한다.
<br>
<br>

## 2. 설치하는 이유
- 터미널에서 Git 명령어를 직접 입력하지 않고 쉽게 Git을 관리하기 위해 사용한다.
<br>
<br>
## 3. 설치 및 연결 방법
1. SourceTree 공식 홈페이지에서 설치 파일을 다운로드한다.
2. 설치 파일을 실행하고 안내에 따라 설치한다.
3. SourceTree를 실행한다.
4. GitHub 계정을 연결한다.
5. GitHub 저장소를 SourceTree에 추가한다.
6. 저장소가 정상적으로 연결되었는지 확인한다.

앞으로 SourceTree를 이용하여 Git의 변경 사항을 쉽게 관리하고 GitHub에 TIL을 정리할 예정이다.
