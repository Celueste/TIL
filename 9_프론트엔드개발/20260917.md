# [TIL] Flexbox와 CSS Grid 레이아웃

## 📝 오늘 배운 내용 요약

- Flexbox는 1차원(가로 또는 세로) 레이아웃으로, 주축과 교차축을 기준으로 요소를 정렬하고 배치한다.
- `flex-grow`, `flex-shrink`, `flex-basis`를 자식 요소에 적용하여 남는 공간이나 부족한 공간에 따른 크기 변화를 제어한다.
- CSS Grid는 2차원(행과 열) 레이아웃으로, `fr` 단위와 `repeat()`, `grid-column`, `grid-row` 등을 사용해 전체적인 구조와 영역을 나눈다.
- 메뉴나 버튼 나열처럼 한 방향 정렬에는 Flexbox를 사용하고, 게시판이나 대시보드처럼 바둑판식 구조에는 Grid를 선택한다.

# 1. Flexbox 기본 설정과 방향 지정

Flexbox는 요소들을 한 방향(가로 또는 세로)으로 정렬하는 1차원 레이아웃 방식이다.

## 기본 문법

Flexbox를 적용하려면 정렬하려는 요소들의 부모 요소에 `display: flex`를 선언한다.

~~~css
.flex-container {
    display: flex;
    flex-direction: row;
}
~~~

- `display: flex`는 해당 요소를 Flex 컨테이너로 지정하여 직계 자식 요소들을 Flex 아이템으로 만든다.
- `flex-direction`은 자식 요소가 배치되는 기준 축(주축)의 방향을 결정한다.

## 배치 방향의 종류

- `row`: 왼쪽에서 오른쪽으로 가로 배치한다. (기본값)
- `row-reverse`: 오른쪽에서 왼쪽으로 가로 배치한다.
- `column`: 위에서 아래로 세로 배치한다.
- `column-reverse`: 아래에서 위로 세로 배치한다.

# 2. Flexbox 정렬 및 줄 바꿈 속성

Flexbox에서는 주축(Main Axis)과 이에 수직인 교차축(Cross Axis)을 기준으로 요소를 정렬하거나 줄 바꿈을 설정한다.

## 주축 정렬 (`justify-content`)

주축을 기준으로 자식 요소들의 위치와 여백을 지정한다.

- `flex-start`: 주축의 시작점에 정렬한다.
- `flex-end`: 주축의 끝점에 정렬한다.
- `center`: 주축의 가운데에 정렬한다.
- `space-between`: 양 끝을 벽면에 붙이고 요소 사이에 동일한 간격을 둔다.
- `space-around`: 각 요소의 좌우(또는 상하)에 동일한 여백을 둔다.
- `space-evenly`: 양 끝과 요소 사이의 모든 간격을 동일하게 맞춘다.

## 교차축 정렬 (`align-items`)

주축과 수직인 방향을 기준으로 정렬 방식을 지정한다.

- `stretch`: 컨테이너 공간에 맞게 요소를 늘린다. (기본값)
- `flex-start`: 교차축의 시작점에 정렬한다.
- `flex-end`: 교차축의 끝점에 정렬한다.
- `center`: 교차축의 가운데에 정렬한다.
- `baseline`: 텍스트 기준선(Baseline)에 맞추어 정렬한다.

~~~css
.practice-area {
    display: flex;
    justify-content: center;
    align-items: center;
}
~~~

- `justify-content: center`와 `align-items: center`를 함께 사용하면 부모 영역 안에서 자식 요소를 완벽하게 정중앙에 배치한다.

## 줄 바꿈 설정 (`flex-wrap`)

컨테이너 크기보다 자식 요소들의 총 너비가 클 때 다음 줄로 넘길지 결정한다.

~~~css
.wrap-container {
    display: flex;
    flex-wrap: wrap;
}
~~~

- `nowrap`: 공간이 부족해도 다음 줄로 넘기지 않고 한 줄에 유지한다. (기본값)
- `wrap`: 공간이 부족하면 자식 요소를 다음 줄로 배치한다.
- `wrap-reverse`: 반대 방향으로 줄을 바꾼다.

# 3. Flexbox 자식 요소의 크기 조절

부모 요소가 아닌 자식 요소(Flex 아이템)에 개별적으로 부여하여 크기 변화 방식을 조절하는 속성이다.

## `flex-basis`

- 요소가 늘어나거나 줄어들기 전의 기본 크기를 정의한다.

~~~css
.logo {
    flex-basis: 100px;
}
~~~

- `.logo` 클래스를 가진 요소의 초기 너비를 100px로 지정한다.

## `flex-grow`

- 부모 요소 내부에 남는 빈 공간이 있을 때, 해당 요소가 공간을 얼마나 차지할 것인지 비율을 지정한다.

~~~css
.input-field {
    flex-grow: 1;
}
~~~

- `flex-grow: 1`을 설정하면 남는 공간을 모두 흡수하여 요소가 늘어난다.

## `flex-shrink`

- 부모 요소의 공간이 부족해졌을 때 해당 요소가 얼마나 줄어들지 비율을 지정한다.

~~~css
.logo {
    flex-shrink: 0;
}
~~~

- `flex-shrink: 0`을 설정하면 화면이 좁아지더라도 크기가 줄어들지 않고 원래 크기를 유지한다.

# 4. CSS Grid 기본 구조와 단위

CSS Grid는 행(Row)과 열(Column)을 함께 사용하는 2차원 레이아웃 방식이다.

## Grid 선언과 열/행 정의

부모 요소에 `display: grid`를 적용하고 `grid-template-columns`와 `grid-template-rows`로 구조를 잡는다.

~~~css
.grid-board {
    display: grid;
    grid-template-columns: 150px 1fr 2fr;
}
~~~

- `display: grid`는 해당 컨테이너를 Grid 환경으로 만든다.
- `grid-template-columns`는 열의 개수와 너비를 설정한다.
- 첫 번째 열은 150px로 고정하고, 남은 공간을 `1fr`과 `2fr`의 비율로 분할한다.
- `fr`(Fraction)은 Grid 컨테이너 내부의 유연한 남은 공간을 비율로 나타내는 전용 단위이다.

## `repeat()` 함수

동일한 크기의 열이나 행을 반복 생성할 때 사용한다.

~~~css
.grid-board {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
~~~

- `repeat(3, 1fr)`은 `1fr 1fr 1fr`과 동일하게 작동하며, 동일한 비율의 열 3개를 생성한다.

# 5. Grid 간격과 영역 확장

## 간격 설정 (`gap`)

칸과 칸 사이의 간격을 조절한다.

~~~css
.grid-board {
    gap: 30px 10px;
}
~~~

- `gap: 30px 10px`은 행 사이 간격(row-gap) 30px, 열 사이 간격(column-gap) 10px을 의미한다.
- 하나의 값만 쓰면 행과 열에 동일하게 적용되며, 필요 시 `row-gap`과 `column-gap`을 개별 속성으로 작성할 수 있다.

## 영역 확장 (`grid-column`, `grid-row`)

자식 요소가 여러 개의 셀을 차지하도록 병합할 때 사용한다.

~~~css
.hero-box {
    grid-column: span 2;
}

.vertical-box {
    grid-row: span 2;
}
~~~

- `grid-column: span 2`는 가로 방향으로 2칸의 영역을 차지한다.
- `grid-row: span 2`는 세로 방향으로 2칸의 영역을 차지한다.

~~~css
.custom-box {
    grid-column: 1 / 3;
}
~~~

- `grid-column: 1 / 3`처럼 시작 눈금선과 종료 눈금선 번호를 지정하여 1번 세로선부터 3번 세로선까지 영역을 설정할 수도 있다.

# 6. Grid 내부 정렬

`place-items` 속성을 사용하면 Grid 각 칸 내부에서 콘텐츠의 위치를 손쉽게 제어한다.

~~~css
.place-board {
    display: grid;
    place-items: center;
}
~~~

- `place-items: center`는 각 셀 내부에서 콘텐츠를 가로와 세로 방향 모두 정중앙으로 배치한다.
- `stretch`: 셀의 영역을 채우도록 늘린다. (기본값)
- `start`: 셀의 시작 위치에 배치한다.
- `end`: 셀의 끝 위치에 배치한다.
- `center`: 셀의 가운데에 배치한다.

# 7. 비교 정리

| 구분 | Flexbox | CSS Grid |
|---|---|---|
| 차원 | 1차원 (가로 또는 세로 한 방향) | 2차원 (행과 열을 동시에 제어) |
| 주 용도 | 컴포넌트 내부 정렬, 메뉴, 버튼 나열 | 페이지의 전체 골격, 대시보드, 카드 목록 |
| 주요 속성 | `flex-direction`, `justify-content`, `align-items` | `grid-template-columns`, `grid-template-rows`, `gap` |
| 자식 요소 제어 | `flex-grow`, `flex-shrink`, `flex-basis` | `grid-column`, `grid-row` |

# 8. 핵심 정리

## 핵심 코드

~~~css
/* Flexbox 정중앙 정렬 */
.flex-container {
    display: flex;
    justify-content: center;
    align-items: center;
}

/* CSS Grid 3열 균등 분할 및 간격 */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}
~~~

## 핵심 개념

- Flexbox는 한 축을 중심으로 요소의 흐름과 간격을 조정하는 데 적합하다.
- `flex-wrap`은 창 크기가 줄어들 때 아이템이 자연스럽게 다음 줄로 떨어지게 만드는 반응형 처리에 필수적이다.
- Grid는 바둑판 형태의 구조를 설계할 때 강력하며, `fr` 단위와 `repeat()`을 활용해 가변적인 비율을 정의한다.
- `span` 키워드를 이용하면 복잡한 눈금선 번호 계산 없이 직관적으로 셀을 병합할 수 있다.

# 9. 느낀 점

Flexbox와 Grid는 각각 1차원과 2차원 레이아웃에 특화되어 있으므로, 전체적인 페이지 구조를 짤 때는 Grid를 쓰고 메뉴나 개별 컴포넌트 내부를 정렬할 때는 Flexbox를 활용하는 방식이 효과적이라는 점을 배웠다. `justify-content`와 `align-items`의 조합으로 중앙 정렬을 단순하게 처리할 수 있게 되었고, Grid의 `fr` 단위와 `span` 속성을 통해 반응형 레이아웃을 구성하는 감각을 익힐 수 있었다.
