# 1. 객체 리터럴과 참조 타입

## 무엇인가?
객체는 관련된 데이터와 동작을 **키(Key)와 값(Value)의 쌍**으로 묶어 하나로 관리하는 자료구조이다. 중괄호 `{}`를 사용해 정의하며 키와 값의 쌍을 프로퍼티(Property)라고 부른다. 프로퍼티 값이 함수인 경우에는 메서드(Method)라고 한다.

## 어떻게 사용하는가?

~~~javascript
const card = {
    suit: "하트",
    rank: "A"
};

console.log(card.suit);     // 마침표 표기법
console.log(card["rank"]);  // 대괄호 표기법

card.value = 14;            // 프로퍼티 추가
card.suit = "스페이드";      // 프로퍼티 수정
delete card.rank;           // 프로퍼티 삭제

console.log("suit" in card); // true (프로퍼티 존재 여부 확인)
~~~

- 마침표(`.`) 또는 대괄호(`[]`)를 사용해 프로퍼티에 접근한다.
- 존재하지 않는 키를 조회하면 `undefined`를 반환한다.
- `delete` 연산자를 사용해 특정 프로퍼티를 삭제할 수 있다.
- `in` 연산자로 특정 프로퍼티가 객체 내에 존재하는지 불리언 값으로 확인한다.

## 객체의 메서드와 this

~~~javascript
const person = {
    name: "이용교",
    age: 45,
    getLoginInfo: function() {
        return `${this.name} (${this.age}세)`;
    }
};

console.log(person.getLoginInfo());
~~~

- 객체 내부의 함수인 메서드에서 `this`는 해당 메서드를 호출한 객체 자신을 가리킨다.

## 참조 타입(Reference Type)의 특징

~~~javascript
const card = {
    suit: "하트",
    rank: "A"
};

const a = card;
a.suit = "스페이드";

console.log(card.suit); // 스페이드
~~~

- 객체는 원시 타입과 달리 메모리의 참조(주소)가 전달된다.
- 변수 `a`에 `card`를 할당하면 실제 객체 데이터가 새로 복제되는 것이 아니라 동일한 메모리 주소를 가리키게 된다.
- 따라서 `a`를 통해 프로퍼티를 변경하면 원본 `card` 객체도 함께 변경된다.

# 2. 배열 기본과 조작 메서드

## 무엇인가?
배열은 여러 개의 데이터를 **순서대로 나열하여 저장하는 자료구조**이다. 대괄호 `[]`를 사용하여 생성하며, 각 데이터의 위치는 0부터 시작하는 인덱스(Index)로 관리한다.

## 어떻게 사용하는가?

~~~javascript
const fruits = ["사과", "바나나", "오렌지"];

console.log(fruits[0]);      // 사과 (인덱스 조회)
console.log(fruits.length); // 3 (배열 요소 개수)
~~~

- 숫자, 문자열, 불리언, 객체, 또 다른 배열 등 다양한 자료형을 하나의 배열 안에 함께 담을 수 있다.

## 요소 추가, 삭제 및 결합 메서드

~~~javascript
const items = ["B", "C"];

items.push("D");    // 배열 끝에 추가 -> ["B", "C", "D"]
items.unshift("A"); // 배열 앞에 추가 -> ["A", "B", "C", "D"]
items.pop();        // 배열 끝 요소 제거 -> ["A", "B", "C"]
items.shift();      // 배열 앞 요소 제거 -> ["B", "C"]

const subItems = items.slice(0, 1); // 인덱스 0부터 1 전까지 추출 (원본 유지)
const addedFruits = items.concat(["D", "E"]); // 새 배열로 병합 (원본 유지)
const joinedText = [2026, "07", 17].join("-"); // 구분자로 연결하여 문자열 반환 -> "2026-07-17"
~~~

- `push()`와 `pop()`은 배열의 끝부분에서 요소를 삽입하거나 삭제한다.
- `unshift()`와 `shift()`는 배열의 첫 부분에서 요소를 삽입하거나 삭제한다.
- `slice(start, end)`는 지정한 범위의 요소를 잘라내어 새 배열로 반환하며 원본 배열을 손상하지 않는다.
- `join()`은 배열 내부의 모든 요소를 특정 문자열 구분자로 결합하여 하나의 문자열로 만든다.

# 3. 배열 반복 메서드와 데이터 가공

반복문(`for`, `while`)을 작성하지 않고도 배열 전용 고차 메서드를 활용해 데이터를 순회하고 가공할 수 있다.

## 주요 반복 메서드

~~~javascript
// 1. forEach: 각 요소를 순회하며 작업 수행
products.forEach((product) => {
    console.log(product.name);
});

// 2. map: 각 요소를 변환하여 새로운 배열 생성
const prices = products.map((product) => {
    return product.price * 1.1;
});

// 3. filter: 조건식이 참인 요소만 추출하여 새 배열 생성
const sellableItems = products.filter(product => product.stock > 0);

// 4. some: 조건을 만족하는 요소가 하나라도 있는지 검사
const hasAdultProduct = products.some(product => product.isAdultOnly);

// 5. every: 모든 요소가 조건을 만족하는지 검사
const isAllInStock = products.every(product => product.stock > 0);

// 6. reduce: 누적 연산을 통해 단일 결과값 도출
const total = products.reduce((sum, product) => {
    return sum + product.price * product.stock;
}, 0);
~~~

- `forEach()`는 단순히 배열 요소를 하나씩 전달받아 실행하는 순회 함수이다.
- `map()`은 기존 배열의 각 요소를 가공한 결과값들을 모아 동일한 길이의 새 배열을 반환한다.
- `filter()`는 콜백 함수가 `true`를 반환하는 항목만 골라낸 새 배열을 반환한다.
- `some()`과 `every()`는 조건 일치 여부에 따라 불리언(`true`/`false`) 값을 반환한다.
- `reduce()`는 누적 계산값(accumulator)과 현재 요소(currentValue)를 사용해 최종 값 하나를 생성한다.

# 4. 다차원 배열과 유사 배열 객체

## 다차원 배열
배열의 요소로 또 다른 배열을 포함하는 구조이다. 행과 열 같은 격자 데이터를 다룰 때 주로 사용한다.

~~~javascript
const matrix = [
    [1, 2, 3],
    [4, 5, 6]
];

console.log(matrix[1][2]); // 6 (인덱스 1번 행의 인덱스 2번 열 접근)
~~~

## 유사 배열 객체(Array-like Object)
배열처럼 0부터 시작하는 숫자 형태의 키와 `length` 프로퍼티를 가지고 있지만 실제 배열은 아닌 객체이다.

~~~javascript
const arrayLike = {
    0: "A",
    1: "B",
    2: "C",
    length: 3
};

const resultString = Array.prototype.join.call(arrayLike, ",");
console.log(resultString); // "A,B,C"
~~~

- 일반 배열 메서드(`push`, `map` 등)를 직접 호출할 수는 없다.
- `Array.prototype.메서드명.call(유사배열객체, 인자)` 방식을 통해 배열 메서드를 간접적으로 적용할 수 있다.

# 5. 구조 분해 할당과 전개 연산자

## 구조 분해 할당(Destructuring Assignment)
배열이나 객체의 값을 분해하여 개별 변수에 즉시 할당하는 문법이다.

~~~javascript
// 배열 구조 분해 할당: 위치(순서)를 기준으로 할당
const RGB = ["red", "green", "blue"];
const [r, g, b] = RGB;
const [first, , third] = RGB; // 쉼표로 특정 순서 건너뛰기
const [x, y = 0] = [120];      // 기본값 지정

// 객체 구조 분해 할당: 키 이름을 기준으로 할당
const user = {
    id: 101,
    nickname: "자바스크립트",
    role: "admin"
};

const { nickname, role } = user;
const { id: userId } = user; // 새 변수명으로 변경하여 할당
~~~

- 배열은 대괄호 `[]` 안의 순서대로 값이 대입된다.
- 객체는 중괄호 `{}` 안에서 프로퍼티의 키 이름과 일치하는 변수로 값이 대입된다.
- `기존키: 새변수명` 문법을 사용하면 원하는 변수 이름으로 변경하여 추출할 수 있다.

## 전개 연산자(Spread Operator)
마침표 3개(`...`)를 사용하여 배열이나 객체의 요소를 낱개로 펼치는 문법이다.

~~~javascript
// 배열 전개
const parts1 = ["엔진", "바퀴"];
const parts2 = ["핸들", "시트"];
const carParts = [...parts1, "범퍼", ...parts2];

// 객체 전개 및 덮어쓰기
const baseSetting = {
    theme: "light",
    volume: 50
};

const userSetting = {
    ...baseSetting,
    volume: 80,
    autoUpdate: true
};
~~~

- 기존 배열을 바탕으로 새로운 배열을 복사하거나 결합할 때 편리하다.
- 객체에서 사용할 경우 기존 프로퍼티들을 복사하며, 동일한 키가 뒤에 위치하면 뒤쪽의 값이 앞의 값을 덮어쓴다.

# 6. Map과 Set 자료구조

## Map
키와 값의 쌍을 저장하는 컬렉션 자료구조이다.

~~~javascript
const zip = new Map([
    ["Tom", "131-8634"],
    ["Huck", "556-0002"]
]);

zip.set("Becky", "154-0000"); // 데이터 추가
console.log(zip.get("Tom"));   // 데이터 조회 -> "131-8634"
~~~

- 일반 객체는 키로 문자열이나 심볼만 허용하지만, `Map`은 객체를 포함한 모든 자료형을 키로 지정할 수 있다.
- `set()` 메서드로 추가하고 `get()` 메서드로 값을 꺼낸다.

## Set
중복을 허용하지 않고 유일한 값들만 보관하는 자료구조이다.

~~~javascript
const uniqueSet = new Set(["A", "B", "A"]);

console.log(uniqueSet.size); // 2
~~~

- 동일한 값을 중복해서 추가해도 하나의 값만 저장된다.
- `size` 프로퍼티를 통해 저장된 고유한 데이터 개수를 확인할 수 있다.

# 7. 내장 객체와 Math 활용

JavaScript는 기본 기능을 처리할 수 있도록 런타임에 미리 정의된 다양한 표준 내장 객체를 제공한다.

## 대표적인 내장 객체
- `Object`, `Array`: 복합 데이터(객체, 배열) 관리
- `String`, `Number`: 문자열 및 숫자 조작
- `Date`: 날짜와 시간 연산
- `RegExp`: 정규 표현식 패턴 검사
- `Error`: 예외 상황 및 오류 정보 관리
- `Map`, `Set`: 고유 컬렉션 자료구조
- `Promise`: 비동기 연산 처리
- `JSON`: 경량 데이터 교환 포맷 처리
- `Math`: 수학적 계산을 위한 유틸리티

실행 환경에 따라 브라우저는 `window`, Node.js는 `global`을 전역 객체로 제공하며, `globalThis`를 사용하면 환경에 구애받지 않고 표준 전역 객체에 접근할 수 있다.

## Math 객체의 주요 메서드
- `Math.abs()`: 절댓값 계산
- `Math.round()` / `Math.ceil()` / `Math.floor()`: 반올림 / 올림 / 내림
- `Math.trunc()`: 정수 부분만 남기고 소수점 절삭
- `Math.max()` / `Math.min()`: 최댓값 및 최솟값 추출
- `Math.random()`: 0 이상 1 미만의 부동소수점 난수 생성

~~~javascript
function getRandomInt(min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}

const rollDice = getRandomInt(1, 6);
~~~

- `Math.random()`과 `Math.floor()`를 조합하여 원하는 정수 난수 범위를 산출할 수 있다.

# 8. 원시 타입과 래퍼 객체

문자열이나 숫자 같은 원시 타입은 객체가 아니지만 객체처럼 전용 메서드를 바로 호출할 수 있다.

## 자동 박싱(Auto-Boxing) 동작 원리

~~~javascript
const text = "javascript";

console.log(text.toUpperCase()); // "JAVASCRIPT"
~~~

- 원시 타입의 메서드를 호출하는 순간, JavaScript 엔진은 해당 값을 임시 래퍼 객체(`String`, `Number`, `Boolean` 등)로 자동 변환한다.
- 메서드 실행이 완료되면 임시 래퍼 객체는 즉시 소멸하고 본래의 원시 값으로 돌아간다.

## 주의해야 할 점

~~~javascript
let nickname = "gildong";
nickname.tempData = "회원정보A";

console.log(nickname.tempData); // undefined
~~~

- 원시 값에 임의로 프로퍼티를 추가해도 메서드 실행 직후 임시 객체가 사라지므로 값이 영구 보존되지 않는다.
- `new Boolean(false)`와 같이 생성자 함수를 사용해 직접 래퍼 객체를 만들면, 객체 자체는 조건문에서 Truthy로 평가되므로 직접 생성하는 방식은 지양해야 한다.

# 9. JSON 데이터 변환

JSON(JavaScript Object Notation)은 네트워크 통신이나 파일 저장 시 데이터를 문자열로 표현하는 표준 경량 포맷이다.

~~~javascript
const orderInfo = {
    id: 1052,
    product: "스마트폰"
};

// 1. 직렬화: 객체 -> JSON 문자열
const serializedData = JSON.stringify(orderInfo);
console.log(typeof serializedData); // "string"

// 2. 역직렬화: JSON 문자열 -> 객체
const parsedData = JSON.parse(serializedData);
console.log(typeof parsedData);     // "object"
console.log(parsedData.product);    // "스마트폰"
~~~

- `JSON.stringify()`: JavaScript 객체를 네트워크 전송이 가능한 JSON 문자열 형태로 직렬화한다.
- `JSON.parse()`: 수신한 JSON 문자열을 파싱하여 실제 활용 가능한 JavaScript 객체로 복원한다.

# 10. MDN 공식 문서 활용법

JavaScript의 방대한 API와 메서드를 전부 암기하는 것은 비효율적이므로, 공식 문서인 MDN(Mozilla Developer Network)을 탐색하여 올바른 사용 규격을 확인해야 한다.

- 메서드의 정확한 기능과 동작 목적 확인
- 전달해야 할 매개변수의 타입 및 필수 여부 확인
- 실행 후 반환되는 반환값의 데이터 타입 확인
- 호출 시 원본 데이터를 직접 수정하는지 여부 확인
- 다양한 옵션 객체 지원 여부 및 브라우저 호환성 표 확인

# 11. 비교 정리

## 배열 메서드의 원본 데이터 변경 여부

| 구분 | 대상 메서드 | 특징 |
|---|---|---|
| 원본 변경 (Mutable) | `push()`, `pop()`, `shift()`, `unshift()`, `reverse()`, `splice()` | 메서드 호출 후 원래 배열의 요소나 순서가 직접 수정된다. |
| 원본 유지 (Immutable) | `slice()`, `concat()`, `map()`, `filter()`, `join()`, `forEach()`, `reduce()` | 기존 배열은 그대로 두고 새로운 배열이나 연산 결과를 반환한다. |

## 객체와 Map의 차이

| 구분 | 객체(Object) | Map |
|---|---|---|
| 키의 타입 | 문자열(String), 심볼(Symbol) | 객체를 포함한 모든 데이터 타입 허용 |
| 크기 확인 | `Object.keys(obj).length` 계산 필요 | `map.size` 프로퍼티로 즉시 확인 |
| 요소 순서 | 보장되지 않거나 복잡함 | 삽입된 순서를 엄격하게 보장 |

# 12. 핵심 정리

### 핵심 코드

~~~javascript
// 배열 고차 메서드 조합
const result = items
    .filter(item => item.price >= 1000)
    .map(item => item.name);

// 직렬화 및 역직렬화
const jsonText = JSON.stringify(data);
const restoredData = JSON.parse(jsonText);
~~~

- `filter`와 `map`을 체이닝하여 조건 검색과 결과 가공을 한 번에 처리한다.
- `JSON.stringify`와 `JSON.parse`로 데이터 전송 규격을 변환한다.

### 핵심 개념
- 객체는 키-값 기반이며 메모리 주소를 공유하는 참조 타입이다.
- 배열은 인덱스 기반의 순서형 구조이며 목적에 따라 원본 변경 메서드와 불변 메서드를 구분해 사용해야 한다.
- 구조 분해 할당과 전개 연산자를 통해 복합 데이터를 간결하고 안전하게 가공할 수 있다.

# 13. 느낀 점

이번 학습을 통해 객체와 배열의 내부 구조 차이뿐만 아니라 참조 타입의 메모리 동작 방식을 명확히 이해할 수 있었다. 실무에서 자주 사용되는 `map()`, `filter()`, `reduce()` 같은 고차 배열 메서드의 불변성 유지 특성과 구조 분해 할당의 유용성을 체감했다. 모든 문법을 억지로 외우려 하기보다는 MDN 공식 문서를 참조하여 원본 변경 여부와 반환값을 정확히 검토하는 개발 습관을 길러야겠다.
