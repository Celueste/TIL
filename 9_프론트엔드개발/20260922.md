# 1. 주석과 콘솔 출력

## 무엇인가?
주석은 프로그램 실행에는 영향을 주지 않고 코드에 메모나 설명을 작성하는 기능이다. `console.log()`는 전달받은 값이나 연산 결과를 콘솔 창에 출력하는 함수이다.

## 어떻게 사용하는가?
한 줄 주석은 `//`를 사용하고, 여러 줄 주석은 `/* */`를 사용한다.

~~~javascript
// 한 줄 주석

/*
여러 줄에 걸쳐
작성하는 주석
*/

console.log("결과를 콘솔에 출력한다.");
~~~

- `//` 뒤에 작성한 내용은 해당 줄에서 실행되지 않는다.
- `/* */` 사이에 작성한 내용은 여러 줄에 걸쳐 주석으로 처리된다.
- `console.log()`는 변수의 값이나 코드 실행 결과를 확인하고 디버깅할 때 사용한다.

# 2. 변수 선언 방식과 스코프

변수를 선언할 때는 선언 키워드에 따라 유효 범위(스코프)와 재할당 가능 여부가 달라진다.

## var의 특징과 문제점
`var`는 초기 JavaScript에서 사용하던 선언 방식이다. 함수 레벨 스코프를 따르며 변수 선언이 위로 끌어올려지는 것처럼 동작하는 호이스팅이 발생한다.

~~~javascript
console.log(currentPoint); // undefined

var currentPoint = 10;

console.log(currentPoint); // 10
~~~

- 변수를 선언하기 전에 참조해도 오류가 발생하지 않고 `undefined`가 출력된다.
- `if`나 `for` 같은 블록 내부에서 선언해도 블록 외부에서 접근할 수 있어 값의 충돌이나 예기치 못한 변경이 발생할 위험이 있다.

## let과 const
`let`과 `const`는 블록 레벨 스코프를 지원하므로 `{}` 블록 안에서 선언된 변수는 블록 외부에서 접근할 수 없다.

~~~javascript
let score = 10;
score = 20; // 값 재할당 가능

const apiEndpoint = "https://server.com/v1";
// apiEndpoint = "https://server.com/v2"; // 오류 발생 (재할당 불가)
~~~

- `let`은 값을 다시 할당해야 하는 경우에 사용한다.
- `const`는 한 번 할당한 후 값을 변경하지 않는 상수를 선언할 때 사용한다.
- 기본적으로 안전한 `const`를 사용하고 재할당이 필요한 변수에만 `let`을 사용하는 것이 권장된다.

# 3. 데이터 타입과 typeof

JavaScript의 기본 데이터 타입에는 `Number`, `String`, `Boolean`, `null`, `undefined` 등이 있다.

## typeof 연산자
`typeof`는 값이나 변수 뒤에 작성하여 해당 데이터의 자료형을 문자열 형태로 반환한다.

~~~javascript
let count = 42;
let greeting = "Hello";
let isCompleted = false;
let unknownBox;

console.log(typeof count);       // "number"
console.log(typeof greeting);    // "string"
console.log(typeof isCompleted); // "boolean"
console.log(typeof unknownBox);  // "undefined"
~~~

- 값이 할당되지 않은 변수는 자료형과 값 모두 `undefined`로 처리된다.

## null 사용 시 주의점

~~~javascript
let emptyBox = null;

console.log(typeof emptyBox); // "object"
~~~

- `null`은 의도적으로 "값이 비어 있음"을 나타내는 원시 타입이지만, `typeof null`을 실행하면 언어 초기 설계상의 이유로 `"object"`가 반환된다.

# 4. 템플릿 리터럴과 Truthy·Falsy

## 템플릿 리터럴
문자열 연결 연산자(`+`) 대신 백틱(`` ` ``)을 사용하여 문자열 내부에 변수나 연산식을 직접 삽입할 수 있다.

~~~javascript
let userName = "Alice";
let userScore = 95;

// 문자열 연결 방식
console.log("안녕하세요, " + userName + "님의 점수는 " + userScore + "점입니다.");

// 템플릿 리터럴 방식
console.log(`안녕하세요, ${userName}님의 점수는 ${userScore}점입니다.`);
~~~

- `${}` 안에 변수나 계산식을 작성하면 문자열 안에서 바로 계산되어 결합된다.

## Truthy와 Falsy
조건문에서 불리언 타입(`true`, `false`)이 아니더라도 참 또는 거짓으로 평가되는 특성을 말한다.

- **Falsy 값**: `false`, `0`, `""`(빈 문자열), `null`, `undefined`, `NaN`
- **Truthy 값**: Falsy 값을 제외한 모든 값 (빈 배열 `[]`, 빈 객체 `{}`도 Truthy로 평가된다.)

# 5. 연산자의 종류와 활용

JavaScript는 값 계산과 비교, 논리 처리를 위한 다양한 연산자를 제공한다.

## 산술 연산자
- 사칙연산과 나머지를 계산한다: `+`, `-`, `*`, `/`, `%`

## 비교 연산자
동등 연산자(`==`)와 달리 엄격한 비교 연산자(`===`, `!==`)는 값과 데이터 타입을 모두 검사한다.

~~~javascript
let requiredAge = 19;
let enteredAge = "19";

console.log(enteredAge === requiredAge); // false
~~~

- 숫자 `19`와 문자열 `"19"`는 값의 형태가 같아 보여도 타입이 서로 다르므로 `===` 비교 시 `false`가 된다.

## 논리 연산자
여러 조건식을 결합하거나 반전할 때 사용한다.

- `&&` (AND): 양쪽 조건이 모두 참일 때만 참이 된다.
- `||` (OR): 양쪽 조건 중 하나라도 참이면 참이 된다.
- `!` (NOT): 참과 거짓을 반대로 뒤집는다.

# 6. 조건문을 통한 흐름 제어

주어진 조건의 참/거짓 여부에 따라 실행할 코드 블록을 분기한다.

## if / else if / else
조건식의 결과에 따라 순차적으로 코드를 실행한다.

~~~javascript
if (userRole === "admin") {
    console.log("관리자");
} else if (userRole === "manager") {
    console.log("매니저");
} else {
    console.log("일반 사용자");
}
~~~

- 조건이 참인 첫 번째 블록만 실행하고 전체 `if`문을 빠져나간다.

## switch-case
하나의 변수나 표현식의 값을 여러 경우(`case`)와 비교할 때 유용하다.

~~~javascript
switch (couponType) {
    case "GOLD":
        discountRate = 30;
        break;
    case "SILVER":
        discountRate = 20;
        break;
    default:
        discountRate = 0;
}
~~~

- 일치하는 `case`를 찾아 진입한 후 `break`를 만날 때까지 아래 코드를 계속 실행한다.
- `break`를 명시하지 않으면 다음 `case` 블록까지 실행되는 현상이 발생하므로 주의해야 한다.
- 일치하는 `case`가 없을 때는 `default` 블록이 실행된다.

# 7. 반복문과 반복 흐름 제어

동일한 작업을 조건에 따라 여러 번 반복 실행할 때 사용한다.

## 반복문의 기본 구조
- **`for`문**: 반복 횟수가 명확할 때 주로 사용한다.
- **`while`문**: 특정 조건이 참인 동안 계속 반복할 때 사용한다. 조건 변경 처리가 없으면 무한 루프가 발생할 수 있다.
- **`do-while`문**: 조건을 검사하기 전에 본문 코드를 최소 1회 먼저 실행한다.

~~~javascript
// for문
for (let i = 1; i <= 3; i++) {
    console.log(i);
}

// while문
let count = 1;
while (count < 3) {
    console.log(count);
    count++;
}

// do-while문
do {
    console.log("한 번은 실행된다.");
} while (false);
~~~

## break와 continue를 활용한 흐름 제어

~~~javascript
// break: 반복문 즉시 종료
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break;
    }
}

// continue: 현재 회차를 건너뛰고 다음 반복 진행
for (let i = 1; i <= 5; i++) {
    if (i % 2 === 0) {
        continue;
    }
    console.log(i); // 홀수만 출력된다.
}
~~~

- `break`는 반복문 실행을 완전히 중단하고 루프를 빠져나간다.
- `continue`는 현재 회차의 남은 명령을 건너뛰고 다음 반복 조건 검사(증감식)로 이동한다.

# 8. try-catch-finally를 활용한 오류 처리

코드 실행 도중 발생하는 예외로 인해 프로그램이 비정상적으로 종료되는 것을 방지하고 오류를 처리한다.

~~~javascript
try {
    console.log(nonExistentData);
} catch (error) {
    console.log("오류가 발생했습니다.");
    console.log(error.name);
    console.log(error.message);
} finally {
    console.log("마무리 작업");
}
~~~

- `try`: 오류가 발생할 가능성이 있는 코드를 작성한다.
- `catch`: `try` 블록에서 오류가 발생했을 때 실행되며 전달된 `error` 객체로 오류 정보를 분석한다.
- `finally`: 오류 발생 여부와 상관없이 항상 마지막에 반드시 실행된다.

### 에러 객체의 주요 프로퍼티
- `error.name`: 발생한 오류의 종류를 나타낸다.
- `error.message`: 오류의 상세 내용이나 원인 설명을 나타낸다.
- `error.stack`: 오류가 발생한 위치와 호출 경로를 나타낸다.

# 9. 비교 정리

| 구분 | `var` | `let` | `const` |
|---|---|---|---|
| 스코프 | 함수 레벨 스코프 | 블록 레벨 스코프 | 블록 레벨 스코프 |
| 재할당 | 가능 | 가능 | 불가능 |
| 재선언 | 가능 | 불가능 | 불가능 |
| 권장 용도 | 권장하지 않음 | 값 변경이 필요한 변수 | 일반적인 상수 및 변수 |

| 구분 | `break` | `continue` |
|---|---|---|
| 동작 방식 | 반복문을 즉시 완전히 종료 | 현재 회차만 중단하고 다음 반복으로 진행 |
| 루프 유지 여부 | 루프를 완전히 빠져나감 | 다음 회차를 계속 실행함 |

# 10. 느낀 점

이번 학습을 통해 JavaScript에서 단순히 문법을 외우는 것을 넘어 코드가 어떤 순서와 조건으로 실행되는지 파악하는 것이 기본이라는 점을 알게 되었다. 특히 `var`와 `let`, `const`의 스코프 차이 및 호이스팅 문제, 그리고 `break`와 `continue`의 흐름 제어 차이를 명확하게 정리할 수 있었다. 앞으로는 예기치 않은 오류를 방지하기 위해 기본적으로 `const`를 사용하고, 반복문과 예외 처리 구문을 목적에 맞게 안정적으로 작성해야겠다.
