- 블록 요소(한 줄 차지)와 인라인 요소(내용 크기 차지)의 차이를 이해하고 화면 요소를 적절히 배치한다.
- `form`, `input`, `label` 태그를 활용하여 사용자 입력을 처리하며 `id`, `name`, `value`의 역할을 구분한다.

## 1. HTML 기본 개념

### HTML의 정의

HTML은 **HyperText Markup Language**의 약자이다. 웹 페이지의 뼈대와 텍스트, 멀티미디어 등의 구조적 의미를 브라우저에 전달하는 마크업 언어이다.

- 프로그래밍 언어와 달리 조건문이나 연산 로직을 실행하지 않는다.
- 브라우저가 화면에 문서를 어떻게 배치하고 해석할지 규정하는 역할을 한다.

### 태그(Tag) 구조

HTML은 태그를 사용하여 문서의 각 영역과 역할을 구분한다.

~~~html
<p>안녕하세요</p>
~~~

- `<p>`: 시작 태그
- `안녕하세요`: 태그 내부의 텍스트 내용
- `</p>`: 슬래시(`/`)가 붙는 종료 태그

### HTML 주석

화면에 출력되지 않고 코드에 대한 설명이나 메모를 남길 때 사용한다.

~~~html
<!-- 주석 내용입니다. 브라우저 화면에 출력되지 않습니다. -->
~~~

## 2. HTML 문서 기본 구조

HTML 문서는 브라우저 해석을 위한 표준 규격에 따라 기본 틀을 작성한다.

~~~html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8">
        <title>웹 페이지 제목</title>
    </head>
    <body>
        <h1>안녕하세요</h1>
        <p>HTML을 공부하고 있습니다.</p>
    </body>
</html>
~~~

- `<!DOCTYPE html>`: 현재 문서가 HTML5 표준을 따르는 문서임을 브라우저에 알린다.
- `<html>`: HTML 문서의 전체를 감싸는 최상위 루트 태그이다.
- `<head>`: 화면에 직접 보이지 않는 메타데이터(문자 인코딩, 문서 제목, 외부 파일 연결 등)를 정의한다.
- `<body>`: 브라우저 뷰포트 영역에 실제로 렌더링되어 사용자가 보는 본문 내용을 작성한다.

## 3. 텍스트 관련 태그

### 제목 태그

`<h1>`부터 `<h6>`까지 단계별로 사용한다.

~~~html
<h1>가장 중요한 제목</h1>
<h2>두 번째 제목</h2>
<h3>세 번째 제목</h3>
~~~

- 숫자가 작을수록 높은 계층의 핵심 제목을 의미한다.
- 검색 엔진 최적화(SEO) 및 문서 구조화에 중요한 기준이 된다.

### 본문 및 줄바꿈 태그

~~~html
<p>첫 번째 문단입니다.</p>
<p>두 번째 문단이며, 줄바꿈을<br>진행합니다.</p>
<hr>
~~~

- `<p>`: 독립된 텍스트 문단을 나타내며 기본 상하 여백을 갖는다.
- `<br>`: 닫는 태그 없이 문장 내에서 강제로 줄을 바꾼다.
- `<hr>`: 문맥상 내용 전환을 나타내는 수평 구분선을 출력한다.

### 텍스트 강조 태그

~~~html
<strong>중요한 내용 강조</strong>
<em>의미상 기울임 강조</em>
<mark>형광펜 하이라이트 효과</mark>
<u>단순 밑줄 표시</u>
~~~

- `<strong>`과 `<em>`은 단순한 시각적 효과 외에 스크린 리더 등에서 중요한 의미를 갖는 시맨틱 태그이다.

## 4. 블록 요소와 인라인 요소

HTML 태그는 화면 배치 규칙에 따라 크게 블록 레벨 요소와 인라인 레벨 요소로 구분된다.

### 블록 요소 (Block Elements)

~~~html
<div>블록 요소 구역</div>
<p>문단 영역</p>
<h1>제목 영역</h1>
~~~

- 가로 폭 전체(100%)를 차지하며, 요소 전후로 자동 줄바꿈이 발생한다.
- `div`, `p`, `h1`~`h6`, `ul`, `ol` 등이 해당한다.

### 인라인 요소 (Inline Elements)

~~~html
<span>인라인 요소</span>
<strong>강조</strong>
<a href="#">링크</a>
~~~

- 텍스트나 내용의 크기만큼만 공간을 차지하며 나란히 옆으로 배치된다.
- 줄바꿈이 일어나지 않으며, `span`, `a`, `strong`, `img` 등이 해당한다.

## 5. 하이퍼링크와 멀티미디어 태그

### 링크 태그 (`<a>`)

다른 웹 페이지나 특정 리소스로 이동할 때 사용한다.

~~~html
<a href="https://www.google.com" target="_blank">구글 새 탭에서 열기</a>
~~~

- `href`: 이동할 대상 페이지의 URL 주소를 지정한다.
- `target="_blank"`: 현재 탭이 아닌 새 브라우징 컨텍스트(새 탭)에서 링크를 연다.

### 이미지 태그 (`<img>`)

~~~html
<img src="image.jpg" alt="실습 프로필 이미지">
~~~

- `src`: 표시할 이미지 파일의 경로나 URL을 지정한다.
- `alt`: 이미지가 로딩되지 않을 때 표시되는 대체 텍스트이며 웹 접근성을 위해 필수적이다.

### 미디어 태그 (`<video>`, `<audio>`)

~~~html
<video src="video.mp4" controls></video>
<audio src="music.mp3" controls></audio>
~~~

- `controls`: 재생, 일시정지, 볼륨 조절 등의 플레이어 인터페이스를 활성화한다.

## 6. 리스트 태그

### 순서가 없는 리스트 (`<ul>`)

항목 앞에 기본 불릿 기호가 붙는다.

~~~html
<ul>
    <li>사과</li>
    <li>바나나</li>
    <li>오렌지</li>
</ul>
~~~

### 순서가 있는 리스트 (`<ol>`)

항목 앞에 번호가 순차적으로 매겨진다.

~~~html
<ol>
    <li>HTML 공부</li>
    <li>CSS 공부</li>
    <li>JavaScript 공부</li>
</ol>
~~~

- `<li>`: `<ul>` 또는 `<ol>` 내부에서 개별 항목을 정의한다.

## 7. 폼과 사용자 입력 태그

사용자로부터 입력을 받아 서버로 전송할 때 사용한다.

### form 기본 구조

~~~html
<form action="/submit" method="post">
    <label for="username">이름</label>
    <input type="text" id="username" name="username" value="홍길동">
    <button type="submit">제출</button>
</form>
~~~

- `action`: 입력 데이터를 전달받아 처리할 서버 주소이다.
- `method`: 전송 방식(`GET` 또는 `POST`)을 지정한다.
- `label`: 입력 필드의 역할을 명시하며, `for` 속성을 `input`의 `id`와 일치시켜 상호작용 영역을 연결한다.

### input 유형

~~~html
<input type="text">      <!-- 일반 텍스트 입력 -->
<input type="password">  <!-- 마스킹 처리되는 비밀번호 입력 -->
<input type="email">     <!-- 이메일 형식 검증 입력 -->
<input type="number">    <!-- 숫자 입력 -->
<input type="date">      <!-- 날짜 선택 달력 -->
<input type="color">     <!-- 색상 팔레트 선택 -->
<input type="file">      <!-- 파일 첨부 -->
~~~

### 선택 요소 (라디오 버튼과 체크박스)

~~~html
<!-- 단일 선택: 동일한 name으로 그룹화 -->
<input type="radio" name="gender" value="male"> 남성
<input type="radio" name="gender" value="female"> 여성

<!-- 다중 선택 -->
<input type="checkbox" name="hobby" value="reading"> 독서
<input type="checkbox" name="hobby" value="game"> 게임
~~~

### 드롭다운과 장문 입력

~~~html
<!-- 선택 상자 -->
<select name="fruit">
    <option value="apple">사과</option>
    <option value="banana">바나나</option>
</select>

<!-- 여러 줄 텍스트 입력 -->
<textarea name="message"></textarea>
~~~

### 버튼 유형

~~~html
<button type="submit">제출</button>      <!-- 폼 데이터를 서버로 전송 -->
<button type="reset">초기화</button>     <!-- 폼 입력 필드를 초기화 -->
<button type="button">일반 버튼</button>  <!-- 스크립트 실행을 위한 기본 버튼 -->
~~~

## 9. 비교 정리

### 배치 특성 비교

| 구분 | 블록 요소 (`div`, `p`, `h1`) | 인라인 요소 (`span`, `a`, `strong`) |
|---|---|---|
| 공간 차지 | 부모 너비의 100% (가로 전체 차지) | 태그 내부 콘텐츠 크기만큼 차지 |
| 줄바꿈 | 요소 생성 시 자동 줄바꿈 발생 | 다음 요소가 같은 줄에 나란히 배치됨 |

### 폼 핵심 속성 비교

| 속성명 | 주요 역할 | 동작 위치 |
|---|---|---|
| `id` | 문서 내 특정 요소 식별, `label`과의 연결, CSS/JS 선택자 | 브라우저 클라이언트 |
| `name` | 전송 시 데이터의 파라미터 Key 값으로 사용 | 서버 전송 |
| `value` | 해당 입력 태그가 실제로 담고 있는 실질적 Data 값 | 서버 전송 및 입력값 |

## 10. 전체 흐름 정리

웹 페이지 작성 시 논리적인 흐름 구조는 다음과 같다.

~~~text
문서 기본 규격 선언 (<!DOCTYPE html>, <html>, <head>, <body>)
    |
    v
헤드 메타정보 설정 (인코딩, 제목, 링크)
    |
    v
본문 구조화 (제목 h1~h6, 본문 p, 리스트 ul/ol)
    |
    v
멀티미디어 및 하이퍼링크 연결 (a, img, video)
    |
    v
사용자 데이터 수집 영역 구축 (form, label, input, button)
~~~

### 종합 실습 예시

~~~html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8">
        <title>자기소개</title>
    </head>
    <body>
        <h1>안녕하세요</h1>
        <p>저는 IT를 공부하고 있습니다.</p>

        <h2>취미</h2>
        <ul>
            <li>음악 듣기</li>
            <li>여행하기</li>
        </ul>

        <h2>연락처</h2>
        <form action="/contact" method="post">
            <label for="email">이메일</label>
            <input type="email" id="email" name="email">
            <button type="submit">제출</button>
        </form>
    </body>
</html>
~~~

- HTML 기본 골격을 바탕으로 제목, 문단, 목록, 폼 입력 요소를 구성한다.

## 11. 핵심 정리

### 주요 태그 분류표

| 태그 | 역할 |
|---|---|
| `html` | HTML 문서의 전체 범위를 정의하는 루트 태그 |
| `head` | 문서 메타데이터 및 문서 설정을 정의 |
| `body` | 화면에 노출되는 실제 문서 본문 내용 |
| `h1`~`h6` | 계층 구조를 갖는 텍스트 제목 |
| `p` / `br` / `hr` | 문단 구분 / 강제 줄바꿈 / 수평 구분선 |
| `strong` / `em` | 중요 내용 강조 / 의미상 기울임 강조 |
| `a` | 하이퍼링크 생성 (`href`, `target` 속성) |
| `img` | 이미지 리소스 표시 (`src`, `alt` 속성) |
| `video` / `audio` | 미디어 파일 재생 (`controls` 속성) |
| `form` | 사용자 입력 데이터 전송 폼 (`action`, `method` 속성) |
| `input` | 다양한 형태의 단일 라인 사용자 입력 처리 |
| `label` | 입력 요소 설명 표시 및 `id` 기반 연결 |
| `select` / `textarea` | 드롭다운 목록 / 여러 줄 장문 입력 |
| `button` | 폼 전송 및 일반 동작 제어 버튼 |
| `ul` / `ol` / `li` | 순서 없는 목록 / 순서 있는 목록 / 개별 리스트 항목 |
| `div` / `span` | 블록 단위 그룹화 / 인라인 단위 그룹화 |

---

## 12. 느낀 점

HTML은 웹 페이지의 내용을 단순히 텍스트 형태로 나열하는 것이 아니라 태그를 통해 각 요소의 의미와 화면 구조를 체계적으로 정의하는 언어임을 확인했다.
특히 폼 요소에서 혼동하기 쉬운 `id`, `name`, `value`의 명확한 차이점과 `label`을 활용한 웹 접근성 연결 방식을 명확히 정리할 수 있었다.
앞으로 개인 자기소개 페이지를 직접 구현하며 시맨틱 태그와 다양한 입력 컴포넌트를 적재적소에 적용해보아야겠다.
