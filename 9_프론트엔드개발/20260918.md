# 1. 반응형 웹과 미디어 쿼리 기본

반응형 웹(Responsive Web)은 PC, 태블릿, 모바일 등 접속 기기의 화면 해상도에 맞춰 요소의 크기와 배치가 최적화되는 웹 디자인 방식이다.

## 미디어 쿼리 문법

CSS의 `@media` 문법을 사용하면 출력 장치나 화면 조건에 따라 스타일을 선택적으로 적용할 수 있다.

~~~css
@media screen and (min-width: 768px) {
    body {
        background-color: lightgreen;
    }
}
~~~

- `@media`는 미디어 쿼리를 선언하는 CSS 규칙이다.
- `screen`은 적용 대상이 화면 디스플레이 장치임을 지정하는 미디어 타입이다.
- `(min-width: 768px)`는 뷰포트 가로 너비가 768px 이상일 때 스타일을 적용하라는 미디어 특성 조건이다.
- 화면 크기가 768px 이상이 되면 `body` 태그의 배경색이 연한 초록색으로 변경된다.

## 미디어 타입과 미디어 특성

- 미디어 타입: 장치 유형을 지정한다.
  - `all`: 모든 장치에 적용한다.
  - `screen`: 모니터, 태블릿, 스마트폰 등 화면 장치에 적용한다.
  - `print`: 인쇄용 출력물이나 인쇄 미리보기에 적용한다.
  - `speech`: 음성 출력 장치에 적용한다.
- 미디어 특성: 장치의 물리적 상태를 조건으로 설정한다.
  - `min-width`: 화면의 최소 가로 너비 기준을 설정한다.
  - `max-width`: 화면의 최대 가로 너비 기준을 설정한다.
  - `width` / `height`: 화면의 가로 및 세로 길이를 확인한다.
  - `orientation`: 가로(landscape) 및 세로(portrait) 방향을 확인한다.

~~~css
@media screen and (min-width: 768px) and (max-width: 1023px) {
    /* 태블릿 화면 범위에서만 적용되는 CSS */
}
~~~

- `and` 연산자를 사용해 여러 조건을 동시에 만족할 때만 스타일이 적용되도록 제한할 수 있다.

# 2. 브레이크포인트 설정과 화면 분기

브레이크포인트(Breakpoint)는 화면 레이아웃과 스타일이 전환되는 가로 해상도의 경계 지점을 의미한다.

## 일반적인 화면 구분 기준

- 모바일: `max-width: 767px`
- 태블릿: `min-width: 768px` ~ `max-width: 1023px`
- 데스크톱: `min-width: 1024px` 이상

각 해상도 구간마다 미디어 쿼리를 선언해두면, 사용자가 브라우저 너비를 조절함에 따라 배경색, 폰트 크기, 그리드 구조 등이 자동으로 변경된다.

# 3. Tailwind CSS 기본 개념과 환경 설정

Tailwind CSS는 CSS 속성을 별도의 스타일시트 파일에 작성하지 않고, 이미 준비된 작은 단위의 유틸리티 클래스를 HTML 태그에 직접 조합하여 적용하는 프레임워크이다.

## 환경 설정

~~~html
<head>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
~~~

- `<head>` 태그 내부에 Tailwind CSS CDN 스크립트를 삽입하면 복잡한 빌드 도구 없이 즉시 사용할 수 있다.
- VS Code 환경에서는 `Tailwind CSS IntelliSense` 확장 기능을 설치해 클래스명 자동 완성과 실시간 미리보기를 지원받는다.

# 4. Tailwind CSS 핵심 유틸리티 클래스

Tailwind CSS는 `[속성]-[크기/값]` 구조의 네이밍 규칙을 따른다.

## 여백과 크기 설정

- 기본 단위: Tailwind의 여백 수치 1단위는 `4px`(0.25rem)에 해당한다.
  - `p-4`: `padding: 16px`를 적용한다.
  - `m-10`: `margin: 40px`를 적용한다.
- 크기 단위: `w`는 너비(width), `h`는 높이(height)를 설정한다.

~~~html
<div class="w-80 h-[200px] p-6 m-10">
    컨텐츠 영역
</div>
~~~

- `w-80`: 20rem(320px) 너비를 설정한다.
- `h-[200px]`: 임의 값(Arbitrary values) 문법을 사용해 기본 스케일에 없는 200px 높이를 직접 지정한다.
- `p-6`: 24px의 안쪽 여백을 부여한다.
- `m-10`: 40px의 바깥 여백을 부여한다.

## 텍스트 스타일

~~~html
<h1 class="text-4xl font-black text-slate-800">
    제목
</h1>
~~~

- `text-4xl`: 폰트 크기를 설정한다.
- `font-black`: 폰트 두께를 가장 굵게 설정한다.
- `text-slate-800`: 텍스트 색상을 Slate 계열의 어두운 톤으로 설정한다.
- `leading-`: 줄 간격(line-height)을 설정한다.
- `tracking-`: 자간(letter-spacing)을 설정한다.

## 상태 제어

~~~html
<button class="hover:bg-blue-600">
    버튼
</button>
~~~

- `hover:`와 같은 상태 접두사를 클래스 앞에 붙여 마우스 커서가 올라갔을 때의 동작을 지정한다.

# 5. Tailwind CSS의 레이아웃과 반응형 처리

Tailwind CSS는 Flexbox와 Grid, 그리고 미디어 쿼리를 클래스 접두사로 즉시 제어할 수 있도록 설계되어 있다.

## Flexbox와 Grid 클래스

~~~html
<!-- Flexbox 적용 -->
<div class="flex items-center gap-4">
    <div>아이템 1</div>
    <div>아이템 2</div>
</div>

<!-- Grid 적용 -->
<div class="grid grid-cols-3 gap-6">
    <div class="col-span-2">2칸 차지</div>
    <div>1칸 차지</div>
</div>
~~~

- `flex`: `display: flex`를 적용한다.
- `items-center`: `align-items: center`로 교차축 중앙 정렬을 실행한다.
- `grid`: `display: grid`를 적용한다.
- `grid-cols-3`: 3열 균등 분할 그리드를 생성한다.
- `col-span-2`: 특정 요소가 열 2칸을 병합하여 차지하도록 설정한다.
- `gap-`: Flex 및 Grid 컨테이너 내부 아이템 간격을 설정한다.

## 반응형 접두사와 모바일 우선 원칙

Tailwind CSS는 작은 화면(모바일) 스타일을 기본으로 작성하고, 화면이 커질수록 접두사를 추가해 스타일을 덮어쓰는 모바일 우선(Mobile-First) 방식을 사용한다.

~~~html
<div class="grid grid-cols-1 md:grid-cols-2">
    <div>카드 1</div>
    <div>카드 2</div>
</div>
~~~

- 기본 모바일 화면에서는 `grid-cols-1`이 적용되어 1열로 세로 정렬된다.
- `md:`(768px 이상) 화면부터는 2열 배치가 적용된다.
- 별도의 CSS `@media` 블록을 구성하지 않고 HTML 클래스 선언만으로 반응형 분기가 완료된다.
- 모든 클래스를 외울 필요 없이 필요한 속성은 Tailwind CSS 공식 문서 검색을 통해 확인하여 조합한다.

# 6. 비교 정리

| 구분 | 일반 CSS 미디어 쿼리 | Tailwind CSS 반응형 클래스 |
|---|---|---|
| 작성 위치 | 별도의 `.css` 파일 또는 `<style>` 태그 | HTML 태그 내부의 `class` 속성 |
| 작성 방식 | `@media` 블록 내부에 CSS 선택자와 속성을 직접 기술 | `md:`, `lg:` 등의 화면 접두사를 클래스 앞에 결합 |
| 분기 제어 | 브레이크포인트 수치(px)를 직접 입력 가능 | 정의된 기본 브레이크포인트 시스템을 활용 |
| 장점 | 세밀하고 복잡한 미디어 규칙 작성에 유리 | 코드 전환 속도가 빠르고 클래스 작성이 직관적임 |

# 7. 핵심 정리

## 핵심 코드

~~~html
<!-- 반응형 카드 그리드 컨테이너 -->
<div class="grid grid-cols-1 md:grid-cols-2 gap-4 p-4">
    <div class="h-[200px] hover:bg-slate-100">카드 1</div>
    <div class="h-[200px] hover:bg-slate-100">카드 2</div>
</div>
~~~

- `grid-cols-1 md:grid-cols-2`: 모바일에서는 1열, 태블릿(768px) 이상에서는 2열로 배치한다.
- `gap-4`: 요소 사이 간격을 16px로 둔다.
- `h-[200px]`: 임의 수치 문법으로 높이를 200px로 고정한다.

## 핵심 개념

- 반응형 웹은 단일 웹페이지 코드로 여러 기기 해상도에 유연하게 대응하는 기술이다.
- 순수 CSS에서는 `@media screen and (min-width: ...)` 형태로 브레이크포인트를 분기한다.
- Tailwind CSS의 수치 단위 1은 기본적으로 `4px`를 나타낸다.
- Tailwind CSS는 모바일 우선 원칙을 따르므로 접두사가 없는 기본 클래스가 모바일용 스타일이 된다.

# 8. 느낀 점

반응형 웹을 구성할 때 일반 CSS의 미디어 쿼리로 브레이크포인트를 설정하는 구조적 원리를 먼저 이해하고, 이를 Tailwind CSS에서 접두사 형태로 간결하게 적용하는 흐름을 파악할 수 있었다. HTML 내부에서 `md:grid-cols-2`와 같이 직관적으로 레이아웃 전환을 처리할 수 있어 작업 속도가 크게 향상된다는 점을 느꼈다. 앞으로 제작할 프로젝트의 특성에 맞춰 일반 CSS 파일 방식과 Tailwind 프레임워크 방식을 적절히 선택하여 개발해야겠다.
