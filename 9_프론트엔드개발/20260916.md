# 1. CSS 기본 문법 구조

CSS(Cascading Style Sheets)는 HTML 문서에 정의된 요소들의 시각적인 스타일을 지정하는 스타일시트 언어이다.

## 기본 구조

CSS는 선택자, 속성, 값의 조합으로 작성한다.

~~~css
선택자 {
    속성: 값;
}
~~~

- 선택자(Selector)는 스타일을 적용할 HTML 요소를 선택한다.
- 속성(Property)은 변경할 스타일의 종류를 지정한다.
- 값(Value)은 해당 속성에 적용할 구체적인 값을 지정한다.

예를 들어 `h1` 태그의 글자 색상과 크기를 변경할 수 있다.

~~~css
h1 {
    color: blue;
    font-size: 20px;
}
~~~

- `h1`은 스타일을 적용할 선택자이다.
- `color`는 글자 색상을 지정하는 속성이다.
- `blue`는 글자 색상에 지정하는 값이다.
- `font-size`는 글자 크기를 지정하는 속성이다.
- `20px`은 글자 크기에 지정하는 값이다.

## CSS 주석

CSS 주석은 브라우저가 해석하지 않는 메모이다. 코드의 역할을 설명하거나 특정 스타일을 임시로 비활성화할 때 사용한다.

~~~css
/* 메인 네비게이션 스타일 */
.nav-item {
    color: #333;
}
~~~

- 주석은 `/*`로 시작하고 `*/`로 끝난다.

# 2. CSS 선택자와 스타일 적용

선택자는 CSS 스타일을 적용할 HTML 요소를 지정하는 역할을 한다. 기본 선택자뿐만 아니라 여러 선택자를 조합하여 원하는 요소를 구체적으로 선택할 수 있다.

## 선택자의 역할

~~~css
p {
    color: blue;
}
~~~

- `p` 선택자는 문서 내의 모든 `<p>` 요소를 지정한다.
- 선택한 모든 `<p>` 요소의 글자 색상을 파란색으로 변경한다.
- 선택자를 활용하면 HTML 구조를 변경하지 않고도 특정 요소의 스타일만 바꿀 수 있다.

# 3. CSS 스타일 적용 방식

HTML 문서에 CSS를 적용하는 방법은 인라인, 내부, 외부 스타일 시트의 세 가지 방식이 있다.

## 인라인 스타일

HTML 태그 내부의 `style` 속성에 CSS를 직접 작성하는 방식이다.

~~~html
<h1 style="color: blue; font-size: 20px;">
    인라인 스타일이 적용된 타이틀
</h1>
~~~

- 특정 요소에 빠르게 스타일을 적용할 수 있다.
- HTML 코드와 CSS가 혼합되어 코드의 가독성과 유지보수성이 떨어진다.

## 내부 스타일 시트

HTML 문서의 `<head>` 영역 안에 `<style>` 태그를 선언하고 CSS를 작성하는 방식이다.

~~~html
<head>
    <style>
        h1 {
            color: blue;
            font-size: 20px;
        }

        p {
            color: green;
        }
    </style>
</head>
~~~

- 하나의 HTML 문서 안에서 스타일을 관리할 수 있다.
- 다른 HTML 문서에서 동일한 스타일을 재사용하기 어렵다.

## 외부 스타일 시트

HTML과 CSS를 별도의 파일로 분리하는 방식이다. CSS 파일을 생성한 뒤 HTML의 `<link>` 태그를 이용해 연결한다.

~~~html
<head>
    <link rel="stylesheet" href="style.css">
</head>
~~~

연결할 `style.css` 파일에는 CSS 코드만 작성한다.

~~~css
h1 {
    color: blue;
    font-size: 20px;
}

p {
    color: green;
}
~~~

- HTML 구조와 CSS 디자인을 독립적으로 관리할 수 있다.
- 여러 HTML 파일에서 하나의 CSS 파일을 공유할 수 있어 유지보수성이 높다.

# 4. CSS 스타일 우선순위와 상속

여러 CSS 규칙이 동일한 HTML 요소에 적용될 경우, 우선순위에 따라 최종적으로 반영될 스타일이 결정된다.

## 캐스케이딩

캐스케이딩은 스타일 충돌이 발생했을 때 우선순위에 따라 최종 스타일을 결정하는 원리이다. 가중치가 동일한 규칙이 충돌하면 가장 마지막에 작성된 규칙이 우선 적용된다.

## 명시도

선택자가 얼마나 구체적으로 요소를 지칭하는지 나타내는 기준이다.

~~~text
인라인 스타일 > ID 선택자 > 클래스/가상 클래스 선택자 > 태그/가상 요소 선택자 > 전체 선택자
~~~

동일한 요소에 서로 다른 선택자가 적용되면 명시도가 높은 선택자의 스타일이 우선한다.

~~~css
#unique-item {
    color: purple;
}

.group-item {
    color: orange;
}

p {
    color: gray;
}
~~~

- 동일한 요소에 세 규칙이 충돌하면 ID 선택자(`#unique-item`)의 보라색이 적용된다.

## 인라인 스타일의 우선순위

HTML 태그 내부에 직접 작성된 인라인 스타일은 외부 CSS나 내부 스타일 시트의 선택자보다 더 높은 우선순위를 가진다.

~~~html
<p class="priority-text" style="color: red;">
    최종적으로 무슨 색이 될까요?
</p>
~~~

- 외부 CSS에서 `.priority-text`에 다른 색상을 지정하더라도 인라인 스타일인 빨간색이 적용된다.

## 스타일 상속

상속은 부모 요소에 지정된 스타일 속성이 자식 요소에게 전달되는 동작이다.

- 부모 요소인 `body`에 글꼴을 지정하면 하위 요소인 `p`나 `span`에도 동일한 글꼴이 적용된다.
- 모든 CSS 속성이 상속되는 것은 아니며, 주로 글꼴이나 텍스트 색상 관련 속성이 상속된다.

# 5. CSS 기본 속성

CSS는 다양한 스타일 속성을 제공하여 HTML 요소의 시각적 형태를 제어한다.

## 글꼴 지정

`font-family` 속성은 텍스트에 적용할 서체를 지정한다.

~~~css
p {
    font-family: 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif;
}
~~~

- 브라우저는 왼쪽부터 순서대로 사용자 환경에 설치된 서체를 탐색하여 적용한다.
- 앞선 글꼴이 없을 경우 다음 글꼴을 대체 적용한다.
- 마지막의 `sans-serif`는 고딕 계열의 범용 서체로, 앞의 글꼴이 모두 없을 때 브라우저 기본 서체를 사용하도록 보장한다.

# 6. 핵심 정리

### 핵심 문법

~~~css
선택자 {
    속성: 값;
}
~~~

- 선택자는 스타일 대상 요소를 지정한다.
- 속성은 변경할 스타일 종류를 지정한다.
- 값은 변경할 구체적인 수치나 키워드를 지정한다.

### 스타일 적용 방식 비교

| 방식 | 작성 위치 | 특징 |
|---|---|---|
| 인라인 스타일 | HTML 요소의 `style` 속성 | 특정 요소에만 개별 적용하며 우선순위가 높다. |
| 내부 스타일 시트 | HTML `<head>` 내 `<style>` 태그 | 해당 HTML 문서 내에서만 스타일을 공유한다. |
| 외부 스타일 시트 | 별도의 `.css` 파일 | `<link>`로 연결하며 유지보수성과 재사용성이 높다. |

### 핵심 개념

- 스타일 충돌 시 명시도(인라인 > ID > 클래스 > 태그 > 전체)와 작성 순서에 따라 적용이 결정된다.
- 글자 색상, 폰트 등 일부 스타일은 부모 요소에서 자식 요소로 상속된다.

# 7. 느낀 점

CSS는 단순히 색상이나 글자 크기를 변경하는 것을 넘어 선택자와 우선순위 규칙을 통해 체계적으로 스타일을 제어하는 언어임을 배웠다. 특히 동일한 요소에 여러 스타일이 충돌할 때 명시도와 적용 방식에 따라 최종 형태가 결정된다는 점을 명확히 이해할 수 있었다.
