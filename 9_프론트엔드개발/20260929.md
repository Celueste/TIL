# 1. 함수의 정의와 구성 요소

## 무엇인가?
함수(Function)는 특정 작업을 수행하는 코드들을 하나의 블록으로 묶어 필요할 때마다 재사용할 수 있도록 정의한 코드 단위이다.

## 왜 사용하는가?
동일한 로직의 코드를 반복해서 작성하지 않도록 방지하여 재사용성을 높이고, 유지보수와 코드 관리를 용이하게 만든다.

## 어떻게 사용하는가?
함수를 정의할 때는 `function` 키워드, 함수 이름, 매개변수 목록, 수행할 코드를 담은 바디 블록(`{}`), 그리고 반환값을 전달하는 `return` 문을 사용한다.

~~~javascript
function square(x) {
    return x * x;
}

square(5);
~~~

- `square`: 함수를 호출할 때 사용하는 함수 이름이다.
- `x`: 외부에서 값을 전달받기 위해 선언한 매개변수(Parameter)이다.
- `{ return x * x; }`: 함수 호출 시 실제로 실행되는 함수 바디(Function Body)이다.
- `x * x`: 함수의 실행이 완료된 후 호출한 위치로 전달되는 반환값(Return Value)이다.
- `5`: 함수를 실행할 때 실제로 전달하는 구체적인 값인 인수(Argument)이다.

- 매개변수(Parameter)는 함수를 정의할 때 선언하는 변수이다.
- 인수(Argument)는 함수를 호출할 때 실제로 전달하는 데이터 값이다.

# 2. 함수 호출과 매개변수 제어

## 함수 호출 방식과 제어 흐름
함수를 실행하려면 반드시 함수 이름 뒤에 호출 연산자인 소괄호 `()`를 붙여야 한다.

~~~javascript
function getGreeting(name) {
    console.log("2. 함수 실행 시작");
    const result = `안녕하세요, ${name}님.`;
    console.log("3. 함수 실행 종료");
    return result;
}

console.log("1. 함수 호출 전");
const message = getGreeting("이용교");
console.log("4. 함수 호출 완료:", message);
~~~

- 소괄호 없이 `square`처럼 이름만 작성하면 함수 실행이 아니라 함수 객체 자체를 참조한다.
- `getGreeting("이용교")`를 호출하면 현재 코드의 제어 흐름이 함수 내부로 이동한다.
- 내부 코드가 순차적으로 실행된 후 `return`을 만나면 결과값을 반환하고 호출 위치로 다시 제어 흐름이 복귀한다.

## 기본 매개변수(Default Parameter)
함수 호출 시 인수를 전달하지 않으면 매개변수에 기본적으로 `undefined`가 할당된다. 이를 방지하기 위해 매개변수 기본값을 지정할 수 있다.

~~~javascript
function multiply(a, b = 1) {
    return a * b;
}

multiply(5, 3); // 15
multiply(5);    // 5
~~~

- `b = 1`과 같이 선언하면 두 번째 인수를 전달하지 않았을 때 기본값 `1`이 할당되어 계산된다.

## arguments 객체와 나머지 매개변수(Rest Parameter)

~~~javascript
// arguments 객체: 유사 배열 객체
function showArgs() {
    console.log(arguments);
}

showArgs(10, 20, 30);

// 나머지 매개변수: 실제 배열
function sumAll(...numbers) {
    let total = 0;
    for (let i = 0; i < numbers.length; i++) {
        total += numbers[i];
    }
    return total;
}

sumAll(1, 2, 3, 4, 5); // 15
~~~

- 일반 함수에서 제공하는 `arguments`는 함수로 전달된 모든 인수를 담고 있지만, 실제 배열 메서드를 직접 사용할 수 없는 유사 배열 객체이다.
- 매개변수 앞에 `...`을 붙이는 나머지 매개변수(Rest Parameter)를 사용하면 전달된 인수들을 온전한 자바스크립트 배열로 수집하여 처리할 수 있다.

# 3. 함수 정의 방식과 일급 객체

## 함수 선언문과 함수 표현식
자바스크립트에서 함수를 정의하는 대표적인 방식으로는 함수 선언문과 함수 표현식이 있다.

~~~javascript
// 1. 함수 선언문: 호이스팅에 의해 선언 위치보다 위에서 호출 가능
console.log(getArea(5, 10)); // 50

function getArea(width, height) {
    return width * height;
}

// 2. 함수 표현식: 변수에 할당된 이후에만 호출 가능
const getVolume = function(width, height, depth) {
    return width * height * depth;
};

getVolume(5, 10, 2);
~~~

- 함수 선언문은 평가 단계에서 함수 전체가 등록되므로 코드 상단에서 호출해도 정상 작동한다.
- 함수 표현식은 익명 함수를 변수에 할당하는 방식이다. `const`로 선언된 함수 표현식은 초기화되기 전에 접근하면 `ReferenceError`가 발생한다.

## 일급 객체(First-Class Object)와 콜백 함수
자바스크립트의 함수는 단순한 코드 블록이 아니라 일반 값과 동일하게 취급되는 일급 객체이다.

- 변수에 함수를 값으로 저장할 수 있다.
- 다른 함수의 인수로 함수를 전달할 수 있다.
- 다른 함수의 실행 결과로 함수를 반환할 수 있다.

~~~javascript
// 1. 함수를 인수로 전달 (콜백 함수)
function execute(func) {
    func();
}

function sayHello() {
    console.log("안녕하세요");
}

execute(sayHello);

// 2. 함수를 반환값으로 사용
function createFunction() {
    return function() {
        console.log("반환된 함수");
    };
}

const myFunc = createFunction();
myFunc();
~~~

- `execute(sayHello)`처럼 다른 함수의 매개변수로 전달되어 특정 시점에 실행되는 함수를 콜백 함수(Callback Function)라고 부른다.

# 4. 화살표 함수와 this

## 화살표 함수(Arrow Function) 문법
`function` 키워드 대신 `=>` 화살표 기호를 사용하여 간결하게 함수를 선언하는 문법이다.

~~~javascript
// 기본 형태
const add = (a, b) => {
    return a + b;
};

// 매개변수가 1개인 경우 소괄호 생략 가능
const square = x => {
    return x * x;
};

// 단일 표현식을 즉시 반환하는 경우 중괄호와 return 생략 가능
const multiply = (a, b) => a * b;
const double = x => x * 2;

// 매개변수가 없는 경우 소괄호 필수
const sayHello = () => "안녕하세요";

// 가변 인수를 받을 때는 나머지 매개변수 사용
const showArgs = (...args) => {
    console.log(args);
};
showArgs(1, 2, 3); // [1, 2, 3]
~~~

- 본문이 한 줄의 식인 경우 `{}`와 `return`을 생략하고 암시적으로 반환할 수 있다.
- 화살표 함수 내부에서는 자체적인 `arguments` 객체를 사용할 수 없으므로 `...args` 나머지 매개변수를 사용해야 한다.
- `new` 키워드를 사용하는 생성자 함수나 제너레이터(`yield`)로 사용할 수 없다.

## 화살표 함수의 this 동작 원리

~~~javascript
const user = {
    name: "이용교",
    greet: function() {
        const innerArrow = () => {
            console.log(this.name);
        };
        innerArrow();
    }
};

user.greet(); // "이용교"
~~~

- 일반 함수는 함수가 호출되는 방식에 따라 `this`가 동적으로 결정된다.
- 화살표 함수는 자신만의 `this`를 생성하지 않으며, 함수가 선언된 외부 상위 스코프의 `this`를 그대로 참조한다(렉시컬 this).
- 따라서 콜백 함수 내부에서 외부 객체의 `this` 맥락을 그대로 유지해야 할 때 매우 유용하다.

# 5. 자바스크립트 엔진의 코드 실행 원리

자바스크립트 엔진은 코드를 즉시 한 줄씩 실행하지 않고, 내부적으로 명확한 2단계를 거쳐 처리한다.

## 평가 단계와 실행 단계
- **평가 단계**: 코드를 실행하기 전 전체 소스코드를 훑으며 변수와 함수 선언을 메모리에 미리 등록하는 준비 단계이다. 함수 선언문이 호이스팅되는 원인이 이 단계에 있다.
- **실행 단계**: 평가 단계가 완료된 후, 선언문을 제외한 실제 코드를 위에서부터 아래로 한 줄씩 실행하고 변수에 값을 할당한다.

## 호출 스택(Call Stack)과 LIFO
자바스크립트 엔진은 함수 실행 순서를 관리하기 위해 호출 스택 자료구조를 사용한다. 호출 스택은 나중에 들어온 작업이 먼저 나가는 후입선출(LIFO, Last In First Out) 방식으로 동작한다.

~~~javascript
function first() {
    console.log("first 시작");
    second();
    console.log("first 종료");
}

function second() {
    console.log("second 실행");
}

first();
~~~

- 함수가 호출되면 호출 스택의 맨 위에 쌓인다(Push).
- 함수의 실행이 종료되면 호출 스택의 맨 위에서 제거된다(Pop).
- 나중에 호출된 `second` 함수가 먼저 종료되어 스택에서 빠져나간 후, `first` 함수의 나머지 코드가 실행된다.

# 6. 클로저와 정보 은닉

## 클로저(Closure)의 정의와 동작
클로저는 내부 함수가 이미 실행이 종료되어 소멸된 외부 함수의 변수(환경)를 계속해서 기억하고 접근할 수 있는 기능이다.

~~~javascript
function createStorage() {
    let value = "기본 데이터";

    return {
        getData: function() {
            return value;
        },
        setData: function(newValue) {
            value = newValue;
        }
    };
}

const storage = createStorage();
console.log(storage.getData()); // "기본 데이터"
storage.setData("수정된 데이터");
console.log(storage.getData()); // "수정된 데이터"
~~~

- `createStorage()`의 실행이 끝난 후에도 반환된 객체의 메서드(`getData`, `setData`)가 내부 변수 `value`를 계속 참조하고 있으므로 메모리에서 사라지지 않는다.

## 정보 은닉(Private Variable)
클로저를 활용하면 변수에 대한 외부의 직접적인 접근을 차단하고 정의된 메서드를 통해서만 조작하도록 제한할 수 있다.

~~~javascript
function createStorage() {
    let value = "비밀 데이터";

    return {
        getData: () => value,
        setData: newValue => value = newValue
    };
}

const storage = createStorage();
storage.getData();
// console.log(value); // ReferenceError 발생
~~~

- `value`는 함수의 지역 변수이므로 외부에서 직접 읽거나 수정할 수 없다.
- 허용된 인터페이스(`getData`, `setData`)를 통해서만 안전하게 데이터를 다룰 수 있도록 캡슐화가 구현된다.

# 7. call, apply, bind를 활용한 this 바인딩

일반적으로 함수의 `this`는 호출 시점에 결정되지만, `Function.prototype`의 메서드를 사용하면 개발자가 명시적으로 `this` 대상을 지정할 수 있다.

## call()과 apply()
함수를 즉시 호출하면서 첫 번째 인수로 전달한 객체를 함수의 `this`로 지정한다.

~~~javascript
function introduce(greeting, symbol) {
    console.log(`${greeting}${symbol} 저는 ${this.name}입니다.`);
}

const person = {
    name: "이용교"
};

// 1. call: 매개변수를 쉼표로 구분하여 개별 전달
introduce.call(person, "안녕하세요", "!");

// 2. apply: 매개변수를 단일 배열로 묶어서 전달
introduce.apply(person, ["반갑습니다", "."]);
~~~

- `call()`은 두 번째 인수부터 쉼표로 나열하여 전달한다.
- `apply()`는 두 번째 인수로 전달할 매개변수들을 배열 형태로 전달한다.
- 두 메서드 모두 호출 즉시 대상 함수를 실행한다.

## bind()
`bind()`는 함수를 즉시 호출하지 않고, 지정한 객체가 `this`로 고정된 새로운 함수를 생성하여 반환한다.

~~~javascript
function introduce(greeting, symbol) {
    console.log(`${greeting}${symbol} 저는 ${this.name}입니다.`);
}

const person = {
    name: "이용교"
};

// this가 바인딩된 새로운 함수 생성
const newIntroduce = introduce.bind(person);
newIntroduce("안녕하세요", "!");

// 일부 인수를 미리 고정하여 부분 적용 함수 생성
const fixedGreeting = introduce.bind(person, "안녕하십니까");
fixedGreeting("?");
~~~

- 반환된 새로운 함수는 원하는 시점에 별도로 호출하여 실행할 수 있다.
- 생성 시점에 특정 인수를 미리 바인딩해 두고 나중에 나머지 인수만 전달하여 실행할 수도 있다.

# 8. 비교 정리

## 함수 정의 방식 비교

| 구분 | 함수 선언문 | 함수 표현식 | 화살표 함수 |
|---|---|---|---|
| 정의 문법 | `function func() {}` | `const func = function() {}` | `const func = () => {}` |
| 선언 전 호출 | 가능 (호이스팅 발생) | 불가능 (`ReferenceError`) | 불가능 (`ReferenceError`) |
| 자체 this 존재 | 존재 (호출 방식에 따라 결정) | 존재 (호출 방식에 따라 결정) | 없음 (상위 스코프 참조) |
| 생성자 활용 | 가능 (`new func()`) | 가능 (`new func()`) | 불가능 |

## 명시적 this 바인딩 메서드 비교

| 메서드 | this 지정 | 함수 실행 시점 | 인수 전달 형태 |
|---|---|---|---|
| `call()` | 가능 | 즉시 실행 | 개별 인수로 전달 (`arg1, arg2`) |
| `apply()` | 가능 | 즉시 실행 | 배열로 묶어서 전달 (`[arg1, arg2]`) |
| `bind()` | 가능 | 즉시 실행 안 함 (새 함수 반환) | 인수 사전 바인딩 및 나중에 전달 가능 |

# 9. 전체 흐름 정리

~~~text
소스코드 로드
    │
    ▼
[평가 단계]
함수 선언문 및 변수 선언 메모리 등록 (호이스팅)
    │
    ▼
[실행 단계]
순차적으로 코드 실행 및 변수 값 할당
    │
    ▼
[함수 호출: first()]
호출 스택에 first() Push
    │
    ▼
[내부 함수 호출: second()]
호출 스택에 second() Push
    │
    ▼
[second() 실행 종료]
호출 스택에서 second() Pop
    │
    ▼
[first() 실행 재개 및 종료]
호출 스택에서 first() Pop
~~~

# 10. 핵심 정리

### 핵심 코드

~~~javascript
// 화살표 함수와 상위 this 유지
const counter = {
    count: 0,
    start: function() {
        setInterval(() => {
            this.count++;
        }, 1000);
    }
};

// 클로저를 활용한 변수 은닉
function makeCounter() {
    let count = 0;
    return () => ++count;
}
~~~

- 화살표 함수를 사용하면 별도의 바인딩 없이도 외부 메서드의 `this` 컨텍스트를 유지할 수 있다.
- 클로저 구조를 통해 특정 상태 변수를 외부에 노출하지 않고 안전하게 관리할 수 있다.

### 핵심 개념
- 자바스크립트의 함수는 값으로 취급되는 일급 객체이므로 변수 저장, 매개변수 전달, 반환값 처리가 모두 가능하다.
- 함수 선언문은 호이스팅되어 위치에 구애받지 않으나 함수 표현식과 화살표 함수는 할당 이후에만 실행할 수 있다.
- 호출 스택은 LIFO 방식으로 동작하며, 내부 함수가 소멸된 외부 함수의 변수를 유지하는 메커니즘을 클로저라고 한다.
- `call`과 `apply`는 즉시 실행을 동반하고 `bind`는 `this`가 고정된 새 함수를 반환한다.

# 11. 느낀 점

이번 학습을 통해 함수의 기본 사용법뿐만 아니라 자바스크립트 엔진이 코드를 실행하는 내부 원리를 체계적으로 정리할 수 있었다. 함수 선언문과 표현식의 호이스팅 차이, 호출 스택의 후입선출 흐름, 그리고 외부 변수를 계속 유지하는 클로저의 동작 방식을 명확히 이해했다. 특히 화살표 함수와 `call`, `apply`, `bind`를 통해 까다롭게 느껴졌던 `this` 바인딩을 상황에 맞게 제어할 수 있는 방법을 알게 되어 큰 도움이 되었다. 앞으로 코드를 작성할 때 함수의 실행 컨텍스트와 데이터 보존 방식을 고려하여 구조를 설계해야겠다.
