## 1. 학습률과 수렴

머신러닝 최적화 과정에서는 모델의 예측 오차(손실)를 줄이기 위해 가중치(Weight)를 점진적으로 갱신하며 최적의 값을 찾아간다. 이때 한 번의 갱신에서 가중치를 얼만큼 이동시킬지 결정하는 하이퍼파라미터가 학습률(Learning Rate)이다.

- 학습률은 경사하강법 등에서 손실 함수의 최저점을 찾아갈 때 한 걸음의 보폭에 비유할 수 있다.
- 보폭의 크기에 따라 학습의 성공 여부와 도달 속도가 달라진다.

### 1.1 오버슈팅 (Overshooting)

- 학습률이 지나치게 클 때 발생한다.
- 보폭이 너무 커서 최저점을 지나쳐 반대편 경사면으로 튕겨 나간다.
- 오차가 줄어들지 않고 오히려 발산하거나 학습이 극도로 불안정해진다.

### 1.2 언더슈팅 (Undershooting)

- 학습률이 지나치게 작을 때 발생한다.
- 최저점으로 이동하는 변화량이 너무 적어 최적점에 도달하는 데 긴 시간이 소요된다.
- 정해진 학습 횟수 내에 충분한 최적화에 도달하지 못할 수 있다.

### 1.3 안정적 수렴 (Convergence)

- 적절한 학습률을 설정했을 때 나타난다.
- 반복 학습을 거치면서 손실 값이 점진적으로 감소하고 최적의 가중치 값에 안정적으로 도달한다.

## 2. Train, Validation, Test 데이터 분할

머신러닝 모델을 평가할 때 보유한 전체 데이터를 학습에 모두 사용하면 모델이 학습 데이터에만 과도하게 맞춰지는 과적합(Overfitting)이 발생하여 일반화 성능을 정확히 측정할 수 없다. 따라서 데이터를 목적에 따라 세 가지 세트로 분할하여 사용한다.

### 2.1 Train Set (훈련 세트)

- 모델이 데이터의 패턴을 파악하고 가중치를 실제로 학습하는 데 사용하는 데이터이다.
- 비유: 개념 학습과 문제 풀이를 연습하는 수학 익힘책에 해당한다.
- 일반적인 비율: 전체 데이터의 약 60% 내외를 할당한다.

### 2.2 Validation Set (검증 세트)

- 학습 중간 과정에서 모델의 일반화 성능을 점검하고, 과적합 여부를 모니터링하기 위한 데이터이다.
- 학습률, 규제 강도 등 사람이 직접 설정하는 하이퍼파라미터를 튜닝할 때 기준으로 활용한다.
- 비유: 본 시험을 치르기 전에 실력을 점검하고 전략을 수정하는 모의고사에 해당한다.
- 일반적인 비율: 전체 데이터의 약 20% 내외를 할당한다.

### 2.3 Test Set (테스트 세트)

- 모든 모델 튜닝과 학습이 완료된 후, 최종 모델이 미지의 실전 데이터에서 어느 정도의 성능을 내는지 최종 검증하는 데이터이다.
- 모델 학습 및 튜닝 과정에 전혀 관여하지 않아야 객관적인 평가가 가능하다.
- 비유: 최종 성적을 결정짓는 실제 수능 시험에 해당한다.
- 일반적인 비율: 전체 데이터의 약 20% 내외를 할당한다.

## 3. VIF와 다중공선성

### 3.1 다중공선성 (Multicollinearity)

다중공선성은 회귀 분석에서 독립 변수(Feature)들 사이에 강한 선형 상관관계가 존재하는 상태를 의미한다.

- 동일하거나 유사한 정보가 중복되어 모델에 입력되면 발생한다.
  - 예시: 주택 가격 예측 모델에 `집의 평수`, `방의 총면적`, `전체 평방미터`를 동시에 포함하는 경우
- 다중공선성이 높으면 회귀 계수의 추정치가 왜곡되어 변수의 개별 영향력을 해석하기 어려워지고 모델의 신뢰도가 하락한다.

### 3.2 VIF (Variance Inflation Factor, 분산 팽창 계수)

VIF는 특정 독립 변수가 다른 독립 변수들에 의해 얼마나 설명되는지를 측정하여 다중공선성의 위험도를 수치화한 지표이다.

- 값이 클수록 다른 변수들과의 선형 종속성이 높음을 의미한다.
- 일반적인 기준:
  - `VIF = 1`: 다중공선성이 없음
  - `1 < VIF < 10`: 어느 정도의 상관관계가 존재하나 수용 가능한 수준
  - `VIF >= 10`: 심각한 다중공선성 의심 (상황에 따라 5 이상을 기준으로 삼기도 함)

### 3.3 다중공선성 해결 방안

- 상관관계가 지나치게 높은 변수 중 중요도가 낮은 변수를 제거한다.
- 비슷한 정보를 가진 변수들을 하나의 복합 변수로 결합하거나 차원을 축소한다.
- 계수의 크기를 제한하는 릿지(Ridge), 라쏘(Lasso) 등 규제(Regularization) 기반 회귀 모델을 적용한다.

## 4. 상용로그와 자연로그

로그(Logarithm)는 지수 함수의 역함수로, 매우 큰 값의 범위를 압축하여 데이터의 스케일을 줄이고 왜도(치우침)를 보정하는 변환 작업에 자주 활용된다.

### 4.1 상용로그 (Common Logarithm)

- 밑(Base)을 10으로 사용하는 로그이다.
- 수식 표기: $\log_{10}x$
- 자릿수 기반의 직관적인 연산이 가능하여 일상적인 지표 측정에 주로 사용된다.
- 주요 활용 분야: 지진의 규모(리히터 규모), 음향 세기(데시벨, dB), 산성도(pH) 측정 등

### 4.2 자연로그 (Natural Logarithm)

- 밑(Base)을 무리수이자 자연상수인 $e$($e \approx 2.71828$)로 사용하는 로그이다.
- 수식 표기: $\ln x$ 또는 수학·데이터 과학 라이브러리에서 $\log x$
- 미분 시 $\frac{d}{dx}\ln x = \frac{1}{x}$로 형태가 단순해져 연속 복리, 변화율 계산 및 최적화 수식 전개에 용이하다.
- 주요 활용 분야: 미적분 연산, 머신러닝 비용 함수 설계, 데이터 왜도 교정, 연속 성장률 분석 등

### 4.3 머신러닝에서의 로그 변환 목적

- 주택 가격, 소득 데이터처럼 오른쪽으로 긴 꼬리를 가진(Right-skewed) 분포를 정규분포에 가깝게 변환한다.
- 이상치(Outlier)의 극단적인 영향력을 완화하여 모델이 가중치를 안정적으로 학습하도록 돕는다.

## 5. 비교 정리

### 5.1 학습률 설정에 따른 결과 비교

| 구분 | 학습률 크기 | 발생 현상 | 모델 학습 영향 |
|---|---|---|---|
| **오버슈팅** | 지나치게 큼 | 최저점을 지나쳐 건너뜀 | 오차가 급증하거나 손실 함수가 발산함 |
| **언더슈팅** | 지나치게 작음 | 가중치 변화량이 미미함 | 학습 속도가 극도로 느리고 최적점에 미달함 |
| **안정적 수렴** | 적절함 | 점진적으로 오차 최소화 | 최적 가중치로 안정적으로 수렴함 |

### 5.2 데이터 분할 세트 비교

| 데이터 세트 | 역할 | 조정 대상 | 시험 비유 | 권장 비율 |
|---|---|---|---|---|
| **Train Set** | 모델 가중치 학습 | 파라미터($w, b$) 갱신 | 수학 익힘책 | 약 60% |
| **Validation Set** | 중간 점검 및 과적합 방지 | 하이퍼파라미터 튜닝 | 모의고사 | 약 20% |
| **Test Set** | 최종 일반화 성능 검증 | 수정 불가 (평가 전용) | 실제 수능 | 약 20% |

### 5.3 상용로그 vs 자연로그 비교

| 구분 | 상용로그 | 자연로그 |
|---|---|---|
| **밑 (Base)** | 10 | 자연상수 $e$ ($e \approx 2.718$) |
| **수식 표기** | $\log_{10}x$ | $\ln x$ (또는 $\log x$) |
| **수학적 특징** | 자릿수 계산이 직관적임 | 미분 연산이 간단하여 최적화에 유리함 |
| **주요 활용** | 데시벨(dB), 지진 규모, 산성도 | 머신러닝 손실 함수, 왜도 교정, 성장률 분석 |

## 6. 전체 흐름 정리

머신러닝 데이터를 구성하고 모델을 안정적으로 학습시키는 전체 파이프라인 흐름은 다음과 같다.

~~~text
[1. 데이터 수집 및 탐색]
독립 변수와 종속 변수 확인 및 데이터 분포 점검
    │
    ▼
[2. 다중공선성 점검 및 데이터 변환]
- VIF 지표를 계산하여 중복 변수 제거 또는 결합
- 치우친 분포를 가진 변수에 자연로그 변환 적용
    │
    ▼
[3. 데이터 세트 분할]
Train (60%) / Validation (20%) / Test (20%) 세트로 분리
    │
    ▼
[4. 모델 학습 및 하이퍼파라미터 튜닝]
- Train Set으로 가중치 학습
- 적절한 학습률을 적용하여 오버슈팅 및 언더슈팅 방지
- Validation Set을 통해 검증하며 최적 설정 도출
    │
    ▼
[5. 최종 일반화 평가]
완성된 모델을 Test Set에 입력하여 최종 성능 측정
~~~

## 7. 핵심 정리

### 핵심 개념

- **학습률(Learning Rate):** 가중치를 갱신하는 보폭이며, 너무 크면 오버슈팅이 발생하고 너무 작으면 언더슈팅이 발생한다.
- **데이터 3단계 분할:** Train(가중치 학습), Validation(하이퍼파라미터 튜닝 및 과적합 모니터링), Test(최종 성능 측정)로 분리하여 평가의 객관성을 확보한다.
- **VIF(분산 팽창 계수):** 변수 간 다중공선성을 진단하는 지표이며, 일반적으로 수치가 10 이상이면 변수 정제나 차원 축소를 검토한다.
- **로그 변환:** 데이터 과학에서는 자연상수 $e$를 밑으로 하는 자연로그($\ln x$)를 주로 사용하여 치우친 데이터 분포를 정규분포 형태로 완화한다.

## 8. 느낀 점

머신러닝 학습이 단순히 모델 함수를 실행하는 작업에 그치지 않고, 가중치 이동 보폭인 학습률을 섬세하게 조율하여 안정적인 수렴을 유도하는 과정임을 깊이 이해하게 되었다. Train, Validation, Test 세트로 역할을 분리하지 않으면 과적합 여부를 판단하기 어렵고 모델의 실제 성능을 왜곡할 수 있다는 점을 확인했다. 또한 독립 변수 간의 다중공선성을 VIF 지표로 사전에 진단하고, 데이터 분포의 왜곡을 로그 변환으로 완화하는 등 모델링 이전의 데이터 구조 최적화가 필수적이라는 점을 배웠다. 앞으로 데이터 분석 프로젝트를 수행할 때는 모델 학습에 앞서 변수 간 상관성을 점검하고, 데이터 분할 및 학습률 설정을 체계적으로 구성해야겠다고 느꼈다.
