## 1. 머신러닝의 기본 개념

머신러닝(Machine Learning)은 사람이 모든 규칙을 직접 프로그래밍하는 대신, 컴퓨터가 대량의 데이터에서 패턴과 규칙을 찾아 스스로 학습하도록 만드는 인공지능의 한 분야이다.

### 1.1 전통적 프로그래밍과 머신러닝의 차이

- 전통적 프로그래밍: 데이터와 사람이 만든 규칙(Rule)을 입력하여 결과(해답)를 출력한다.
- 머신러닝: 데이터와 정답을 함께 입력하여 컴퓨터가 스스로 규칙을 찾아 학습된 모델(Model)을 생성한다.

### 1.2 핵심 용어

- **Feature (특성, $X$):** 예측에 사용하는 입력 변수 또는 데이터의 속성이다.
- **Target / Label (정답, $y$):** 모델이 최종적으로 맞춰야 하는 정답 데이터이다.
- **Model (모델):** 데이터 학습을 거쳐 만들어진 수학적 함수 또는 규칙의 집합이다.
- **Prediction (예측값, $\hat{y}$):** 모델이 새로운 입력을 받았을 때 계산하여 도출한 결과이다.
- **Error (오차):** 실제 정답값과 모델의 예측값 사이의 차이이다.

## 2. 머신러닝의 3가지 학습 방법

머신러닝은 데이터에 정답(Label)이 포함되어 있는지, 혹은 상호작용을 통해 피드백을 받는지에 따라 세 가지로 분류된다.

### 2.1 지도학습 (Supervised Learning)

문제(Feature)와 정답(Label)이 함께 주어지는 데이터셋을 학습하는 방식이다.

- **분류(Classification):** 예측해야 하는 결괏값이 범주형 데이터(카테고리)인 경우이다. (예: 스팸 메일 여부, 고객 이탈 여부)
- **회귀(Regression):** 예측해야 하는 결괏값이 연속적인 숫자인 경우이다. (예: 주택 가격 예측, 분기별 매출 예측)

### 2.2 비지도학습 (Unsupervised Learning)

정답(Label)이 주어지지 않은 상태에서 데이터 내부의 숨겨진 구조, 규칙, 유사성을 찾는 학습 방식이다.

- **군집화(Clustering):** 데이터 간의 거리나 유사도를 계산하여 비슷한 특성을 가진 그룹으로 묶는 방법이다. (예: 고객 세그먼트 분석)

### 2.3 강화학습 (Reinforcement Learning)

에이전트가 주어진 환경 안에서 행동을 취하고, 그 결과에 따른 보상(Reward)을 최대화하도록 시행착오를 통해 최적의 행동 전략을 학습하는 방식이다. (예: 게임 AI, 자율주행 제어)

## 4. 데이터 전처리

수집된 원시 데이터(Raw Data)는 결측치, 형식 오류, 불필요한 기호 등을 포함하므로 모델이 학습하기에 적합한 수치형 형태로 정제해야 한다.

### 4.1 데이터 구조 및 문자열 변환

~~~python
df.info()
df.describe()

df['price'] = df['price'].str.replace('$', '')
df['price'] = df['price'].str.replace(',', '')
df['price'] = pd.to_numeric(df['price'])
~~~

- `df.info()`는 데이터프레임의 행/열 개수, 결측치 수, 각 컬럼의 자료형을 출력한다.
- `df.describe()`는 수치형 컬럼들의 평균, 표준편차, 사분위수 등 요약 통계량을 제공한다.
- `str.replace()`를 통해 통화 기호나 쉼표를 제거하고, `pd.to_numeric()`으로 문자열을 계산 가능한 실수형으로 변환한다.

### 4.2 결측치(Missing Value) 처리

데이터가 누락된 경우 모델 연산에서 오류가 발생하므로 확인 후 적절한 대푯값으로 채우거나 삭제한다.

~~~python
df.isnull().sum()

mean_age = df['age'].mean()
df.loc[:, 'age'] = df['age'].fillna(mean_age)

mode_embarked = df['embark_town'].mode()[0]
df.loc[:, 'embark_town'] = df['embark_town'].fillna(mode_embarked)
~~~

- `df.isnull().sum()`은 컬럼별 결측치 총개수를 계산한다.
- 연속형 변수(예: 나이)의 결측치는 컬럼의 평균값(`mean()`)으로 대체한다.
- 범주형 변수(예: 탑승 도시)의 결측치는 가장 빈도가 높은 최빈값(`mode()[0]`)으로 대체한다.

### 4.3 이상치 및 중복 데이터 처리

~~~python
df = df[df['fare'] < 300]

duplicate_count = df.duplicated().sum()
df = df.drop_duplicates().reset_index(drop=True)
~~~

- 불필요하게 극단적인 값은 조건부 필터링(`df['fare'] < 300`)을 적용하여 제거한다.
- `duplicated().sum()`으로 완전히 동일한 중복 행의 개수를 파악한다.
- `drop_duplicates()`로 중복 행을 제거한 후, `reset_index(drop=True)`를 통해 기존 인덱스를 재정렬한다.

## 6. 선형 회귀와 평가 지표

### 6.1 선형 회귀 (Linear Regression)

선형 회귀는 입력값($x$)과 출력값($y$) 사이의 관계를 가장 잘 설명하는 최적의 직선 방정식을 찾는 지도학습 회귀 알고리즘이다.

$$\hat{y} = wx + b$$

- $\hat{y}$: 모델이 예측한 값이다.
- $x$: 입력 특성(Feature) 값이다.
- $w$ (Weight, 가중치): 직선의 기울기이며, $x$가 1단위 증가할 때 $y$가 변화하는 크기를 의미한다.
- $b$ (Bias, 편향): $x$가 0일 때의 $y$ 절편이며, 직선의 기본 높이를 결정한다.
- 모델 학습의 목적은 전체 데이터의 실제값과 예측값의 오차를 최소화하는 $w$와 $b$를 찾는 것이다.

### 6.2 회귀 모델 평가 지표: MSE와 MAE

모델의 예측이 실제값과 얼마나 차이 나는지 측정하는 지표이다.

- **MSE (Mean Squared Error, 평균 제곱 오차):**
  오차를 제곱한 후 평균을 계산하는 방식이다. 큰 오차에 대해 가중치를 크게 부여하므로, 이상치나 큰 오차에 민감하게 반응해야 할 때 주로 사용한다.
  
  $$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

- **MAE (Mean Absolute Error, 평균 절대 오차):**
  오차의 절댓값을 취한 후 평균을 계산하는 방식이다. 결과가 실제 데이터와 동일한 단위를 유지하므로 직관적인 해석이 용이하다.
  
  $$\text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

## 7. 선형 회귀 실습

주택 면적 데이터를 바탕으로 주택 가격을 예측하는 Scikit-learn 기반 실습 코드이다.

### 7.1 데이터 로드 및 전처리

~~~python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('usa_housing.csv')

df = df[
    (df['YearBuilt'] > 2015) &
    (df['CrimeRate'] < 40)
]
~~~

- `read_csv()`를 통해 원본 데이터를 데이터프레임으로 불러온다.
- 2015년 이후 완공되고 범죄율이 40 미만인 행만 조건식으로 필터링한다.

### 7.2 Feature와 Target 분리

~~~python
X = df[['SquareFeet']]
y = df['Price']
~~~

- `X`: 독립변수(Feature)로 주택 면적을 설정한다. Scikit-learn 모델은 2차원 형태(행과 열 구조)의 입력을 요구하므로 대괄호를 두 번 감싸 전달한다.
- `y`: 종속변수(Target)로 실제 주택 가격을 1차원 Series 형태로 분리한다.

### 7.3 모델 생성, 학습 및 평가

~~~python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, mean_absolute_error

model = LinearRegression()
model.fit(X, y)

y_pred = model.predict(X)

mse = mean_squared_error(y, y_pred)
mae = mean_absolute_error(y, y_pred)

print(f"컴퓨터가 찾은 기울기(w): {model.coef_}")
print(f"컴퓨터가 찾은 기본값(b): {model.intercept_:.2f}")
print(f"오차 제곱 평균(MSE): {mse:.2f}")
print(f"오차 절대값 평균(MAE): {mae:.2f}")
~~~

- `LinearRegression()`으로 선형 회귀 모델 객체를 생성한다.
- `model.fit(X, y)`를 실행하여 오차를 최소화하는 최적의 $w$와 $b$를 학습한다.
- `model.predict(X)`로 면적 데이터에 대한 모델의 가격 예측값을 생성한다.
- `model.coef_`는 학습된 기울기($w$)를 반환하고, `model.intercept_`는 절편($b$)을 반환한다.
- `mean_squared_error`와 `mean_absolute_error`로 전체 오차 수준을 확인한다.

### 7.4 회귀 직선 시각화

~~~python
plt.figure(figsize=(8, 5))

plt.scatter(X, y, alpha=0.5, label='Actual Data')
plt.plot(X, y_pred, color='red', linewidth=3, label='Regression Line')

plt.title('Linear Regression Prediction')
plt.xlabel('Square Feet (Area)')
plt.ylabel('Price ($)')
plt.legend()
plt.grid(True)
plt.show()
~~~

- `plt.scatter`를 통해 실제 주택 데이터 점들을 산점도로 배치한다.
- `plt.plot`을 이용해 모델이 도출한 최적의 회귀 직선을 겹쳐서 표시하여 학습 결과를 검증한다.

## 8. 비교 정리

### 8.1 전통적 프로그래밍 vs 머신러닝

| 구분 | 전통적 프로그래밍 | 머신러닝 |
|---|---|---|
| 규칙 정의 | 개발자가 직접 로직 작성 | 알고리즘이 데이터로부터 자동 학습 |
| 입력값 | 데이터 + 명시적 규칙 | 데이터 + 실제 정답 |
| 산출물 | 연산 결과 | 데이터를 예측할 수 있는 학습된 모델 |
| 적합한 작업 | 정형화된 업무 (급여 계산, 자판기) | 예외가 많고 복잡한 패턴 (추천, 이상 감지) |

### 8.2 회귀 모델 평가 지표 비교

| 구분 | MSE (Mean Squared Error) | MAE (Mean Absolute Error) |
|---|---|---|
| 계산 방식 | 오차를 제곱한 값의 평균 | 오차의 절댓값의 평균 |
| 단위 | 실제 데이터 단위의 제곱 | 실제 데이터 단위와 동일 |
| 이상치 민감도 | 매우 민감함 (오차가 클수록 가중 반영) | 덜 민감함 (직관적 오차 반영) |
| 활용 목적 | 큰 오차 발생을 엄격하게 제한할 때 | 직관적인 오차 해석이 필요할 때 |

## 9. 전체 흐름 정리

머신러닝 프로젝트의 표준 파이프라인 흐름은 다음과 같다.

~~~text
[1. 문제 정의]
예측 대상 설정 및 문제 유형 분류 (지도학습 - 회귀/분류 등)
    │
    ▼
[2. 데이터 수집 및 EDA]
기초 통계량(describe)과 구조(info) 확인 및 시각화
    │
    ▼
[3. 데이터 전처리]
결측치 대치, 이상치 필터링, 자료형 변환, 중복 제거
    │
    ▼
[4. 데이터 분할]
독립변수(Feature, X)와 종속변수(Target, y) 분리
    │
    ▼
[5. 모델 생성 및 학습]
알고리즘 객체 생성 및 fit(X, y)을 통한 최적 파라미터(w, b) 도출
    │
    ▼
[6. 예측 및 성능 평가]
predict(X) 수행 후 MSE, MAE 등의 지표로 모델의 오차 측정
~~~

## 10. 핵심 정리

### 핵심 코드

~~~python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)
y_pred = model.predict(X)
~~~

- `model.fit(X, y)`를 통해 특성과 정답 데이터를 기반으로 최적의 선형 방정식을 학습한다.
- `model.predict(X)`를 호출하여 입력 데이터에 대한 연속적인 예측값을 반환한다.

### 핵심 개념

- 머신러닝은 데이터를 기반으로 패턴을 찾아내며, 지도학습은 정답(Label)의 존재 여부에 따라 분류와 회귀로 나뉜다.
- 모델 학습 이전에 이상치 제거, 결측치 대체, 타입 변환 등의 전처리가 올바르게 수행되어야 신뢰할 수 있는 결과를 얻을 수 있다.
- 선형 회귀는 입력값과 출력값 사이의 오차를 최소화하는 직선($\hat{y} = wx + b$)을 찾는 모델이며, 성능 평가는 MSE와 MAE를 활용한다.

## 11. 느낀 점

머신러닝이 단순히 복잡한 수학 수식을 코드로 구현하는 것에 그치지 않고, 데이터 속에서 컴퓨터가 스스로 최적의 규칙을 찾아내도록 설계하는 과정임을 명확히 이해했다. 지도학습과 비지도학습의 차이를 정답의 유무로 구분하고, 예측하려는 대상이 범주형인지 연속형 숫자인지에 따라 분류와 회귀 문제를 올바르게 정의하는 접근법을 배웠다. 특히 모델을 학습시키기 전 데이터의 구조를 파악하는 EDA와 결측치 및 이상치를 처리하는 전처리 단계가 모델의 최종 성능에 결정적인 영향을 미친다는 점을 체감했다. 선형 회귀 실습을 통해 Scikit-learn 라이브러리로 데이터를 분리하고, 학습(fit)과 예측(predict), 그리고 오차 지표(MSE, MAE) 계산까지 이어지는 전체 워크플로우를 직접 실행해 봄으로써 머신러닝 개발의 기초 뼈대를 탄탄히 다질 수 있었다.
