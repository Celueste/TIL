## 1. 단어의 수치화: 원핫 인코딩과 워드 임베딩

컴퓨터는 자연어 텍스트를 직접 연산할 수 없으므로 텍스트를 수치 벡터로 변환하는 과정이 필요하다.

### 1.1 원핫 인코딩 (One-Hot Encoding)

단어 사전(Vocabulary)의 크기만큼 벡터 차원을 설정하고, 표현하고자 하는 단어의 인덱스 위치에만 1을 부여하고 나머지 원소는 모두 0으로 채우는 방식이다.

- **희소 표현(Sparse Representation):** 벡터의 대부분을 차지하는 값이 0으로 채워진다.
- **차원의 저주:** 단어 집합의 크기가 커질수록 벡터 차원이 무한정 증가하여 메모리와 연산 효율이 급격히 저하된다.
- **유사도 표현 불가:** 모든 단어 벡터 간의 내적이 0이 되므로 단어 사이의 의미적 유사성이나 관계를 수학적으로 계산할 수 없다.

### 1.2 워드 임베딩 (Word Embedding)

원핫 인코딩의 한계를 극복하기 위해 단어를 사전에 정해진 저차원의 연속적인 실수 벡터로 변환하는 기법이다.

- **밀집 표현(Dense Representation):** 0이 아닌 유의미한 실수값들로 구성된다.
- **의미적 관계 반영:** 비슷한 문맥에서 자주 등장하는 단어들은 다차원 벡터 공간에서 서로 가까운 거리에 위치하게 된다.
- **학습 가능한 가중치:** 임베딩 벡터는 고정된 상수가 아니라 모델 학습 과정에서 역전파(Backpropagation)를 통해 손실을 줄이는 방향으로 함께 갱신된다.

~~~python
import torch.nn as nn

# num_embeddings: 단어 사전의 크기, embedding_dim: 임베딩 벡터 차원 수
embedding_layer = nn.Embedding(num_embeddings=vocab_size, embedding_dim=128)
~~~

- `nn.Embedding`은 각 단어 인덱스를 행으로 갖는 가중치 행렬(Lookup Table) 형태로 동작한다.
- 단어 인덱스가 입력되면 해당하는 인덱스의 128차원 밀집 벡터를 추출하여 반환한다.

## 2. 순차 데이터 처리와 RNN

순차 데이터(Sequential Data)는 어순이나 시간 순서가 데이터의 의미를 결정짓는 핵심 요소이다. (예: 문장, 주가 데이터, 시계열 센서값)

### 2.1 RNN (Recurrent Neural Network, 순환 신경망)

RNN은 이전 시점($t-1$)의 은닉 상태(Hidden State)를 현재 시점($t$)의 입력과 함께 전달받아 새로운 은닉 상태를 계산함으로써 과거의 맥락을 기억하는 구조를 가진다.

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b_h)$$

- $x_t$: 시점 $t$에서의 입력 벡터이다.
- $h_{t-1}$: 이전 시점의 은닉 상태(과거 기억)이다.
- $h_t$: 현재 시점의 새로운 은닉 상태이며, 다음 시점의 연산에 전달된다.
- $\tanh$: 은닉 상태의 값이 폭주하지 않도록 값의 범위를 -1과 1 사이로 압축하는 비선형 활성화 함수이다.

### 2.2 가중치 공유 (Weight Sharing)

RNN은 시점이 진행되더라도 새로운 가중치를 생성하지 않고, 동일한 가중치($W_x, W_h$)와 편향($b_h$)을 모든 시간 단계에서 반복하여 재사용한다. 이를 통해 시퀀스의 길이에 관계없이 고정된 크기의 파라미터로 데이터를 처리할 수 있다.

## 3. LSTM과 장기 의존성 해결

### 3.1 RNN의 장기 의존성 문제 (Long-Term Dependency)

기본 RNN은 시퀀스가 길어질수록 역전파 과정에서 시간 축을 따라 기울기가 곱해지며 점차 0에 수렴하는 기울기 소실(Vanishing Gradient) 문제가 발생한다. 결과적으로 문장 초반의 정보가 후반부까지 온전히 전달되지 못하는 한계가 발생한다.

### 3.2 LSTM (Long Short-Term Memory)

LSTM은 장기 기억을 보존하기 위해 셀 상태(Cell State, $c$)를 도입하고, 3개의 게이트(Gate)를 통해 정보의 흐름을 능동적으로 통제한다.

- **은닉 상태 ($h$):** 단기 기억을 담당하며 현재 시점의 출력과 직접 연관된다.
- **셀 상태 ($c$):** 이전 시점부터 누적된 정보를 컨베이어 벨트처럼 온전히 보존하며 장기 기억을 전달한다.

| 게이트 종류 | 역할 | 수식 및 동작 원리 |
|---|---|---|
| **망각 게이트 (Forget Gate)** | 과거 정보 중 버릴 비율 결정 | $f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$<br>0에 가까울수록 기억 삭제, 1에 가까울수록 보존 |
| **입력 게이트 (Input Gate)** | 현재 입력 정보 중 새로 저장할 비율 결정 | $i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$<br>새로운 후보 정보와 곱해져 셀 상태에 갱신 |
| **출력 게이트 (Output Gate)** | 갱신된 셀 상태 중 다음 시점으로 내보낼 은닉 상태 결정 | $o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$<br>$h_t = o_t \odot \tanh(c_t)$ 형태로 출력 생성 |

## 4. Embedding과 LSTM 감성 분류 실습

네이버 영화 리뷰 데이터를 활용하여 문장의 긍정(1) 및 부정(0)을 판별하는 이진 분류 파이프라인 실습이다.

### 4.1 데이터 전처리 및 특수 토큰

- **데이터 분할:** Train(64%), Validation(16%), Test(20%) 구조로 분리한다.
- **토큰화 및 인덱싱:** 단어를 최소 단위로 쪼개어 단어 사전을 구축하고 정수 ID를 매핑한다.
- **특수 토큰:**
  - `<PAD>` (Index 0): 배치 처리를 위해 길이가 서로 다른 문장의 길이를 일정하게 맞추는 패딩 토큰이다.
  - `<UNK>` (Index 1): 단어 사전에 포함되지 않은 미등록 단어(Out of Vocabulary)를 대체하는 토큰이다.

### 4.2 분류 모델 아키텍처

~~~python
import torch
import torch.nn as nn

class ReviewSentimentClassifier(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(
            num_embeddings=vocab_size,
            embedding_dim=embedding_dim
        )
        self.lstm = nn.LSTM(
            input_size=embedding_dim,
            hidden_size=hidden_dim,
            batch_first=True
        )
        self.dropout = nn.Dropout(0.5)
        self.classifier = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        # x shape: (batch_size, seq_len)
        embedded = self.embedding(x)
        # lstm_out shape: (batch_size, seq_len, hidden_dim)
        # hidden shape: (num_layers, batch_size, hidden_dim)
        lstm_out, (hidden, cell) = self.lstm(embedded)
        
        # 마지막 시점의 은닉 상태를 추출하여 완전연결층에 전달
        last_hidden = hidden[-1]
        out = self.dropout(last_hidden)
        logits = self.classifier(out)
        return logits
~~~

- `batch_first=True`: 입력 텐서의 첫 번째 차원을 배치 크기(`batch_size, seq_len, dim`)로 설정한다.
- `hidden[-1]`: 전체 문장을 순차적으로 읽어낸 후 최종 시점에서 도출된 은닉 상태를 문장 전체의 요약본으로 추출한다.
- `self.classifier`: 은닉 벡터를 최종 점수(Logit) 1개로 변환한다.

### 4.3 손실 함수: BCEWithLogitsLoss

~~~python
criterion = nn.BCEWithLogitsLoss()
probabilities = torch.sigmoid(logits)
~~~

- `nn.BCEWithLogitsLoss()`는 내부적으로 시그모이드(Sigmoid) 활성화 함수와 이진 교차 엔트로피(Binary Cross Entropy) 손실 연산을 수학적으로 결합하여 처리한다.
- 모델 출력층에 직접 Sigmoid를 적용하는 것보다 연산의 수치적 안정성(Numerical Stability, 오버플로우/언더플로우 방지)이 우수하다.
- 추론 시점에는 출력된 Logit에 `torch.sigmoid()`를 취해 0과 1 사이의 확률값으로 변환한다.

## 5. Seq2Seq 모델 구조와 동작 원리

Seq2Seq(Sequence-to-Sequence)는 가변 길이의 입력 시퀀스를 받아 가변 길이의 출력 시퀀스로 변환하는 인코더-디코더(Encoder-Decoder) 신경망 구조이다.

### 5.1 인코더 (Encoder)

- 원본 입력 문장(예: 영어 문장)의 모든 토큰을 순차적으로 읽어 들인다.
- 마지막 시점의 최종 은닉 상태($h_T$)와 셀 상태($c_T$)를 하나의 고정된 크기를 가진 컨텍스트 벡터($C$)로 압축하여 디코더로 넘겨준다.

$$C = (h_T, c_T)$$

### 5.2 디코더 (Decoder)

- 인코더가 압축한 컨텍스트 벡터를 초기 은닉 상태로 설정하고 단어를 순차적으로 생성한다.
- 문장의 시작을 알리는 특수 토큰 `<sos>`(Start of Sequence)를 첫 입력으로 전달받는다.
- 이전 시점에 예측한 단어를 다음 시점의 입력으로 이어받으며 문장을 생성하다가, 문장 종료 토큰 `<eos>`(End of Sequence)를 생성하면 출력을 종료한다.

### 5.3 교사 강요 (Teacher Forcing)

학습 단계에서 디코더의 다음 입력으로 이전 시점의 모델 예측값이 아닌 **실제 정답(Ground Truth)** 토큰을 강제로 주입하는 학습 기법이다.

- 초기 학습 단계에서 모델이 잘못된 단어를 예측했을 때, 그 오답이 후속 단어 생성에 연쇄적으로 악영향을 미치는 현상을 차단한다.
- 모델의 학습 수렴 속도를 비약적으로 단축시키고 안정적인 최적화를 돕는다.

## 6. 컨텍스트 벡터의 병목 현상

기본 Seq2Seq 아키텍처는 인코더의 모든 정보를 하나의 고정된 차원을 가진 컨텍스트 벡터에 억지로 압축해야 하는 구조적 결함을 지닌다.

~~~text
[기본 Seq2Seq의 병목 현상]
긴 입력 문장 (100개 이상의 토큰)
       │
       ▼
고정 크기 컨텍스트 벡터 (예: 512차원)  <--- [병목 및 정보 손실 발생]
       │
       ▼
디코더 출력 (초반 단어 기억 소실로 번역 품질 저하)
~~~

- **정보 손실 (Information Loss):** 입력 문장의 길이가 길어질수록 앞부분의 세부 정보가 유실된다.
- **표현력 한계:** 문장의 복잡도나 길이에 관계없이 항상 일정한 크기의 벡터만을 사용해야 하므로 문맥 표현에 병목(Bottleneck)이 형성된다.

## 7. Attention 메커니즘과 Q, K, V 연산

Attention 메커니즘은 고정 크기 벡터에 전체 문장을 압축하는 대신, 인코더가 생성한 모든 시점의 은닉 상태를 저장해 두고 **디코더가 특정 단어를 예측할 때 가장 관련성이 높은 입력 단어들을 동적으로 선택하여 참조**하는 방식이다.

### 7.1 Query, Key, Value의 개념

Attention 연산은 정보 검색(Information Retrieval)의 원리와 동일한 논리로 작동한다.

- **Query ($Q$):** 현재 시점에서 찾고자 하는 정보의 기준 벡터이다. (디코더의 현재 은닉 상태 $s_t$)
- **Key ($K$):** Query와 비교할 대상들의 식별 정보 벡터이다. (인코더의 모든 시점 은닉 상태 $h_i$)
- **Value ($V$):** 실제로 가중합을 계산하여 가져올 정보의 알맹이 벡터이다. (일반적으로 Key와 동일한 인코더 은닉 상태 $h_i$)

### 7.2 Attention 연산의 3단계

1. **유사도 점수 계산 (Dot-Product Attention):**
   Query와 모든 Key 벡터 사이의 내적(Dot Product)을 계산하여 유사도를 측정한다.
   $$\text{Score}(Q, K) = Q K^T$$

2. **Attention 가중치 도출 (Attention Weight):**
   유사도 점수 벡터에 Softmax 함수를 취하여 모든 원소의 합이 1이 되는 확률 분포로 정규화한다.
   $$\text{Attention Weight} = \text{Softmax}(\text{Score})$$

3. **컨텍스트 벡터 생성 (가중합 계산):**
   계산된 가중치를 Value 벡터들에 각각 곱하여 최종 가중합(Weighted Sum)을 산출한다.
   $$\text{Context Vector} = \sum (\text{Attention Weight} \times V)$$

결과적으로 현재 예측 대상과 가장 연관성이 높은 단어의 정보가 강하게 반영된 맞춤형 컨텍스트 벡터가 생성된다.

## 8. Attention 연산 실습 및 가중치 시각화

### 8.1 텐서 연산 구현

~~~python
import torch
import torch.nn.functional as F

# Q: 디코더 은닉 상태, K: 인코더 은닉 상태들, V: 인코더 은닉 상태들
# 1단계: 유사도 점수 계산 (내적 연산)
scores = torch.matmul(Q, K.t())

# 2단계: Attention 가중치 계산 (Softmax 정규화)
attention_weights = F.softmax(scores, dim=-1)

# 3단계: 가중합을 통한 컨텍스트 벡터 생성
context_vector = torch.matmul(attention_weights, V)
~~~

- `torch.matmul(Q, K.t())`: Query와 Key의 전치 행렬을 행렬곱하여 모든 단어 쌍 간의 유사도 점수를 한 번에 연산한다.
- `F.softmax(scores, dim=-1)`: 마지막 차원을 기준으로 정규화하여 각 Key별 집중 비율을 0과 1 사이의 값으로 변환한다.
- `torch.matmul(attention_weights, V)`: 산출된 가중치 비율대로 Value 벡터들을 혼합하여 최종 컨텍스트 벡터를 도출한다.

### 8.2 가중치 시각화 (Attention Map)

Attention Weight 값을 2차원 히트맵(Heatmap) 차트로 시각화하면, 모델이 출력 단어를 생성할 때 어떤 입력 단어를 가장 강하게 응시하고 있는지 직관적으로 파악할 수 있다. 색상이 짙을수록 높은 가중치가 부여되었음을 나타낸다.

## 9. 비교 정리

### 9.1 단어 표현 방식 비교

| 구분 | 원핫 인코딩 (One-Hot Encoding) | 워드 임베딩 (Word Embedding) |
|---|---|---|
| **벡터 형태** | 고차원 희소 벡터 (Sparse Vector) | 저차원 밀집 벡터 (Dense Vector) |
| **차원 크기** | 단어 사전의 전체 단어 수 | 사용자 설정 파라미터 (예: 128, 256) |
| **값의 구성** | 0과 1로만 구성 | 다양한 실수값으로 구성 |
| **의미 유사도** | 단어 간 거리 및 유사도 표현 불가 | 벡터 공간상의 거리로 유사도 표현 가능 |
| **학습 여부** | 고정된 규칙 기반 변환 | 역전파를 통해 모델과 함께 지속적 학습 |

### 9.2 순환 신경망 모델 비교

| 모델 | 상태 벡터 구성 | 게이트 구성 | 장단점 및 특징 |
|---|---|---|---|
| **기본 RNN** | 단일 은닉 상태 ($h$) | 없음 | 구조가 단순하나 장기 의존성 및 기울기 소실 문제 발생 |
| **LSTM** | 은닉 상태 ($h$) + 셀 상태 ($c$) | 망각, 입력, 출력 게이트 | 셀 상태를 통해 장기 기억 보존 가능, 연산 복잡도 증가 |

### 9.3 시퀀스 변환 방식 비교

| 구분 | 기본 Seq2Seq | Attention 적용 Seq2Seq |
|---|---|---|
| **정보 전달 방식** | 마지막 시점의 단일 은닉 상태만 전달 | 인코더의 모든 시점 은닉 상태를 보존 후 전달 |
| **컨텍스트 벡터** | 고정된 단일 크기 벡터 | 디코더 시점마다 다르게 계산되는 동적 벡터 |
| **긴 문장 처리** | 심각한 정보 손실 및 병목 현상 유발 | 필요한 단어에 직접 가중치를 두어 병목 해결 |

## 10. 전체 흐름 정리

원시 텍스트가 입력되어 최종 시퀀스로 변환되는 딥러닝 파이프라인의 전체 구조는 다음과 같다.

~~~text
[1. 텍스트 토큰화 및 수치화]
자연어 문장 토큰화 -> 정수 인덱스 부여 (<PAD>, <UNK> 매핑)
      │
      ▼
[2. 워드 임베딩]
단어 인덱스를 nn.Embedding을 통해 저차원 밀집 벡터로 변환
      │
      ▼
[3. 인코더 (LSTM)]
각 시점의 임베딩 벡터를 순차 처리하여 모든 시점의 은닉 상태(Key, Value) 생성
      │
      ▼
[4. Attention 가중치 계산]
디코더의 현재 상태(Query)와 인코더 은닉 상태(Key)의 내적 -> Softmax 정규화
      │
      ▼
[5. 컨텍스트 벡터 결합]
Attention Weight와 인코더 상태(Value)의 가중합으로 동적 컨텍스트 벡터 도출
      │
      ▼
[6. 디코더 (LSTM) 및 출력]
컨텍스트 벡터와 이전 출력을 결합하여 다음 단어 생성 (<eos> 토큰 생성 시 종료)
~~~

## 11. 핵심 정리

### 핵심 코드

~~~python
import torch
import torch.nn.functional as F

# Attention 핵심 3단계 계산
scores = torch.matmul(Q, K.t())
weights = F.softmax(scores, dim=-1)
context = torch.matmul(weights, V)
~~~

- Query와 Key의 내적으로 유사도 점수를 계산한다.
- Softmax 함수로 점수를 가중치 확률 분포로 변환한다.
- 가중치와 Value의 행렬곱을 통해 최종 동적 컨텍스트 벡터를 생성한다.

### 핵심 개념

- 원핫 인코딩의 희소성과 차원 한계는 학습 가능한 저차원 밀집 벡터인 임베딩(Embedding)으로 극복한다.
- RNN의 순환 구조에서 발생하는 기울기 소실 문제는 셀 상태와 게이트를 도입한 LSTM을 통해 완화한다.
- Seq2Seq의 고정 크기 컨텍스트 벡터 병목 현상은 모든 인코더 상태를 참조하는 Attention 메커니즘을 적용하여 해결한다.

## 12. 느낀 점

자연어 처리 모델이 텍스트 데이터를 처리하기 위해 거치는 일련의 발전 과정을 단어 벡터화부터 최신 어텐션 기법까지 유기적으로 이해할 수 있었다. 단순히 원핫 인코딩으로 단어를 표현했을 때 발생하는 차원의 저주와 의미 소실 문제를 임베딩이 어떻게 해결하는지 수식과 코드로 명확히 정리했다. 특히 Seq2Seq 모델이 가진 구조적 취약점인 '고정 크기 컨텍스트 벡터의 병목 현상'이 왜 발생하는지, 그리고 이를 극복하기 위해 제안된 Attention 메커니즘이 인코더의 모든 은닉 상태를 Key와 Value로 보존해 두고 디코더의 Query와 비교하여 가중치를 동적으로 할당하는 논리를 체계적으로 파악했다. 이번 학습을 바탕으로 향후 트랜스포머(Transformer)와 대형 언어 모델(LLM)의 근간이 되는 Self-Attention 구조까지 자연스럽게 시야를 확장할 수 있는 기초를 확립했다.
