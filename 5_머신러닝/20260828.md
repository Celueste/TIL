## 1. 신경망의 기본 구조와 퍼셉트론

인공신경망(Artificial Neural Network)은 생물학적 신경세포의 신호 전달 체계를 모방한 머신러닝 알고리즘이다. 입력층, 은닉층, 출력층의 계층 구조로 이루어져 있다.

- **입력층 (Input Layer):** 외부 데이터를 모델로 처음 받아들이는 층이다.
- **은닉층 (Hidden Layer):** 입력층과 출력층 사이에서 복잡한 패턴과 특징을 다단계로 추출하는 층이다.
- **출력층 (Output Layer):** 최종 예측값(회귀 예측값 또는 클래스별 점수)을 출력하는 층이다.

### 1.1 단층 퍼셉트론 (Single-Layer Perceptron)

은닉층 없이 입력층과 출력층만으로 구성된 가장 단순한 형태의 신경망이다.

$$Z = W \cdot X + b$$

- 입력값($X$)에 가중치($W$)를 곱하고 편향($b$)을 더해 계산한다.
- 하나의 선형 결정 경계로만 데이터를 분리할 수 있어 XOR 문제와 같은 비선형 분류 문제를 해결하지 못하는 한계가 있다.

### 1.2 다층 퍼셉트론 (Multi-Layer Perceptron, MLP)

단층 퍼셉트론의 한계를 극복하기 위해 입력층과 출력층 사이에 하나 이상의 은닉층을 추가한 구조이다.

- 은닉층을 거치며 입력 데이터의 단순한 형태(예: 선, 경계면)를 조합하여 고차원적이고 추상적인 특징(예: 사물의 형태, 패턴)을 학습한다.
- 비선형 활성화 함수와 결합하여 비선형적으로 분포된 복잡한 데이터 관계를 학습할 수 있다.

## 2. 은닉층과 모델 파라미터 계산

파라미터(Parameter)는 학습 과정에서 최적의 예측을 위해 모델이 자체적으로 갱신하는 내부 변수(가중치와 편향)이다. $28 \times 28$ 크기(총 784픽셀)의 이미지를 10개 클래스로 분류하는 상황을 기준으로 계산한다.

### 2.1 은닉층이 없는 경우 (입력 784 → 출력 10)

- 가중치($W$): $784 \times 10 = 7,840$개
- 편향($b$): $10$개
- 총 파라미터 수: $7,840 + 10 = 7,850$개

### 2.2 128개 노드의 은닉층을 1개 추가한 경우

- **입력층 → 은닉층 (784 → 128):**
  - 가중치: $784 \times 128 = 100,352$개
  - 편향: $128$개
  - 소계: $100,480$개
- **은닉층 → 출력층 (128 → 10):**
  - 가중치: $128 \times 10 = 1,280$개
  - 편향: $10$개
  - 소계: $1,290$개
- **총 파라미터 수:** $100,480 + 1,290 = 101,770$개

은닉층과 노드 수가 늘어날수록 모델의 표현력은 향상되지만, 계산 비용과 과적합 발생 위험이 함께 커진다.

## 3. 역전파와 옵티마이저

신경망 학습은 순방향으로 오차를 확인하고, 역방향으로 기울기를 계산한 뒤, 옵티마이저로 파라미터를 갱신하는 순환 구조로 이루어진다.

~~~text
[순방향 전파]
입력 데이터 주입 -> 레이어별 선형 연산 및 활성화 함수 통과 -> 최종 예측값 도출
      │
      ▼
[손실 계산]
예측값과 실제 정답을 손실 함수(Loss Function)로 비교하여 오차(Loss) 산출
      │
      ▼
[역전파 (Backpropagation)]
연쇄 법칙(Chain Rule)을 적용해 손실에 대한 각 가중치의 기울기(Gradient) 계산
      │
      ▼
[옵티마이저 (Optimizer)]
계산된 기울기와 학습률(η)을 적용하여 가중치와 편향 값 갱신
~~~

### 3.1 역전파와 옵티마이저의 차이

$$W \leftarrow W - \eta \frac{\partial L}{\partial W}$$

- **역전파 (Backpropagation):** 오차를 줄이기 위해 가중치를 어느 방향으로 얼만큼 수정해야 하는지 나타내는 '기울기(Gradient)'를 계산하는 알고리즘이다.
- **옵티마이저 (Optimizer):** 역전파로 계산된 기울기를 활용하여 실제 가중치 값을 업데이트하는 최적화 알고리즘이다.
- **학습률 ($\eta$):** 갱신 과정에서 한 번에 이동할 보폭의 크기이다.

### 3.2 주요 옵티마이저 종류

- **SGD (확률적 경사하강법):** 미니 배치마다 계산된 기울기를 그대로 반영하여 가중치를 갱신한다. 단순하지만 국소 최적점(Local Minima)에 갇히거나 진동이 심해 수렴 속도가 느려질 수 있다.
- **Momentum:** 이전 단계의 이동 방향과 속도를 기억하는 '관성' 개념을 도입하여 진동을 줄이고 빠르게 최적점으로 이동한다.
- **RMSprop:** 각 파라미터의 최근 기울기 크기에 따라 학습률을 다르게 조절한다. 변화가 큰 파라미터는 작은 보폭으로, 변화가 작은 파라미터는 큰 보폭으로 이동시킨다.
- **Adam (Adaptive Moment Estimation):** Momentum의 관성 효과와 RMSprop의 적응적 학습률 조절을 결합하여 가장 널리 안정적으로 사용된다.

## 4. 활성화 함수와 기울기 소실

### 4.1 활성화 함수(Activation Function)가 필요한 이유

선형 레이어만을 여러 층 쌓으면 수학적으로 단일 선형 레이어로 축약된다.

$$Z_1 = W_1 X + b_1, \quad Z_2 = W_2 Z_1 + b_2 \implies Z_2 = (W_2 W_1) X + (W_2 b_1 + b_2) = W_{\text{new}} X + b_{\text{new}}$$

은닉층 사이에 비선형 활성화 함수를 배치해야 신경망이 비선형적인 복잡한 데이터 경계를 표현할 수 있다.

### 4.2 Sigmoid와 기울기 소실 (Vanishing Gradient)

- Sigmoid 함수는 입력값을 0과 1 사이로 압축한다.
- 입력값의 절댓값이 커질수록 함수의 양 끝단에서 기울기가 0에 매우 가까워진다.
- 역전파 과정에서 0에 가까운 작은 기울기 값들이 연쇄적으로 곱해지면 입력층에 가까운 층으로 갈수록 기울기가 소멸하여 가중치가 더 이상 학습되지 않는 기울기 소실 문제가 발생한다.

### 4.3 ReLU (Rectified Linear Unit)

심층 신경망에서 기울기 소실 문제를 극복하기 위해 설계된 표준 활성화 함수이다.

$$f(x) = \max(0, x)$$

- 입력값이 0 이하이면 0을 출력하고, 0보다 크면 입력값을 그대로 통과시킨다.
- 양수 영역에서 기울기가 항상 1로 유지되므로 층이 깊어져도 기울기가 소실되지 않고 안정적으로 역전파된다.

## 5. 과소적합, 과적합 및 규제 기법

### 5.1 과소적합과 과적합

- **과소적합 (Underfitting):** 모델의 복잡도가 부족하여 훈련 데이터의 기본적인 경향조차 제대로 학습하지 못한 상태이다.
  - 대응: 은닉층이나 노드 수를 늘려 모델 복잡도를 높이거나, 학습 에포크(Epoch)를 늘린다.
- **과적합 (Overfitting):** 모델이 훈련 데이터의 노이즈까지 과도하게 외워 훈련 데이터에 대한 손실은 낮지만 검증/테스트 데이터에서는 예측 성능이 급격히 떨어지는 상태이다.
  - 대응: 데이터 증강(Data Augmentation), 모델 크기 축소, Dropout, Early Stopping을 적용한다.

### 5.2 Dropout

학습 과정에서 무작위로 은닉층 뉴런의 일부를 비활성화(연산 제외)하는 정규화(규제) 기법이다.

- 특정 뉴런들끼리 결합하여 고정된 패턴에 과도하게 의존하는 동시적응(Co-adaptation) 현상을 방지한다.
- **학습 시:** 지정한 확률($p$)에 따라 뉴런을 무작위로 끈다.
- **평가 시:** 모든 뉴런을 활성화하여 출력값 전체를 사용한다.

### 5.3 Early Stopping (조기 종료)

검증 데이터의 오차(Validation Loss)가 더 이상 감소하지 않고 일정 에포크 동안 개선되지 않을 때 학습을 미리 중단하는 방법이다.

- 훈련 손실(Train Loss)은 계속 감소하더라도 검증 손실이 증가하기 시작하면 과적합 단계로 판단한다.
- `patience` 값을 지정하여 검증 손실이 개선되지 않는 상황을 몇 번까지 허용할지 제어한다. (예: `patience=3` 설정 시 3회 연속 미개선 시 즉시 중단)

### 6.2 Fashion MNIST 데이터 분할 및 DataLoader

- 원본 데이터: Train 60,000장, Test 10,000장
- 실습 분할: Train 50,000장, Validation 10,000장, Test 10,000장

~~~python
from torch.utils.data import DataLoader

train_loader = DataLoader(
    train_data,
    batch_size=32,
    shuffle=True
)

val_loader = DataLoader(
    val_data,
    batch_size=32,

~~~

- `batch_size=32`: 전체 데이터를 32개씩 묶은 미니 배치 단위로 모델에 주입하여 메모리 사용을 효율화한다.

## 7. PyTorch 모델 설계 및 학습 구현

### 7.1 신경망 모델 클래스 정의

~~~python
import torch.nn as nn

class AdvancedFashionClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.linear1 = nn.Linear(28 * 28, 128)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(p=0.2)
        self.linear2 = nn.Linear(128, 10)

    def forward(self, x):
        out = self.flatten(x)
        out = self.linear1(out)
        out = self.relu(out)
        out = self.dropout(out)
        out = self.linear2(out)
        return out
~~~

- `nn.Flatten()`: 2차원 이미지 데이터($28 \times 28$)를 1차원 벡터($784$)로 변환한다.
- `nn.Linear(28 * 28, 128)`: 입력 노드 784개를 은닉 노드 128개로 연결하는 선형 계층이다.
- `nn.ReLU()`: 은닉층 뒤에 비선형 활성화 함수를 적용한다.
- `nn.Dropout(p=0.2)`: 학습 시 20%의 뉴런을 무작위로 비활성화하여 과적합을 억제한다.
- `nn.Linear(128, 10)`: 최종 10개 클래스에 대응하는 원시 점수(Logit)를 출력한다.

### 7.2 학습 모드와 평가 모드 분리

~~~python
# 학습 루프 내부
model.train()
optimizer.zero_grad()
outputs = model(images)
loss = criterion(outputs, labels)
loss.backward()
optimizer.step()

# 검증/평가 루프 내부
model.eval()
with torch.no_grad():
    val_outputs = model(val_images)
    val_loss = criterion(val_outputs, val_labels)
~~~

- `model.train()`: 모델을 학습 상태로 설정하여 Dropout 기능을 활성화한다.
- `optimizer.zero_grad()`: PyTorch는 기울기를 누적하는 특성이 있으므로, 새로운 배치 계산 전 이전 배치의 기울기를 0으로 초기화한다.
- `loss.backward()`: 역전파를 수행하여 모델 파라미터별 편미분 기울기를 계산한다.
- `optimizer.step()`: 계산된 기울기를 기반으로 가중치를 업데이트한다.
- `model.eval()`: 평가 모드로 전환하여 Dropout 동작을 비활성화한다.
- `torch.no_grad()`: 검증 과정에서는 역전파가 필요하지 않으므로 기울기 연산 추적을 중단하여 연산 속도를 높이고 메모리를 절약한다.

## 8. 손실 함수 (Cross Entropy Loss)

다중 클래스 분류 문제에서는 모델의 예측 확률 분포와 실제 정답 분포 간의 차이를 측정하는 Cross Entropy Loss를 주로 사용한다.

~~~python
criterion = nn.CrossEntropyLoss()
~~~

- `nn.CrossEntropyLoss()`는 내부적으로 Softmax 함수 연산과 NLLLoss(Negative Log Likelihood Loss) 연산을 통합 처리하므로 모델 출력층에 별도의 Softmax를 붙이지 않는다.
- 입력값으로는 클래스별 점수인 Logit을 받고, 타깃으로는 원-핫 벡터가 아닌 클래스 인덱스 정수를 직접 전달받아 손실을 계산한다.

## 9. 비교 정리

### 9.1 활성화 함수 비교

| 구분 | Sigmoid | ReLU |
|---|---|---|
| 출력 범위 | $(0, 1)$ | $[0, \infty)$ |
| 연산 특징 | 지수 함수 계산 포함 | 단순 임계값($\max(0, x)$) 계산으로 속도 빠름 |
| 주요 문제점 | 층이 깊어지면 양 극단에서 기울기 소실 발생 | 음수 입력 영역에서 뉴런이 비활성화됨 |
| 주 활용처 | 이진 분류 출력층 | 심층 신경망의 은닉층 표준 |

### 9.2 레이블 표현 방식에 따른 Cross Entropy 비교

| 구분 | Categorical Cross Entropy | Sparse Categorical Cross Entropy |
|---|---|---|
| 정답 레이블 형태 | 원-핫 인코딩 벡터 (예: `[0, 0, 1]`) | 정수형 클래스 인덱스 (예: `2`) |
| 메모리 효율 | 클래스 수가 많을수록 메모리 낭비 발생 | 정수 1개만 저장하므로 메모리 효율적 |
| PyTorch 적용 방식 | 원-핫 벡터를 직접 입력으로 줄 때 변환 필요 | `nn.CrossEntropyLoss()`의 기본 입력 표준 형태 |

### 9.3 옵티마이저 특성 비교

| 옵티마이저 | 핵심 메커니즘 | 주요 특징 |
|---|---|---|
| **SGD** | 현재 배치의 순간 기울기 반영 | 구현이 단순하나 진동이 심하고 수렴 속도 느림 |
| **Momentum** | 이전 기울기의 이동 관성(Momentum) 반영 | 국소 최적점을 잘 탈출하며 진행 방향 진동 완화 |
| **RMSprop** | 파라미터별 최근 기울기 제곱 평균 반영 | 학습률을 파라미터 단위로 동적 조절하여 안정화 |
| **Adam** | Momentum(관성) + RMSprop(적응적 보폭) 결합 | 하이퍼파라미터 튜닝이 용이하고 범용 성능 우수 |

## 10. 전체 흐름 정리

PyTorch 기반 심층 신경망 모델링 파이프라인의 전체 실행 흐름은 다음과 같다.

~~~text
[1. 환경 및 데이터 준비]
PyTorch/TorchVision 구성 -> Fashion MNIST 로드 -> Train/Val/Test 분할 -> DataLoader 구성
      │
      ▼
[2. 신경망 아키텍처 설계]
nn.Flatten -> nn.Linear -> nn.ReLU (비선형 활성화) -> nn.Dropout (과적합 규제) -> nn.Linear (Logit 출력)
      │
      ▼
[3. 손실 함수 및 옵티마이저 정의]
nn.CrossEntropyLoss 선언 및 Adam 옵티마이저에 모델 파라미터 등록
      │
      ▼
[4. 모델 학습 단계 (에포크 반복)]
model.train() -> optimizer.zero_grad() -> Forward -> Loss 계산 -> loss.backward() -> optimizer.step()
      │
      ▼
[5. 검증 및 조기 종료 판단]
model.eval() 및 torch.no_grad() -> Validation Loss 평가 -> 개선 미달 시 Early Stopping
      │
      ▼
[6. 최종 모델 평가]
최적 가중치 로드 후 Test Set을 통해 최종 분류 정확도 검증
~~~

## 11. 핵심 정리

### 핵심 코드

~~~python
import torch
import torch.nn as nn

# 1. 모델, 손실함수, 옵티마이저 설정
model = AdvancedFashionClassifier()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# 2. 1회 배치 학습 표준 스텝
optimizer.zero_grad()
outputs = model(images)
loss = criterion(outputs, labels)
loss.backward()
optimizer.step()
~~~

- `optimizer.zero_grad()`로 이전 단계의 잔여 기울기를 비운다.
- `loss.backward()`로 오차 역전파를 수행해 파라미터별 기울기를 산출한다.
- `optimizer.step()`으로 계산된 기울기를 활용해 실제 모델 파라미터를 갱신한다.

### 핵심 개념

- 다층 퍼셉트론은 선형 연산 사이에 비선형 활성화 함수(ReLU)를 추가하여 복잡한 비선형 데이터 패턴을 학습한다.
- 역전파는 오차에 대한 파라미터의 기울기를 구하는 과정이며, 옵티마이저(Adam 등)는 그 기울기를 바탕으로 가중치를 최적화하는 주체이다.
- 과적합은 Dropout과 Early Stopping을 통해 통제하며, 평가 시에는 `model.eval()`과 `torch.no_grad()`를 선언해 불필요한 계산을 차단해야 한다.

## 12. 느낀 점

신경망이 단순히 선형 변환 층을 높게 쌓는다고 해서 성능이 개선되는 것이 아니라, 은닉층 사이에 비선형 활성화 함수를 배치해야만 고차원적 패턴을 표현할 수 있다는 원리를 깊이 이해하게 되었다. 역전파가 손실에 따른 미분 기울기를 역방향으로 전달하는 알고리즘이고, 옵티마이저가 이 기울기를 넘겨받아 실제 가중치의 이동 방향과 보폭을 제어한다는 역할 구분을 명확히 정립했다. 또한 은닉층이 증가할수록 파라미터 수가 급증하여 과적합 위험이 발생하므로, Dropout과 Early Stopping 같은 규제 기법이 필수적임을 알게 되었다. PyTorch 코드로 모델을 설계하고 `zero_grad()`부터 `backward()`, `step()`으로 이어지는 학습 루프의 5단계 파이프라인을 직접 작성해 봄으로써 딥러닝 프레임워크의 동작 원리를 체계적으로 체득할 수 있었다.
